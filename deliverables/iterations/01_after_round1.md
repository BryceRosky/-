# 面向离散扩散多模态大模型的生成优化方法研究

## 一、国内外研究进展、现状、挑战与意义

### 1.1 研究背景、问题范围与选题意义

大规模预训练模型正在由单一文本建模扩展到图像、视频、语音等多种模态，并从分类、检索等判别任务逐步走向理解、生成与交互的一体化。统一多模态模型希望以共享的主体网络接收文本和视觉输入，同时完成视觉问答、文生图、图像编辑及多轮修正。其价值不只在于减少任务专用模块，还在于使理解侧获得的对象、属性和关系知识能够约束生成，使生成结果又能成为理解与反馈的对象。若这种闭环能够稳定建立，同一模型便可能在内容创作、视觉设计、教育辅助、具身交互和科学可视化中提供一致接口。

文生图是检验生成能力的代表任务。现有模型能够合成具有较高感知质量的图像，但在包含多个对象和组合关系的提示上，仍会出现对象遗漏、计数错误、属性绑定混乱及空间关系颠倒等问题；GenEval 和 DPG-Bench 分别从对象中心组合语义和稠密提示遵循角度揭示了这些不足[1–2]。这些失败不应全部解释为模型缺乏知识：有些提示在增加采样候选、调整轨迹或给予语义反馈后能够得到正确结果，说明推理预算如何分配、训练奖励如何传递到具体决策，同样决定了最终性能。持续扩大模型、数据和训练计算可以提高能力上限，却难以替代对生成机制和部署预算的研究。因此，在固定底座与有限计算条件下提高提示遵循、视觉质量和生成效率，是具有独立价值的问题。

本课题把研究范围限定为使用离散视觉 token、通过多轮掩码预测生成图像，并兼具视觉理解能力的统一模型。该范围需要与三类相邻系统区分。第一类是连续潜空间扩散模型，其图像状态为连续变量；第二类是按固定顺序逐 token 输出图像的自回归模型；第三类是“语言模型加独立连续扩散生成器”的组合系统。三类系统都可能完成理解和生成，但动作空间、轨迹概率、缓存方式和少步化方法并不相同。本文关注的离散掩码扩散从全掩码状态出发，在每轮并行预测多个视觉位置并按置信度或调度规则保留部分 token，同一终态可以由不同去掩码顺序到达。可调的生成顺序、候选轨迹和采样步数为优化提供了自由度，也带来了离散信用分配、中间状态评价和跨步迁移等特有问题。

围绕这一对象，现有研究可分为四个相连层面：基础模型决定视觉表示与生成轨迹；训练后优化决定终局奖励如何传到 token 和阶段；推理时扩展决定额外计算用于哪些候选；蒸馏与少步生成决定在线搜索经验能否固化为固定预算能力。本文综述按这一链路组织，而不把“统一架构”“强化学习”“搜索”和“加速”视为互不相关的技术点。其核心问题是：能否识别离散生成中的高价值决策，按其预期贡献配置训练和推理计算，并在不牺牲理解可靠性与视觉多样性的前提下，将所得经验迁移到少步模型中。

这一问题具有三方面意义。理论上，非固定去掩码顺序中的联合概率与信用传播不同于固定顺序自回归，也不同于连续扩散的状态演化，需要分析生成秩、条件上下文和终局奖励之间的关系。方法上，统一模型能够同时生成和读取图像，为内部语义反馈提供了条件，但也产生共享偏差和评价器漂移。应用上，减少无效轨迹和采样轮数有望降低交互等待和部署成本，不过只有端到端时延、吞吐和峰值显存的实测才能证明实际加速，网络前向次数减少本身并不等同于墙钟时间按比例下降。

### 1.2 图像生成范式、离散视觉表示与掩码扩散

扩散概率模型通过构造逐步破坏数据的前向过程并学习反向恢复，为高质量图像生成建立了稳定训练框架。DDPM 证明了多步去噪的有效性[3]，潜空间扩散将去噪转移到压缩潜变量中，降低了高分辨率生成成本[4]，SDXL 又通过更大的网络、改进的条件编码与训练策略提升了高分辨率合成质量[5]。连续表示便于描述细粒度变化，相关采样理论和工程生态也较成熟；传统迭代采样通常需要多次网络前向，但这一特点不能写成连续扩散必然“固定多步”。渐进蒸馏、一致性模型和分布匹配蒸馏已经分别从教师轨迹压缩、一致性映射与生成分布匹配角度将连续扩散减少到少数步甚至一步[6–8]。连续扩散因此是少步研究的重要参照，而不是静态且不可加速的对照组。

离散图像生成首先需要把像素压缩为有限词表。VQ-VAE 以向量量化学习离散潜变量，奠定了神经离散表示的基本形式[9]；VQGAN 在此基础上结合感知损失与对抗训练，提高了高分辨率图像的重建与感知质量[10]。DALL-E 展示了将文本和离散图像 token 作为统一序列进行生成的可行性[11]。这一路线把图像问题转化为词表上的概率建模，使 Transformer 能够在同一序列空间处理两种模态，但其性能上限受 tokenizer 约束：较大的码本和较低的压缩率有助于保留纹理、文字与小物体，却会增加序列长度和计算；较强压缩降低主干成本，却可能在建模之前已经丢失细节。因而，视觉 token 数量、码本利用率、重建质量和主体模型长度必须联合报告，不能只用主体模型参数量衡量系统能力。

早期离散图像模型多采用自回归分解，按栅格或预定顺序逐 token 生成。其联合概率定义清晰，但高分辨率图像对应长序列，逐位置解码造成较高延迟，早期错误也可能沿固定顺序累积。MaskGIT 改用双向 Transformer 反复预测被掩码位置，每轮保留高置信 token 并重掩码低置信位置，实现多位置并行恢复[12]。D3PM 从离散状态空间的马尔可夫转移角度建立更一般的离散扩散框架[13]，后续比率估计方法进一步扩展了训练与采样形式[14]。这些工作共同说明，离散生成并不等于自回归：掩码扩散可以同时预测多个位置，并通过掩码调度改变生成顺序和步数。

设视觉 token 序列为 z=(z1,…,zN)，初始状态全部为特殊掩码 [M]。在第 t 轮，模型根据文本条件 c 和当前可见 token 预测所有掩码位置的类别分布，再按置信度、随机性与调度函数决定哪些预测被写入状态、哪些重新置为 [M]。经过 T 轮后，完整序列由图像解码器还原。相对自回归模型，这一过程允许并行恢复和非固定顺序；相对连续扩散，类别分布、掩码集合与去掩码事件构成显式的离散决策变量，可用于策略优化、搜索和跨步监督。不过“可作为决策变量”不等于可以直接套用连续梯度：并行选择改变轨迹概率，同一终态对应许多路径，随机重掩码还可能构造出真实 rollout 从未访问的上下文。

二维图像展平为一维序列后，模型还需恢复空间关系。自回归栅格顺序本身含有局部邻接，而掩码扩散的恢复次序由置信度、调度和随机采样共同决定，需要二维位置编码、行列标记或分块机制补充空间结构。一次恢复多个位置能减少同步轮数，但每一轮 Transformer 前向仍需处理长序列，classifier-free guidance 还可能引入条件与无条件计算。若每轮只保留少量位置，过程退化为长步数迭代；若过早固化过多位置，错误结构可能难以纠正。因此，视觉 tokenizer、空间编码、掩码日程和主干计算共同决定质量与效率，不能把“并行 token”简单等同于“低延迟”。

现有研究常观察到早期去掩码阶段更多影响对象数量、主体位置和大体布局，后期阶段更多补充颜色、纹理与局部属性，但这一现象依赖模型、提示和采样调度，并非每个早期 token 都对应轮廓。高置信背景可能很早出现，复杂主体的关键边界也可能较晚稳定。《Sketch Then Paint》在特定底座和协议上利用了这种统计倾向[15]，其证据适合支持“生成顺序可能包含层次信息”，尚不足以把“早期等于结构、后期等于细节”写成普遍事实。后续优化需要把顺序作为可检验先验，并结合预测熵、空间区域和对终局奖励的敏感度判断其适用范围。

### 1.3 生成与理解统一模型的技术谱系及比较

“统一多模态模型”至少包含架构共享、表示共享和学习目标共享三个层次，不能仅因一个系统同时支持问答和文生图就认为三者都已统一。按图像生成机制，现有代表工作可分为三类。第一类把文本和离散图像都视为序列并使用下一 token 预测，Emu3 代表这种全自回归路线[16]；Janus-Pro 则通过解耦的视觉编码路径缓解理解与生成对表示需求不同的问题，同时保留共享主体模型[17]。这类方法的联合分布定义直接，但图像长序列仍带来逐 token 解码成本。第二类在同一 Transformer 中组合不同目标，Show-o 对文本采用自回归建模、对图像采用离散扩散[18]。它共享主体参数，却没有把两种模态的生成过程变为同一目标。第三类进一步采用双向注意力和掩码预测处理多模态 token，试图在统一离散扩散目标下覆盖理解与生成；MMaDA、Muddit、Lumina-DiMOO 和 LaViDa-O 属于这一方向[19–22]。

语言扩散模型为第三类路线提供了初始化和训练基础。LLaDA 将掩码扩散扩展到语言建模[23]，从自回归模型迁移参数的研究表明，适配可以降低从头训练扩散语言模型的成本[24]。LLaDA-V 通过视觉指令微调使扩散语言模型读取图像并回答问题[25]，但视觉理解能力本身不等于具备图像生成。相比之下，MMaDA、Muddit 与 Lumina-DiMOO 等需要同时表示文本和输出图像，训练数据、视觉词表、注意力方式及采样器都会影响两类能力。将这些工作放在同一表格比较时，应至少区分：文本建模目标、图像建模目标、是否共享词表与主干、是否支持图像输出/编辑、视觉 token 数量、默认采样步数以及是否包含后训练。这样才能判断性能来自“统一目标”、更强 tokenizer、更大模型或更丰富数据，而不是把所有提升归因于统一架构。

所附 Lumina-DiMOO 论文给出了全离散统一模型的完整实例[21]。该模型以扩散语言模型为初始化，在文本词表之外使用包含 8192 个离散符号的视觉词表，使用同一个双向 Transformer 和掩码预测目标处理两种模态。其图像 tokenizer 的空间下采样率为 16，1024×1024 图像对应 4096 个视觉位置，并通过行结束标记保留二维形状信息。训练由图文预训练、多任务中期训练、监督微调和 Self-GRPO 组成，覆盖文生图、编辑、主体驱动、控制生成、补绘、外扩和视觉问答。这个例子说明架构统一需要数据和阶段化训练配合；仅共享主干并不能自动消除生成与理解之间的目标冲突。

在论文报告的同一设置内，Lumina-DiMOO 基础模型的 GenEval 总分为 0.88，Self-GRPO 后为 0.91，颜色与属性绑定分项由 0.89、0.76 提升至 0.95、0.82[21]。这些数值支持理解分支能够构造对生成有用的语义反馈，但 GenEval 只评价生成图像是否符合对象和属性要求，不能由此推出视觉理解能力同步提高。证明“生成—理解协同”至少需要三类证据：生成指标改善、独立理解基准不退化，以及评价分支与人工或外部判断保持相关。若只有第一类证据，更准确的结论是“理解分支为生成提供了有效训练信号”。

统一模型还面临长序列和多轮采样的系统矛盾。Lumina-DiMOO 在所报设置下使用最大 logit 缓存复用稳定 token 表示，将 1024×1024 文生图时间由约 45 秒降至约 22 秒，同时峰值显存由 38.9 GB 增至 45.9 GB，且缓存为有损近似[21]。这一结果体现了计算、内存和误差的交换：网络级缓存减少重复计算，但不决定哪些候选值得继续；序列剪枝可以缩短输入，却可能破坏全局关系；算法级预算分配能够减少低价值轨迹或步骤，却要承担评分与调度开销。后续工作需要在相同硬件、批量、分辨率与解码设置下分别报告主模型、验证和图像解码成本，才能比较不同层面的效率优化。

综合而言，现有统一模型已经证明共享主体网络可以覆盖多种理解和生成任务，却尚未形成单一最优范式。全自回归路线具有清楚的概率分解，混合目标路线保留各模态的成熟机制，全掩码扩散路线则提供双向条件建模和并行恢复。本文选择第三类路线，是因为非固定去掩码顺序、内部理解反馈与可调采样步数共同形成了独特优化空间；这一选择并不意味着其他统一架构在能力或效率上天然较弱，所有结论都应限定在可比底座和评测协议内。

### 1.4 奖励后训练、离散策略概率与层次信用分配

最大似然或掩码预测训练优化的是数据分布上的局部预测，而实际生成评价通常关心完整图像的提示遵循、审美、感知质量或人类偏好。奖励后训练试图缩小两者差距。PPO 以裁剪概率比限制策略更新幅度[26]，GRPO 在同一输入下比较多条样本，以组内相对奖励构造优势，从而减少对独立价值网络的依赖[27]。在连续扩散图像生成中，DDPO 把逐步去噪视为策略轨迹，直接依据终局奖励优化扩散模型[28]；Diffusion-DPO 则把成对偏好转化为无需在线奖励采样的直接偏好目标[29]。前者说明生成模型可以用可微策略梯度对齐外部奖励，后者说明离线偏好也能改变生成分布，但两者所处理的是连续状态和预定时间序列，不能直接回答离散掩码扩散中“哪些 token 在何时成为动作”的问题。

离散掩码生成的困难首先来自轨迹定义。自回归模型的联合概率按固定位置顺序分解；掩码扩散在一轮内同时给出多个位置的类别分布，再由置信度、随机性和掩码日程决定写入集合。同一最终图像可以经由不同写入次序产生，轨迹概率不仅包含 token 类别概率，还与位置选择事件有关。若将最终每个 token 当作彼此独立的动作，会遗漏并行选择和调度的贡献；若严格保存每一轮状态、位置事件与新旧策略概率，计算和显存又随序列长度、采样步数及 rollout 数量增长。离散 RL 的关键取舍因此不是“要不要使用奖励”，而是如何在训练上下文忠实度、概率估计偏差和可承受开销之间平衡。

现有离散扩散强化学习大体采用三类上下文。第一类随机重掩码最终样本，代表方法包括 MaskGRPO[30]。它无需保存完整轨迹，能够在同一图像上构造多种掩码组合，但可见 token 可能含有真实 rollout 中尚未生成的未来信息，导致训练条件与行为策略不一致。第二类保存实际去掩码轨迹。TraceRL 主要面向扩散语言模型；《Sketch Then Paint》依据其轨迹记录思想构造图像生成对照 TraceGRPO[15, 31]。该路线可减少未来信息污染，却需要缓存多个长序列中间状态，且单条图像只覆盖已经采样的一条顺序。第三类在统一的全掩码、仅文本可见上下文中估计概率，使所有位置都不接触图像答案，计算更规整，但同时删除了真实过去信息，因此属于有偏代理而非真实轨迹概率[15]。三类方法分别换取覆盖度、忠实度和效率，不宜只用最终分数判断哪一种估计“更正确”。

第二个困难是图像级奖励与 token 级动作之间的信用分配。将同一个终局优势广播给全部视觉 token，隐含假设每个位置和阶段贡献相同；实际生成中，改变对象数量、空间关系的决策与补充背景纹理的决策对语义指标影响不同。另一方面，固定给早期 token 更高权重也不是严格的因果估计，因为某个早期状态能否获得高回报取决于后续策略如何补全，同一结构经不同随机补全可能产生很大方差。更恰当的区分是“状态价值”和“动作边际贡献”：前者表示给定部分结构后继续生成的期望回报，后者表示替换或重掩码某个动作造成的价值变化。精确计算需要多次条件补全或反事实 rollout，成本较高，因此现有方法多使用生成秩、预测熵或分组权重作为近似。

《Sketch Then Paint》提出 HT-GRPO，将 rollout 中较早恢复且高熵的视觉 token 视为结构集合，较晚 token 视为细化集合，在全局、结构和细化三个阶段分配不同训练预算与信用权重[15]。该方法使用全掩码文本条件估计概率比，以避免随机重掩码的未来信息污染和真实轨迹的缓存开销。其代价是代理分布不含真实已生成上下文，不能与行为轨迹条件概率等同。方法所利用的“早期更偏结构”应理解为统计先验，而不是逐 token 的语义标注。

在该稿件所报的同一实验协议内，HT-GRPO 将 MMaDA 的 GenEval 从 0.56 提升至 0.83，MaskGRPO 对照为 0.80；在 Lumina-DiMOO 上由 0.83 提升至 0.92，MaskGRPO 对照为 0.88，DPG-Bench 也报告同方向增益[15]。这些结果支持层次信用在指定底座、提示集与评价器上的有效性，但尚不能证明固定结构比例或全掩码概率代理具有普适性。稿件属于最新公开工作，相关结论还需在更多采样日程、分辨率和非文生图任务中验证，并与相同训练预算、rollout 数量和奖励模型的基线比较。

现有研究由此形成清晰而未闭合的链条：连续扩散 RL 证明终局奖励能够优化生成策略[28–29]，离散方法提出了可计算的概率代理[15, 30–31]，层次方法进一步承认阶段贡献不同[15]。仍然缺少的是对代理偏差、轨迹成本和动态信用的统一测量。评价此类方法时应同时报告奖励提升、独立测试指标、策略 KL、概率比裁剪率、样本多样性、训练显存和 GPU 时间；若只报告训练奖励或单一对齐指标，无法排除奖励过拟合、模式收缩或计算换分数。

### 1.5 生成—理解自反馈与推理时轨迹扩展

统一模型的特殊能力在于它可以读取自己的输出并形成内部反馈。传统文生图评价常依赖 CLIP 图文相似度、ImageReward 等偏好模型，或额外部署视觉语言模型[32–33]。外部评价器的优点是与生成模型参数分离，标准相对稳定；缺点是增加计算和部署复杂度，其偏好也可能与目标模型、提示分布或人工判断不一致。内部评价器无需引入另一套大型模型，还能把提示分解为对象、数量、颜色和关系问题，再通过视觉问答给出结构化反馈。不过，生成器和评价器共享参数或训练数据时，二者也可能共享盲区，内部一致不等于对人类正确。

UniRL 探索了通过监督学习和强化学习使统一多模态模型自我改进[34]。Lumina-DiMOO 的 Self-GRPO 针对同一提示生成多张图像，将提示中的实体、关系、数量和颜色转为选择题，由模型理解分支作答，并以正确答案数量构造组内奖励[21]。其训练联合生成目标、理解目标和 KL 正则，为控制 4096 个视觉位置带来的显存，只在部分扩散时间步反向传播。与只给一个整体相似度相比，问答反馈能够指明计数、绑定或关系中的具体错误；与外部视觉语言模型相比，它复用统一主干。然而，当前生成指标提升只能证明这种反馈对生成有效，不能单独证明理解分支本身提高。

内部自验证有三类可靠性风险。第一，模型可能根据提示先验猜答案，而没有真正读取图像；可通过无图输入、交换图像、遮挡区域和反事实问题检验图像证据是否改变判断。第二，若生成和评价分支同步更新，奖励标准随策略变化，模型可能学会产生便于自身判对、却不符合外部观察者的模式；冻结评价器能稳定标准，却又无法适应新的生成分布。第三，结构化问答容易覆盖对象和属性，难以充分评价审美、文字、局部伪影、真实感和多样性。因此，内部反馈需要与冻结的外部指标、独立理解集和人工盲评交叉验证，并报告置信度校准，而不能把自评分当作客观真值。

在参数保持不变时，另一种提高生成质量的途径是增加推理计算，即 test-time scaling。连续扩散中的代表工作从扩展初始噪声候选、以奖励或价值函数筛选、在中间状态搜索以及反思式迭代等方向展开[35–38]。最简单的 best-of-N 为同一提示完整生成 N 张图像再选择最好结果，容易实现和并行，但主模型成本随 N 近似线性增长；若每条候选又尝试 T 种细化设置，朴素组合需要约 N×T 组生成。树或分层搜索在中间状态剪枝，把预算集中给高潜力分支，却面临不完整图像难以评价的问题：越早剪枝越能节省计算，评价噪声和误删风险也越大。

dMLLM-TTS 将离散扩散的推理扩展分为轨迹探索和迭代细化两条轴[39]。轨迹探索扩大初始结构假设，迭代细化增加保留轨迹的恢复深度；其自验证把文本—图像一致性转化为视觉问答，并用模型自身理解分支评分。分层轨迹搜索先探索多个结构，再保留固定宽度 K 的候选继续细化，避免对所有 N 个候选执行全部 T 种后续配置。在 K 视为固定且只统计主模型前向的预算模型下，所需 NFE 可由朴素组合的量级 O(NT) 降为近似由探索与细化相加的 O(N+T)。这一表述依赖固定保留宽度、共享计算和具体实现，验证问题生成、问答、解码、数据搬运与不规则批处理并未包含在该渐近记号中。

CVPR 版本在 Lumina-DiMOO、MMaDA 和 Muddit 上报告了质量增益，并在其设定下相对线性搜索获得最高约 6 倍的主模型前向计算效率改善[39]。这一“最高值”只应作为论文特定配置的结果，不应改写成普遍端到端加速。扩展版 dMLLM-TTS v2 又加入多种采样调度器，并聚合提示遵循、审美和质量信号[40]。所附在审稿件在 T=32、N=32、K=8 的代表设置下报告：线性轨迹搜索 GenEval 为 0.91，分层搜索为 0.93；在相近总体得分下，后者 NFE 约为前者五分之一。由于 [40] 尚未形成正式卷期，这些数字应明确写成“所附在审稿件报告”，并与正式发表结果分开表述。

自反馈训练和推理搜索虽然发生在不同阶段，却共享同一瓶颈：价值信号是否可信。训练时错误反馈会改变参数并长期积累，搜索时错误评分会提前剪除可恢复轨迹。完整图像适合评价细节和审美，中间状态更适合判断粗略对象与布局，验证粒度应随生成阶段变化。多评分器可以覆盖语义、感知和偏好，但简单加权会受量纲与相关性影响，还可能增加足以抵消主模型节省的计算。评价这一路线应同时测量验证器与人工判断的相关性、早期误删率、候选多样性、主模型 NFE、验证 NFE、端到端时延和峰值显存。

现有证据说明，统一模型的理解能力既可形成训练奖励，也可用于推理时选择轨迹[21, 34, 39–40]。尚未解决的问题是内部评价在中间生成分布上的校准、共享偏差如何被独立发现，以及搜索收益如何避免在每个请求中重复支付。前两项决定“选得准不准”，后一项连接推理扩展与少步学习。

### 1.6 少步生成、扩散蒸馏与搜索经验迁移

蒸馏的目标是将多步教师的生成能力迁移给少步学生。连续扩散已形成至少三种代表性路线。渐进蒸馏每轮让学生用一步逼近教师的两步确定性更新，再反复将步数减半[6]；一致性模型要求同一概率流轨迹上的不同噪声状态映射到一致的干净样本，可通过教师蒸馏或直接训练获得一步及多步生成能力[7]；分布匹配蒸馏不要求学生逐点复制某条教师轨迹，而是利用真实与生成分布的得分差异训练一步生成器[8]。三类方法分别强调局部轨迹压缩、跨时间一致性与边缘分布匹配，说明“少步”并不存在唯一监督对象。

这些连续方法不能不加改变地用于掩码离散扩散。连续状态之间具有可定义的数值距离和确定性求解轨迹，而离散学生一步可能同时决定大量类别 token；教师后续预测又依赖已经揭示的上下文。若学生直接匹配最终完整图像，监督稀疏且高方差，也难以定义像素或 token 的一一对应；若逐轮模仿教师，则可能保留原有采样步数；若只匹配每个位置的边缘类别分布，又会忽略对象结构和位置间相关性。少步离散生成还面临训练—推理状态偏移：教师轨迹上的干净中间状态与学生实际产生的错误或不完整结构不同，学生在未见状态上继续生成时可能积累误差。

Di[M]O 通过在离散 token 概率空间匹配多步教师与一步学生的输出分布，将掩码图像生成模型蒸馏为一步生成器[41]。答辩材料在一个 Meissonic 设置中给出一步学生与多步基座的质量差距；由于该数值未从可访问全文独立核到具体表格，本报告不把它作为正式定量证据。该材料只提示极端步数压缩可能带来语义损失，不能推出一步模型在一般情况下必然弱于教师。近期工作进一步尝试学习潜空间受控动力学来跨越多步掩码状态[42]，反映出研究重点正在从“删除步骤”转向“学习跨步状态转移”。由于 [42] 为 2026 年预印本，相关优势仍应按公开稿件的范围描述。

一步生成具有最低同步轮数，却可能把全局布局和局部纹理压在同一高难度决策中。少数步生成提供另一种折中：前几步建立可补全结构，后几步在结构条件下恢复属性与细节。这里的关键不只是给总步数设定一个较小值，而是决定学生学习什么。若监督对象是教师终态，学生可能复制高分样本而丢失分布覆盖；若监督对象是教师中间 token 分布，需要保证教师和学生处在可比状态；若监督来自搜索最优样本，还会产生选择偏差，因为高分尾部受到验证器偏好影响。评价少步方法应同时比较固定步数下的质量、固定质量下的真实时延、输出多样性、教师调用成本和训练数据生成成本。

推理搜索可以为蒸馏提供比单条教师轨迹更丰富的信息。候选组不仅包含“哪张图最好”，还包含哪些部分结构在多次补全后保持高回报、哪些状态容易被教师修复、哪些提示需要更宽探索。现有测试时扩展主要在每次请求中使用这些信息[35–40]，现有离散蒸馏则侧重压缩教师生成过程[41–42]，二者的监督对象和计算账本通常分开。若只将搜索选出的最终图像作为训练目标，学生可能复现验证器偏好而不知道分支优劣；若保留候选的相对价值及条件补全分布，才可能把预算选择与跨步生成联系起来。

截至 2026 年 10 月、在本文所覆盖的公开文献和用户提供材料范围内，尚未见一种离散扩散多模态生成方法同时系统处理以下三点：以多次条件补全估计部分结构的期望价值；在学生实际访问状态上构造跨步教师监督；以同一质量—效率协议验证搜索收益是否转化为少步端到端收益。这个空白必须保持范围限定，不能表述为所有搜索与蒸馏结合均无人研究。后续若检索到处理其中两项或三项的工作，应进一步缩小创新边界，并把它纳入同预算比较。

### 1.7 评价体系、可比性与证据边界

生成优化至少需要同时评价语义遵循、感知质量、多样性、理解能力、系统效率和训练稳定性，单一总分不能覆盖全部目标。GenEval 以对象为中心，将单对象、双对象、计数、颜色、位置和属性绑定拆分评价，适合诊断组合语义[1]；DPG-Bench 使用更稠密的提示考察复杂文本遵循，其来源工作为 ELLA[2]。ImageReward、HPSv3、DeQA 和 Unified Reward Model 分别从人类偏好或感知质量角度提供补充[33, 43–45]。这些自动指标并非可互换：对象检测式指标对构图与真实感不敏感，CLIP 类相似度可能忽略计数和绑定，偏好模型可能奖励特定风格，质量回归模型又未必反映文本一致性。因此，应按能力维度分别报告结果，并避免把训练使用的奖励同时作为唯一测试指标。

统一模型还必须检查“生成提高而理解退化”。POPE 通过不同负样本策略询问图像中是否存在某个对象，适合测量对象幻觉及 yes-bias[46]；MMBench 以多项选择和循环评测覆盖细粒度感知与推理，可提供较广的理解能力剖面[47]。两者功能不同：POPE 是针对对象幻觉的窄而敏感诊断，MMBench 是较宽的综合评测。现阶段保留这两项已经能够对应“幻觉”和“总体理解”两个问题，无需仅为增加数量同时罗列 SEED、MMMU 等更多基准。若后续研究强调专家知识推理、视频或文本密集图像，再根据实际接口补充相应基准。理解评测应使用优化前后同一模型、提示模板和解码配置，并同时报告准确率、校准及无图/交换图像对照，判断模型是否真正利用视觉证据。

对自反馈和多目标奖励，还需要验证评分器本身。应在独立人工标注子集上测量内部问答得分、外部奖励与人类判断的相关性，记录不同错误类型的假阳性和假阴性。训练时使用的问答模板、奖励模型和提示集合不能与最终测试完全重合，否则提升可能来自奖励记忆而非泛化。若多种奖励经加权组合，应报告各分量的尺度、相关性和消融；如果只给加权总分，无法判断模型究竟改善了语义、审美还是迎合某一评分器。人工评价应采用盲评、随机呈现和明确的胜负/平局规则，并报告样本数与置信区间。

效率评价必须建立完整计算账本。NFE 便于统计主模型前向次数，却不能涵盖提示解析、问题生成、视觉问答、多个奖励模型、VAE/视觉 tokenizer 解码、缓存维护、CPU—GPU 数据搬运和动态批处理。分层搜索可能降低主模型 NFE，却因分支长度不同降低 GPU 利用率；缓存减少重复计算，却提高峰值显存；少步学生减少同步轮数，但若每步扩展更多候选，其时延不会与步数同比下降。因此，至少应报告相同硬件和软件环境下的单图延迟、固定批量吞吐、峰值显存、主模型 NFE、验证 NFE 和训练 GPU-hours，并分别在固定预算下比较质量、在固定质量下比较延迟。只有端到端测量支持时才使用“实际加速”，其余应写为“NFE 降低”或“理论主干计算减少”。

稳定性与多样性同样属于证据链。奖励优化可能因组内样本分数接近而缺乏有效优势，也可能因奖励差异过大导致策略快速偏离参考模型。应使用多个随机种子报告均值和方差，并监控奖励方差、有效样本量、策略 KL、裁剪率、梯度范数及失败率。对于生成结果，还需检查提示间与同提示多样性，避免以模式收缩换取自动指标。少步蒸馏应区分教师生成数据成本与学生部署成本；推理搜索则应说明候选能否并行及批量变化。没有这些信息，质量—效率结论难以复现。

跨论文数值只适合说明趋势，不宜拼接为统一排行榜。即使使用同名底座，不同 checkpoint、分辨率、CFG、采样器、提示集、检测器版本和随机种子都会改变 GenEval 或 DPG-Bench。用户材料中 Lumina-DiMOO 在不同稿件中的基础分存在差异，合理原因可能是模型和协议更新，但不能用一个论文的基线与另一个论文的方法分数直接相减。可信比较应优先采用同一论文同一表中的增量；若跨论文比较，必须重新运行统一评测代码，并公开配置与 checkpoint。

多参考图像创作与编辑可作为文生图之外的泛化边界。MICE-Bench 考察多参考条件下的主体保持、指令执行、非目标区域保护和关系组合[48]，这些维度能够检验价值分配是否仍然有效：生成模型不仅要提高目标区域质量，也要避免改动无关内容。该基准只有在后续实验确实包含多参考编辑时才应留在评价体系中，否则宜移到“前期工作基础”。TR-PTS 研究分类模型中的任务相关参数与 token 选择[49]，与本课题有高效选择的思想联系，却不是离散生成轨迹或信用分配的直接证据，应放入第六部分说明研究经验，不宜在文献综述中承担核心论证。

最后，证据等级需要在文字中可见。正式发表论文可写“论文报告/结果表明”，公开预印本应写“作者在预印本中报告”，未发表在审稿应写“所附在审稿件报告”，仅来自答辩材料的录用或审稿状态应写“答辩材料标注”。实验数值可以作为阶段性依据，但不能因稿件真实存在就视为已获独立验证。对个人贡献也应区分本人主导、主要负责和团队共同成果，使研究基础与学术归属保持一致。

### 1.8 国内外研究格局、现有空白与本课题定位

从全球研究脉络看，图像生成先后经历连续扩散质量提升、离散视觉表示与序列建模、统一多模态架构、奖励后训练和推理时扩展等阶段。DDPM、潜扩散、VQ-VAE/VQGAN、MaskGIT 和 D3PM 奠定了连续与离散生成基础[3–4, 9–10, 12–13]；Emu3、Show-o、Janus-Pro 等展示了不同程度的理解—生成统一[16–18]；近年的 MMaDA、Muddit、Lumina-DiMOO 和 LaViDa-O 则把统一目标进一步推进到多模态掩码扩散[19–22]。与此同时，连续扩散中的奖励优化、偏好学习、推理扩展和少步蒸馏提供了可借鉴的优化框架[6–8, 28–29, 35–38]。这些方向并非线性替代关系，而是在表示空间、概率分解、在线预算和离线训练成本上采取不同权衡。

国内高校和研究机构在统一离散扩散方向已有多项代表性参与，相关成果覆盖基础模型、视觉指令、统一生成理解、自验证搜索与层次强化学习[15, 19–21, 25, 39–40]。正式论文中如需使用“国内牵头”或“国内团队”等表述，应依据论文首页的第一作者、通讯作者和单位逐篇核对；跨机构合作不能仅凭作者姓名或项目印象分类。与其简单按地域罗列，更有信息量的比较是：部分工作侧重建立统一底座，部分工作侧重训练后对齐，另一些工作关注冻结模型的推理预算。国内相关工作在全离散统一模型与自验证方面形成连续成果，为本课题提供开源底座和真实实验经验，也意味着该方向版本迭代快、相近方法多，创新声明必须保持严格检索边界。

第一项研究空白是离散生成的信用粒度仍不充分。随机重掩码、真实轨迹和全掩码代理分别在覆盖度、忠实度与成本上取舍[15, 30–31]，但多数方法仍以图像级优势更新大量 token。层次权重开始区分结构和细化阶段，却依赖固定比例或生成次序先验。现有证据尚未回答生成秩、预测熵、空间结构和反事实奖励变化之间是否存在稳定关系，也缺少在统一预算下对概率偏差、训练内存和最终泛化的联合比较。

第二项研究空白是推理预算分配受到验证噪声限制。best-of-N 对完整结果评价较可靠，但重复生成成本高；中间状态剪枝节省主模型计算，却可能因图像不完整而误删后续可恢复轨迹[35–40]。内部视觉问答能够检查对象、数量和关系，但其在自身生成分布上的校准、对文本先验的依赖及与外部评价的相关性尚未充分建立。现有工作多报告质量和主模型 NFE，验证器成本与真实延迟的完整账本仍不统一。

第三项研究空白是生成—理解闭环的收益与风险尚未同时验证。Self-GRPO 等工作说明理解分支可以构造有效生成奖励[21]，但生成指标提升不能替代理解基准；评价器共同更新又可能产生非平稳标准。当前证据需要从“能否自评分”推进到“自评分何时可信”：内部奖励应与人工判断、冻结外部指标、POPE 和 MMBench 等独立理解测量共同检验[46–47]，并明确评价器更新方式与失败类型。

第四项研究空白是在线搜索经验尚未充分迁移为少步能力。推理搜索能够发现高价值候选，却在每个请求中重复支付探索和验证成本；一步蒸馏减少在线步骤，却可能丢失结构、细节和多样性[39–42]。连续扩散的轨迹压缩、一致性和分布匹配提供了三种监督视角[6–8]，但离散模型还要处理并行 token、条件可见集合和学生状态偏移。在本文检索范围内，尚缺乏把部分结构的期望补全价值、学生访问状态上的跨步监督及端到端效率验证放进同一框架的系统研究。

上述四项空白可由一个共同视角连接：价值信号作用于不同尺度。token 尺度决定训练时更新哪些决策，轨迹尺度决定推理时继续计算哪些分支，反馈尺度决定由谁判断输出，步数尺度决定哪些中间计算可以被学生跨越。把四者放在同一质量—成本协议下研究，有助于避免多个算法的简单堆叠，也使每项结论都能通过独立消融检验。该定位来自现有方法的比较，不预设“早期 token 必然代表结构”或“内部反馈必然优于外部评价”，而是把这些主张转化为可证伪假设。

本课题已有的 HT-GRPO、dMLLM-TTS 与 Self-GRPO 分别为层次信用、轨迹搜索和内部反馈提供阶段性证据[15, 21, 39–40]，粗到细少步生成则构成后续需要完成的环节。正式开题报告应继续区分证据状态：dMLLM-TTS 为已正式发表工作[39]；Lumina-DiMOO、Sketch Then Paint 按公开预印本身份引用[15, 21]，录用或审稿状态若仅由答辩材料支持，应注明信息来源；dMLLM-TTS v2 为所附未公开作者稿[40]；答辩材料标注其处于 TPAMI 在审阶段，不能写成已发表期刊论文。Lumina-DiMOO 的统一底座属于团队成果，本人主要负责的 Self-GRPO 可作为个人研究基础，但不应把整个底座模型归为个人独立成果。

从学术意义看，本课题关注非固定生成顺序中的层次结构、终局奖励到并行 token 的信用传递、内部评价在生成分布上的可靠性，以及搜索经验向少步学生的迁移。这些问题共同指向离散并行生成的价值建模。即便某项顺序先验只在部分提示或底座上成立，明确其有效范围和失败条件也能深化对生成机制的理解。从工程意义看，统一报告固定预算质量、固定质量时延、独立理解指标、人工偏好与稳定性，可以把“指标提高”转化为可复验的质量—效率结论，为交互式创作和多参考编辑等高约束应用提供更可信的部署依据。

## 二、课题研究目标、主要研究内容和拟解决的关键问题

### 2.1 总体研究目标

本课题面向生成与理解统一的离散扩散多模态大模型，研究有限计算预算下生成决策的价值估计、计算分配与能力迁移。给定文本条件 c，以 z_t 表示第 t 个去掩码状态，以 a_t＝(S_t，y_t(S_t)) 表示该步动作，其中 S_t 是本步选择恢复的位置集合，y_t(S_t) 是这些位置上的视觉 token 类别，完整轨迹记为 τ＝(z_0，a_0，…，z_T)，终局图像为 x＝D(z_T)。由与训练信号解耦的指标和人工评价共同界定终局效用 R(x，c)；模型自身问答或质量分数记为代理效用 R̂(x，c)。代理效用必须经独立证据校准，不能直接视为客观真值。

在给定后续策略 π 下，中间状态的条件补全价值定义为 V^π(z_t,c)=E_π[R(x,c)|z_t,c]。它回答“给定当前文本、可见 token、掩码状态和剩余预算，继续生成最终能够取得多高效用”。单个位置或类别决策的贡献以保留、重掩码或替换该决策前后的条件价值差近似。生成秩、预测熵、跨步稳定性和空间信息只是估计该贡献的候选特征，是否具有超出随机分组和单一置信度的增量信息，需要由反事实干预和同预算对照验证。

总体目标是在预先规定的计算预算 B 下提高 E[R(x，c)]，同时使各项独立理解指标 U_k 和多样性 D 不低于相应基线减去预设非劣界，即满足 E[C(τ)]≤B、U_k≥U_k(基线)−ε_k、D≥D(基线)−δ。计算成本 C 同时包含主生成模型、临时补全、问题生成、视觉问答、外部评分、图像解码和系统调度开销。ε_k 与 δ 在查看正式测试结果前，根据基线重复实验、测量波动和应用可接受损失确定并冻结。若采用多目标加权效用，权重在测试前固定，各分量仍单独报告。

四项研究围绕同一条件价值形成“信号校准—训练与推理双路径—能力迁移”的接口关系。研究内容三构造并校准代理效用，输出阶段内冻结或慢更新的目标评价器；研究内容一利用经校准的终局反馈估计 token 边际贡献，输出结构概率、信用权重和改进策略；研究内容二估计部分状态的继续生成价值，决定轨迹扩展、剪枝和停止，输出候选状态、相对价值、保留标签、采样调度与后续回报；研究内容四以结构先验、候选组和教师条件转移为监督，将在线价值判断和预算规律迁移到单轨迹少步学生。每一环节可独立检验，最终通过交叉消融判断接口是否真正提供互补信息。

### 2.2 主要研究内容

#### （1）生成层次感知的强化学习优化

研究非固定去掩码顺序中位置选择与 token 类别预测的信用分配。依据真实 rollout 中的生成秩、预测熵、跨步稳定性和少量反事实补全结果，学习提示相关的结构概率；在匹配 rollout 数、反向 token 数、优化步数和训练 FLOPs 的条件下，对图像级组内优势进行动态加权。全掩码上下文仅用于构造低成本的提示条件代理比率，不把它解释为真实行为轨迹的重要性比。该研究输出结构概率、token 权重和经校准的生成策略，并明确顺序先验成立与失效的提示范围。

#### （2）自验证驱动的推理搜索优化

研究不完整状态的条件补全价值估计和推理预算分配。探索阶段生成具有不同随机种子、温度或调度器的结构候选；评价阶段以同预算临时补全形成可解码的 probe image，再由统一模型的冻结目标评价器进行结构化问答；剪枝阶段依据置信区间延迟淘汰不确定候选，并保留固定探索配额。主设置不依赖额外大型多模态验证器；可选轻量质量评分器和所有临时补全、验证及解码成本均计入端到端账本。该研究输出候选状态、相对价值、保留或淘汰标签、调度信息和后续真实回报，供少步学生使用。

#### （3）生成与理解协同的可校准自反馈

研究内部语义反馈是否真实依赖图像证据，以及该反馈用于参数更新时是否稳定。由提示得到的对象、数量、颜色与关系答案只用于评价生成结果是否满足条件，不直接作为错误生成图像的理解训练标签；理解分支仅使用独立可靠标签或经人工、外部工具确认的样本更新。训练维护在线生成策略和阶段内冻结的目标评价器，对奖励路径停止梯度，并用无图、错图、遮挡和反事实问题检测提示泄漏。该研究输出带可靠性界限的代理效用和冻结或慢更新评价器，为 token 信用和轨迹排序提供统一信号。

#### （4）粗到细蒸馏与推理加速

研究将搜索候选的相对价值和教师条件转移迁移到单轨迹少步学生。对同一提示产生 H 个结构候选，每个候选由冻结教师独立补全 M 次，用经校准的终局效用均值估计条件价值，并保留低价值候选学习决策边界。学生在自身访问状态上同时蒸馏教师的新增位置分布和相应 token 软类别分布；对于低置信可见 token，比较固定与允许重掩码纠错两种机制。推理主设置只运行一条学生轨迹，以 K_s 步形成结构、K_r 步完成细化，并在固定总预算 B=K_s+K_r 下研究阶段分配。

四项内容共享同一状态、动作和价值接口，但在实验上保持可分离。内容三提供代理效用及其可靠性界限；内容一检验该效用能否合理分配到位置与类别决策；内容二检验中间状态价值能否在扣除验证成本后改善预算分配；内容四检验搜索相对偏好和教师跨步转移能否被单轨迹学生吸收。只有接口信息在同等计算预算下带来可重复增量，才认为相应环节支持总体主线。

### 2.3 拟解决的关键问题

第一，生成次序和不确定性是否包含可用于 token 信用分配的增量信息。本课题不预设“早生成 token 等同于结构 token”，而检验生成秩、预测熵、跨步稳定性、空间连通性与反事实价值差的关系。在固定采样数、更新次数和训练计算下，与随机分组、均匀信用、仅按熵或仅按置信度加权的基线比较。若动态结构概率不能提高对干预敏感度的预测，或最终增益可由额外更新预算完全解释，则该假设不成立，生成次序只能作为经验调度特征。

第二，含噪内部评价能否在不完整状态上可靠排序轨迹，并在计入验证开销后改善质量—计算折中。研究分别测量中间价值排序相关、top-K 召回、优质轨迹误删率、校准误差和阶段稳定性。若内部评价在早期状态上的排序接近随机，或临时补全、问题生成和视觉问答的额外时延抵消主模型前向节省，则不把 NFE 降低解释为实际加速，并限制自验证只在可靠阶段使用。

第三，统一模型的理解能力能否形成依赖图像证据、可校准且在训练中保持稳定的生成反馈。研究通过无图输入、错图交换、图像遮挡、反事实问题和人工标注子集，检验评价器是否真正读取图像；通过冻结目标评价器、慢速同步和独立理解数据控制奖励非平稳与循环监督。若内部奖励与独立判断的相关性持续下降、理解能力退化超过预设非劣界，或错图与无图条件仍获得相近得分，则不能认为形成了可信协同。

第四，搜索所得相对价值和教师条件转移能否迁移为单轨迹少步生成能力。学生使用真实搜索候选组、保留或淘汰标签、校准价值和教师后续补全，同时学习下一阶段应恢复的位置及其类别分布。若联合方案相对纯蒸馏、纯结构强化或随机候选蒸馏没有稳定增量，若质量损失超过非劣界，或只减少 NFE 而未改善端到端时延，则搜索经验迁移假设不成立，应退回分阶段训练或把结论限定为核心计算降低。

## 三、拟采取的研究方法、研究方案及其可行性分析

### 3.1 总体技术路线

首先在可获得权重、代码和评测条件的代表性离散扩散多模态模型上建立统一实验接口，固定数据划分、分辨率、提示集合、解码方式和评测实现，复现基础推理、均匀信用、随机剪枝、best-of-N、代表性后训练与蒸馏基线。所有训练、搜索和蒸馏过程统一记录状态 z_t、位置集合 S_t、类别分布、生成秩、预测熵、跨步变化、采样调度、终局结果和成本，使不同研究在相同状态—动作定义下交换数据。

第二步建立价值信号可靠性基线。终局效用由与训练信号解耦的自动指标和人工评价共同刻画，统一模型产生的结构化问答分数只作为代理效用。通过无图、错图、遮挡和反事实问题测量图像依赖性，通过人工标注子集和独立评分器测量排序相关与校准误差。主训练方案使用阶段内冻结的目标评价器并对奖励路径停止梯度；理解分支只在独立可靠标签上更新，达到预设校准条件后再慢速同步。该步骤输出经校准的目标评价器及其适用阶段。

第三步分别验证训练端信用分配和推理端预算分配。训练端从真实 rollout 提取生成秩、熵、稳定性和反事实干预结果，在相同更新预算下比较均匀、固定层次和动态层次信用；全掩码上下文只构成低成本代理目标，另以真实中间状态测量偏差。推理端以同预算临时补全观察中间状态，依据置信区间执行延迟剪枝、保留探索配额和阶段感知复核；搜索成本同时统计主模型、临时补全、验证、解码与调度开销。

第四步构建搜索记录集和粗到细学生。搜索模块对同一提示输出候选结构组、相对价值、保留标签、采样调度及教师后续补全轨迹。学生从自身访问状态出发，一方面通过组内排序或相对优势学习高价值结构选择，另一方面同时蒸馏教师的下一阶段位置分布和新增位置类别分布。主部署设置仅保留一条学生轨迹，在固定总步数内完成结构形成与细节补全；多候选模式仅作为增强设置单独报告。

最后开展跨环节消融与外部有效性验证。依次移除校准评价器、动态 token 信用、搜索候选偏好、位置监督和类别监督，判断各接口的独立贡献；先在一个底座完成主结论，在资源和阶段门允许时再验证第二底座。若代理评价未达到可靠性门槛，则不进入联合训练；若联合损失长期冲突，则转为先蒸馏后强化；若 NFE 降低未转化为时延改善，则只报告算法计算变化。

### 3.2 研究内容一的方法方案

设第 t 步状态为 z_t，当前掩码集合为 M_t，本轮新增恢复的位置集合为 S_t，位置上的类别动作记为 y_t(S_t)。掩码调度器在主比较中固定为不训练的环境规则；若改用可学习调度器，则位置选择和类别预测分别建模并单独消融，避免把日程收益错误归于 token 信用。对同一提示采样 G 条完整轨迹，记录生成秩、阶段内置信度、跨阶段条件熵、跨步 logit 变化和空间位置。这里区分两类量：早期阶段因上下文较少可具有较高平均条件熵，而同一阶段内被优先固化的位置仍可能是相对高置信位置。

结构概率 s_i 表示位置 i 在当前提示和轨迹中承担高影响决策的估计概率，不等同于对象轮廓标签。其候选特征包括生成秩、预测熵、跨步稳定性、对象或边界区域统计，以及对该位置执行保留、替换或重掩码后条件补全价值的变化。对同一结构使用配对随机数完成多次后续补全，以降低反事实比较的随机方差；位置选择贡献和类别选择贡献分别分析。组内终局奖励标准化为图像级优势 A_g，token 权重在 batch 内归一化到平均值 1，使不同信用方案具有可比的平均梯度尺度。

真实 rollout 动作依赖部分可见状态 z_t，而全掩码代理在仅文本可见的上下文中计算 r̃_i=p_θ(y_i|c,[M]^N)/p_ref(y_i|c,[M]^N)。该比值删除了真实历史条件，也没有完整包含“选择哪些位置先恢复”的概率，因此只是提示条件代理比率，不是标准轨迹重要性比；相应裁剪目标也不作无偏 on-policy 策略梯度解释。其目的在于以较低存储开销避免未来可见 token 的直接泄漏。校准实验从真实轨迹抽取状态，比较全掩码、部分历史上下文和真实轨迹条件下 log-ratio 的 Pearson/Spearman 相关、符号一致率、裁剪率、KL、显存与时间；若代理梯度长期不一致，则提高部分上下文或真实状态目标的权重，并把结论限定为经验 surrogate。

公平对照包括均匀信用、随机同规模 token 子集、仅生成秩、仅熵、固定层次、动态层次、随机重掩码和真实轨迹估计。各方法匹配 rollout 数、奖励调用、优化步数、参与反向的 token 数、训练 FLOPs 和目标 KL。主要机制证据为结构分数对高干预敏感 token 的 AUROC/AUPRC、与价值差的 Spearman 相关及分提示类型置信区间；注意力或熵图只作辅助。若最终增益可由额外更新次数或更大梯度完全解释，便不把结果解释为层次信用有效。

### 3.3 研究内容二的方法方案

搜索由探索、评价、剪枝和细化组成。探索阶段从全掩码状态使用不同随机种子、温度或掩码日程产生 N 个候选；评价阶段不把不可解码的部分 token 直接当作完整图像，而对每个候选使用相同预算的冻结临时补全策略形成 probe image，再由目标评价器回答对象、数量、属性和空间关系问题。若某阶段临时补全方差过高，则推迟评价或只作软排序，不执行硬剪枝。token 状态上的轻量价值头可作为低成本对照，但其训练成本和精度单独报告。

设探索阶段每条候选运行 T_s 步，剪枝区间第 t 步保留宽度为 W_t，T_r 后保留 K 条轨迹至总步数 T；评价候选时的临时补全步数为 L_p(t)。主模型轨迹步成本由四部分相加：N 条候选的探索步、剪枝区间各步的保留宽度、K 条轨迹从 T_r 到 T 的细化步，以及所有候选的临时补全步。端到端成本还包括提示解析、问题生成、各阶段 W_t 次验证、图像解码、数据搬运和动态批处理。文中不再把特定固定宽度设置下的 O(N+T) 简写当作一般实际复杂度；实验同时报告主模型 NFE、验证器等效 FLOPs、GPU-seconds、P50/P95 延迟、吞吐和峰值显存。

搜索需要估计的是状态继续生成后的期望终局效用，而非当前 probe image 的表面得分。对抽样状态独立补全 L 次，以未参与搜索的终局效用均值作为近似参考值，分阶段报告内部评分与该参考值的 Spearman/Kendall 相关、NDCG、top-K recall 和优质轨迹误删率。置信区间较宽的候选延迟决策；高置信低价值候选提前停止；另保留固定探索配额，防止早期评分错误导致模式收缩。

比较对象包括单轨迹、best-of-N、线性完整扩展、同预算随机剪枝、使用同一评分器的均匀预算、冻结外部验证器以及只作上界的 oracle。主方法的语义排序使用统一模型自身的目标评价器；外部大型视觉语言模型仅作上界或对照。若在线使用轻量质量或美学评分器，则明确参数、调用次数、时延和显存并计入总成本。搜索保存候选状态、调度器、内部与外部审计分数、置信区间、保留标签及后续回报，形成研究内容四的训练记录。

### 3.4 研究内容三的方法方案

从提示提取实体—属性—关系约束，并构造答案空间封闭、可程序核验的对象存在、数量、颜色、属性绑定和空间关系问题。评价器只接收生成图像或视觉 token 与问题，不接收原始生成提示和标准答案。由提示解析得到的期望答案用于评价输出是否满足条件，不直接作为生成图像上的理解监督；否则当图像生成错误时，理解分支会被训练为忽略图像并猜测提示答案。理解分支只在独立带标签数据或经人工、外部工具确认的生成样本上更新，短答案问题作为扩展而非主要奖励来源。

训练维护在线生成策略 π_θ 和目标评价器 f̄_ψ。在一个更新阶段内固定 f̄_ψ，由其产生代理奖励并对奖励路径停止梯度；在线理解参数只在独立理解数据上更新。目标评价器仅在 POPE、MMBench、自身生成分布上的人工校验集以及预设校准误差没有恶化时，以低频或指数滑动平均方式同步。冻结、慢速同步和同步更新分别作为主方案、扩展方案和压力测试。无图输入、图像遮挡、图像交换、提示—图像错配和反事实问题用于衡量视觉证据增量；若无图或错图得分接近真实图像，内部评价不进入主奖励。

内部语义、感知质量和多样性分别报告。若训练需要标量效用，各分量先在固定校准集归一化，权重在正式测试前冻结；多样性定义为同提示候选组的特征距离、覆盖率或熵约束，不与单张图像分数直接混合。训练评分器、模型选择指标和最终测试指标预先分离，至少保留一组完全未参与训练、搜索和超参数选择的终局评价。设置无强化学习、外部反馈、冻结自评、慢更新自评、同步自评和混合反馈基线，并在生成改善时同时检验理解非劣性、奖励—人工相关和 reward hacking 失败率。

### 3.5 研究内容四的方法方案

研究内容二为同一提示的 H 个候选逐一保存搜索记录。第 g 条记录包含文本条件 c、中间状态 z_τ(g)、经校准的相对价值 V̂_g、调度器 h_g、保留或淘汰标签 k_g，以及教师后续补全轨迹 τ_g^+。学生首先在同提示候选组内以排序或相对优势学习高价值结构，同时保留少量低价值候选以学习决策边界。用随机候选、仅最优终图、仅教师轨迹和完整搜索记录四种数据构造比较，检验增益是否真正来自搜索信息。推理主设置每个提示只生成一条学生轨迹；多候选增强模式单独报告，不与少步部署结论混合。

对于学生自身访问的结构状态 z_τ，冻结教师 π_φ 独立补全 M 次得到 x_1，…，x_M。条件价值估计为这 M 个结果的代理效用均值，即 V̂(z_τ，c)＝(1/M)Σ_m R̂(x_m，c)，并报告标准误、教师置信度和随 M 变化的估计方差。该量是冻结教师策略下的 Monte Carlo 价值，不等同于学生策略价值；教师低置信或明显分布外补全需要降权。同一结构下的多样性 D(x_m)作为组级正则或约束单独计算，不与单样本语义、质量得分直接平均。

跨步蒸馏同时监督位置选择和 token 类别。给定学生状态 z_t，教师在相同文本、可见 token 和掩码条件下运行到更完整状态 z_s，新增位置集合记为 ΔS_t→s。教师的选择置信度或多轨迹选择频率形成位置目标 q_φ(i|z_t,c)，学生以集合排序损失或 KL 学习哪些位置应先恢复；对 i∈ΔS_t→s，再匹配教师软类别分布 p_φ(y_i|z_t,c)。已有可见位置不重复计入类别损失。另比较严格固定已见 token 与允许低置信位置重掩码纠错，以诊断学生早期错误是否被永久锁定。

总目标由候选排序或结构策略损失 L_rank、位置蒸馏损失 L_pos、类别蒸馏损失 L_tok 和相对冻结参考策略的正则项 L_KL 加权组成；各项按样本或新增位置归一化，权重和 KL 方向在实验前明确。主方案先以蒸馏建立基本补全能力，再逐步增加结构策略权重；同步联合训练和梯度投影只作对照或冲突处理。若梯度长期相反或验证集质量下降，则按预先规则转为分阶段训练。

推理时固定总步数 B=K_s+K_r，比较均分、前多后少、前少后多和不确定性自适应四类预算，并与原多步教师、教师直接截短、一步 Di[M]O 类基线、相同步数普通蒸馏、纯结构强化、先蒸馏后强化和联合方法比较。只有单轨迹墙钟时间或 GPU-seconds 的置信区间支持下降且质量满足非劣界时，才称为实际加速；若只减少 NFE，则结论限定为采样步数或核心前向计算降低。

### 3.6 实验设计与评价

本课题采用“一个预先指定主终点、若干安全性与机制终点”的评价方式，避免在多个自动指标中事后选择有利结果。所有方法在同一底座 checkpoint、图像 tokenizer、分辨率、提示集合、CFG、采样日程和评测代码版本下比较，并记录代码提交、checkpoint 哈希和随机种子。训练奖励或调参使用过的评分器不作为相应实验的主测试终点；最终结论使用未参与训练、模型选择和超参数调整的冻结测试集与独立评价器。

研究内容一以 GenEval Overall 的配对变化为生成主终点，以 DPG-Bench、GenEval 六个子项、独立感知质量和多样性为次要终点。动态信用方法与均匀信用、随机 token 子集、固定层次信用、随机重掩码和真实轨迹估计比较；各方法匹配 rollout 数、奖励调用次数、优化器步数、参与反向传播的 token 数、训练 FLOPs 和目标 KL。token 权重在 batch 内归一化，使平均权重为 1，排除更大梯度尺度带来的混淆。机制验证报告全掩码提示条件代理比率与真实轨迹比率在不同生成阶段的相关、偏差、裁剪率和 KL，并以干预敏感度而非注意力图作为“高价值 token”的主要证据。

研究内容二以质量—计算 Pareto 关系为主终点。在预先固定的质量目标处，检验分层搜索相对线性搜索能否在生成质量非劣的前提下降低端到端延迟；在预先固定的总计算预算处，检验其能否提高独立生成指标。搜索成本分别累计各步保留轨迹的主模型前向数，以及所有进入验证阶段候选的验证调用成本，同时报告估算 FLOPs、GPU-seconds、P50/P95 单图延迟、吞吐和峰值显存。CFG 的条件与无条件计算、动态批处理、问题生成、视觉问答、解码和外部评分均计入端到端结果。比较对象包括单轨迹、best-of-N、线性轨迹搜索、同等预算随机剪枝、使用同一评分器的均匀预算、外部冻结验证器和仅作上界的 oracle；oracle 不用于选择正式测试结果。

中间状态的当前自评分不直接视为轨迹价值。对抽样的中间状态独立补全多次，以独立终局效用的均值近似条件补全价值，按生成阶段报告自验证分数与该价值的 Spearman/Kendall 相关、top-K recall、NDCG 和误删率。若早期自验证不能可靠预测终局回报，则推迟首次剪枝、保留固定探索配额，或使用冻结外部/集成价值估计；不以当前局部图像得分替代可恢复价值。

研究内容三采用生成效果与理解保持两个共同主终点：其一，GenEval Overall 相对同底座和同预算基线的配对变化；其二，POPE 和 MMBench 的预先指定宏平均理解分数满足非劣性。DPG-Bench、独立偏好/质量指标、答案校准误差及各理解基准单项结果作为次要终点。评价分支只接收生成图像或视觉 token 与问题，不接收原始生成提示和标准答案；主要实验使用答案空间封闭、可程序核验的问题，并设置无图、图像遮挡、图像交换、提示—图像错配和反事实问题对照，验证评分确实依赖图像证据。冻结参考评价器或 EMA target evaluator 作为奖励锚点，同步更新评价器只作为对照；所有方案均由同一个冻结审计集监测奖励漂移。

研究内容四以“固定少步预算下的质量非劣性”和“同等质量下的端到端效率提升”为共同主终点。比较原多步教师、教师直接截短采样、一步 Di[M]O 类方法、相同步数普通蒸馏、纯结构强化学习、先蒸馏后强化和联合训练。除 token 类别软分布外，实验同时考察新增位置集合或生成秩的蒸馏；比较固定可见 token 与允许低置信 token 重掩码纠错两种方案。报告 GenEval、DPG-Bench、独立质量与多样性、NFE、P50/P95 延迟、吞吐、显存和训练 GPU-hours。若只降低 NFE 而端到端延迟的置信区间不支持下降，则结论仅表述为“采样步数或核心前向计算降低”，不表述为实际加速。

非劣界在查看正式测试结果前由 pilot 确定并冻结。确定原则同时考虑三项信息：同一基线重复评测的测量波动、独立训练种子之间的方差，以及小规模人工配对评价能够识别的最小实际差异；最终界值不得大于应用上可接受的最大性能损失，也不得因观察到待比较方法的结果而调整。生成质量非劣性要求方法与基线的配对差值 95% 置信区间下界高于 -δ_G；理解保持要求宏平均差值下界高于 -δ_U，且任一单项出现超过预设警戒界的下降时单独报告。效率提升要求延迟或 GPU-seconds 的相对差异置信区间支持下降。pilot 所用提示和样本不进入正式测试集。

统计分析以提示为聚类单位，所有方法尽量共享提示和采样随机种子，使用配对 bootstrap 给出差值及 95% 置信区间。机制级关键实验至少进行三次独立训练；同一 checkpoint 下增加生成随机种子只用于估计采样方差，不能替代训练重复。若完整 8B 训练受资源限制而不能重复三次，则明确把结论限定为该次训练，并同时给出 prompt-level bootstrap，不将其表述为训练稳定性证据。一个主假设只指定一个生成主指标；多个次要指标采用 Holm 方法控制多重比较。人工评价的样本数由先导实验功效分析确定，每对结果由至少三名不知道方法身份的评价者独立判断，随机交换左右位置并允许平局，报告胜率、95% 置信区间和评价者一致性。

实验预先记录以下失败判据。全掩码代理比率若与真实轨迹比率缺乏阶段内相关，停止将其解释为轨迹策略比率，转用部分上下文或真实状态估计；自验证若不能预测条件补全价值，停止早期激进剪枝，转用延迟剪枝或冻结外部/集成验证器；自反馈若在无图或换图对照中仍维持高分，或理解非劣性未通过，则降低其权重并以冻结评价为主；联合蒸馏若质量非劣性未通过或梯度长期冲突，则转为先蒸馏、后结构强化的分阶段方案，并适当增加学生步数。失败结果用于界定方法适用范围，不通过更换主指标或放宽非劣界掩盖。

### 3.7 可行性分析与资源分级

理论上，离散扩散的掩码集合、生成秩、类别分布和中间状态均可记录，能够支持代理比率校准、条件补全价值估计和跨步监督；统一模型同时提供生成与图像问答接口，可用于构造自验证和自反馈。前期成果已在真实的大模型训练条件下验证相关流程：所提供的 HT-GRPO 稿件报告其训练实验使用 8 张 A100-80G，Lumina-DiMOO 材料报告 Stage IV Self-GRPO 使用 8 张 H200。这些配置只作为团队已经实施过相近工作负载的前期证据，不代表后续实验资源已经获批，也不据此承诺相同设备持续可用。

后续研究采用三级资源包络。第一级为机制验证包络：使用较小底座、较低分辨率或参数高效配置，验证代理比率、结构分组、终局价值校准、提示泄漏控制和跨步蒸馏目标是否成立；该阶段覆盖多个独立训练种子，但不用于宣称 8B 模型最终性能。第二级为主实验包络：仅将第一级通过阶段门的最佳配置扩展到一个代表性大模型底座，完成质量、理解、效率、稳定性和人工评价的完整对照。第三级为迁移验证包络：只有主实验达到预设主终点且获得相应计算资源时，才在第二底座、另一分辨率或多参考任务上验证外部有效性；该阶段用于限定可迁移范围，不作为前两级结论成立的前提。

绝对 GPU-hours、最大 rollout 数 G、搜索宽度 N、保留宽度 K、结构候选数 H、每结构教师补全数 M 和训练样本数不在缺少实测吞吐时臆测。正式训练前在目标软硬件上运行固定时长 pilot，记录每次生成、验证、反向和教师补全的墙钟时间、峰值显存及失败率，据此计算三个包络的 GPU-hours 和存储上限，并在实验记录中冻结。预算估算显式包含：强化学习的 G 条 rollout 与反向 token 数；搜索各步保留轨迹数之和及全部验证调用；蒸馏中每个提示约 H×M 次教师补全及学生更新。预算调整只能由资源变化、实现错误或安全停止触发，并保留调整前后的记录，不能根据测试指标临时扩大某一方法预算。

资源分配遵循“先证机制、再做单底座主结论、最后做迁移”的次序。机制验证阶段结束时设置门 M：基础模型和关键基线在统一协议下可复现；训练无持续数值发散；代理量与独立终局效用具有可报告的校准关系；端到端计时与显存测量完成。未通过门 M 的模块不进入大模型主实验，而按失败判据修改或缩小论断。主实验结束时设置门 P：至少一个预先指定主终点通过，所有共同安全终点满足非劣性，且计算未超过冻结上限。只有通过门 P，才进入第二底座迁移验证；未通过时保留完整负结果，转向误差分析或分阶段方案。

主要风险及回退路径如下。若全掩码代理偏差过大，则保留其低成本工程版本，同时把学术结论转向部分上下文与少量真实轨迹校准；若内部验证器存在明显提示先验或共享偏差，则使用冻结外部验证器或内部—外部集成，并把“完全自验证”缩减为辅助信号；若同步生成—理解更新造成理解退化，则冻结评价分支、使用 EMA 锚点或分阶段训练；若少步学生质量下降超过非劣界，则增加细化步数、允许低置信 token 纠错，并从联合训练退回先蒸馏后强化；若只获得机制验证所需资源，则完成机制、统计和单底座证据，将跨底座结论明确列为未验证，而不以低配实验替代原定大模型结论。

可行性还来自已有代码和实验积累，但可复现性以实际产物为准。每项实验保存配置、随机种子、checkpoint 哈希、数据版本、日志、GPU-hours、异常退出和失败案例；对无法公开的模型或数据，至少保留可审计的配置与指标生成脚本。多参考图像创作与编辑仅在第三级资源允许时作为外部有效性测试，不作为本课题通过验收的必要条件。

## 四、课题的创新点

### 4.1 面向生成层次的 token 信用分配

已有基础：前期 HT-GRPO 利用实际去掩码次序构造全局—结构—细化三阶段更新，并在特定底座和同协议实验中观察到相对均匀信用方法的生成语义增益；全掩码上下文的代理比率降低了轨迹缓存需求并避免直接引入未来可见 token。

现有不足：固定结构比例和固定权重不能适应提示复杂度；生成得早、高熵或高置信并不必然意味着对对象布局具有较大贡献。全掩码比率还丢失真实历史和位置选择事件，只能视为有偏 surrogate。现有最终分数不足以区分增益究竟来自结构信息、额外更新预算还是代理目标的正则化作用。

拟新增工作及预期创新：以生成秩、熵、跨步稳定性、空间信息和反事实条件价值差学习提示相关的结构概率，分别估计位置选择与类别预测的贡献；在相同训练预算下与随机、均匀和单特征信用比较，并用真实中间状态校准代理目标。预期创新是把固定顺序启发式扩展为可检验、可自适应的 token 信用估计框架，其成立范围以反事实实验和跨底座证据为准。

### 4.2 统一模型自验证驱动的轨迹预算分配

已有基础：前期 dMLLM-TTS 系列工作已验证，统一模型可把提示遵循转化为结构化问答，并通过分层轨迹探索和筛选改善特定实验协议下的质量—NFE 折中。

现有不足：中间状态不完整，评价器可能依据文本先验而非图像证据排序；临时补全、问题生成和问答验证会引入未被 NFE 完整反映的成本。固定阈值可能在早期误删可恢复轨迹，已有 NFE 结果不能直接推出同倍数墙钟加速。

拟新增工作及预期创新：建立阶段感知的中间状态评价，在固定预算的 probe completion 上测量排序置信区间，对不确定候选延迟剪枝并保留探索配额；完整保存候选状态、调度器、相对价值和后续回报，供少步学生学习。预期创新是将自验证从终局选优扩展为带可靠性估计和完整成本核算的轨迹预算规则，是否构成实际加速由端到端实测决定。

### 4.3 生成—理解闭环中的可校准自反馈

已有基础：前期 Self-GRPO 利用对象、数量、颜色和关系问答形成结构化语义奖励，并在统一模型中观察到生成提示遵循改善；真实 rollout 上的时间步抽样为控制长视觉序列训练成本提供了可行基础。

现有不足：生成分支与评价分支共享参数和偏差，评价器可能根据提示猜答案；若把提示期望答案直接当作错误生成图像的理解标签，还会形成循环监督。同步更新使奖励分布非平稳，单纯生成指标提升不能证明理解能力保持或内部评价可信。

拟新增工作及预期创新：分离在线生成策略与阶段内冻结的目标评价器，对奖励路径停止梯度，并只用独立可靠标签更新理解能力；通过无图、错图、遮挡、反事实问题、人工子集和独立理解基准校准评价器，再研究满足校准门槛的慢速同步与多奖励集成。预期创新是形成带图像依赖检验、奖励稳定化和理解非劣约束的自反馈闭环。

### 4.4 以搜索相对价值和位置—类别联合监督连接结构强化学习与跨步蒸馏

已有基础：前三项研究能够提供结构分组、候选轨迹、内部价值信号和教师后续补全；现有少步蒸馏工作说明多步教师信息可以迁移到更少步骤的学生，为粗到细训练提供了技术起点。

现有不足：只蒸馏最终最优图像会产生高分尾部的选择偏差，普通跨步类别匹配也没有传递“哪些位置应先恢复”的生成顺序。若学生只使用教师状态训练，会面临推理时自身状态分布偏移；若部署仍依赖多候选筛选，则不能证明搜索经验已经固化为单轨迹能力。

拟新增工作及预期创新：在学生真实访问状态上，用同提示搜索候选组的相对价值学习结构决策，并用教师后续转移同时监督新增位置选择分布和 token 类别分布；保留低价值候选学习决策边界，以周期性 on-policy 刷新覆盖学生错误状态。主部署模式只运行一条固定步数学生轨迹。预期创新是把“选择高价值结构”“决定恢复位置”和“预测位置类别”连接到同一学生状态分布，使在线搜索信息能够接受是否转化为少步端到端收益的直接检验。

## 五、计划进度、预期成果

### 5.1 计划进度与阶段门

2026 年 10 月—12 月：统一协议与 pilot。 整理 HT-GRPO、dMLLM-TTS/v2 和 Self-GRPO 的既有实现，在同一数据、采样、奖励和日志接口下复核基础 checkpoint 与关键基线；完成主终点、非劣界确定流程、提示级配对统计、端到端计时和资源测量脚本。开展固定时长资源 pilot，冻结机制验证包络及第一版实验注册表。阶段门 A：基线可运行，数据和指标版本可追溯，成本分解能够复测；未通过则优先修复协议，不进入新方法大规模训练。

2027 年 1 月—4 月：机制验证。 在第一级资源包络内验证全掩码代理比率与真实轨迹比率的关系、生成秩与干预敏感度的关系、中间自验证对终局补全价值的预测能力，以及跨步类别和位置监督的有效性；完成无图、换图、反事实问题等泄漏对照。至少对关键机制进行三次独立训练或重复实验，依据开发集冻结动态分组、剪枝时机、奖励锚点和蒸馏间隔。阶段门 M：关键代理量通过预设校准检查，方法无持续数值发散，且主实验预算能够在拟申请资源上执行；失败模块按 3.6 的回退方案调整，不直接扩展到 8B 主实验。

2027 年 5 月—8 月：单底座主实验。 对通过门 M 的配置，在一个代表性离散扩散多模态底座上完成层次信用、自验证搜索、自反馈和粗到细蒸馏的公平对照。报告生成质量、理解非劣性、NFE、端到端延迟、P95 延迟、吞吐、显存、GPU-hours 和失败类型；完成教师直接少步、普通蒸馏、纯强化、分阶段和联合训练等关键基线。阶段门 P：至少一个预先指定生成主终点通过，相应共同安全终点满足非劣性，且总计算不超过 pilot 后冻结的上限。若联合方法未通过，则保留分阶段结果和失败边界，不进入无约束扩大搜索。

2027 年 9 月—12 月：迁移验证与交叉消融。 在门 P 通过且获得相应资源的条件下，将最佳配置迁移到第二底座或另一分辨率，检验结论对 tokenizer、模型规模和采样日程的敏感性；完成质量—计算 Pareto、生成—理解安全、代理比率校准和中间价值校准四组主表，并开展预先设计的人工盲评。若迁移验证未通过，则把结论限定于主底座并系统分析差异来源；多参考编辑只在资源允许时作为补充，不影响核心验收。

2028 年 1 月—3 月：冻结测试与论文写作。 锁定最终配置后一次性运行正式测试集，完成配对 bootstrap、非劣性检验、多重比较校正、人工评价一致性和失败案例审计；统一前期论文与新增实验的 checkpoint、协议、术语和贡献边界，形成学位论文初稿、可复现实验清单和预答辩材料。阶段门 T：所有主表能够由冻结配置重新生成，结论与置信区间、资源消耗和失败条件一一对应。

2028 年 4 月—6 月：送审、答辩与归档。 根据预答辩和送审意见补充必要的确认性实验，不改变已经冻结的主终点或非劣界；完成论文定稿、毕业答辩、代码与配置归档，并对正式发表状态、个人贡献和参考文献做最终核对。

### 5.2 预期成果与验收方式

本课题预期形成围绕条件补全价值的离散扩散生成优化方法体系，包括层次 token 信用分配、轨迹价值驱动的分层搜索、带冻结锚点的生成—理解自反馈，以及同时蒸馏位置日程和 token 分布的粗到细少步生成。前三项既有成果在统一协议下复核和补足机制边界，第四项形成新的方法与实证结果。每项结论均对应可重新运行的配置、checkpoint 哈希、评测脚本、计算成本和失败案例，不以单张示例或单一奖励分数作为验收依据。

研究内容一的验收证据为：在匹配训练计算和平均梯度尺度后，层次或动态信用相对均匀信用的 GenEval Overall 配对差值及 95% 置信区间；代理比率与真实轨迹比率的分阶段校准；生成秩/结构分数对干预敏感 token 的预测能力。若质量提升未通过主终点，但得到稳定的失效场景和代理偏差证据，则作为机制边界报告，不宣称动态信用普遍有效。

研究内容二的验收证据为：包含生成与验证开销的完整质量—计算 Pareto 曲线；在预先指定质量目标处的非劣性和端到端成本差；中间价值预测的相关、top-K recall 与误删率。只有墙钟延迟或 GPU-seconds 的置信区间支持下降时才称为实际加速；仅 NFE 下降时交付算法计算压缩结论。

研究内容三的验收证据为：独立生成主指标改善与理解宏平均非劣性共同成立；自评分与人工/外部评价的相关和校准；无图、换图、反事实问题下的图像证据增量；冻结、EMA 和同步评价器的奖励漂移对照。若生成改善伴随理解退化或明显提示泄漏，则不认定为生成—理解协同，只报告受限自反馈结果及回退方案。

研究内容四的验收证据为：固定少步预算下生成质量满足预先冻结的非劣界，同等质量下端到端延迟或 GPU-seconds 下降；位置日程蒸馏、token 软分布蒸馏、纠错重掩码和结构价值估计的消融完整；与教师截短采样、普通蒸馏、Di[M]O 类一步基线、纯强化和分阶段训练公平比较。若少步学生无法满足质量非劣性，则交付质量—步数边界、错误累积分析和可复现负结果，不把降低步数本身作为方法成功。

最终成果包括博士学位论文《面向离散扩散多模态大模型的生成优化方法研究》、相应学术论文或投稿材料、统一评测协议、实验配置与日志、质量—计算 Pareto 数据、生成—理解安全审计和可公开范围内的代码/模型产物。主实验至少在一个代表性底座上完成；第二底座和多参考编辑属于门 P 通过且资源允许时的迁移证据。任何跨模型结论均限定在实际完成的模型、tokenizer、分辨率和任务范围内。

## 六、与本课题有关的工作积累、已有的研究工作成绩

本人已围绕多模态生成、统一离散扩散、推理时扩展、高效训练与评测开展连续研究，已形成支撑本课题的模型、算法和基准基础。

第一，在统一离散扩散底座方面，本人作为共同第一作者参与 Lumina-DiMOO。该工作用全离散扩散框架统一多模态生成与理解，覆盖文生图、图生图和视觉问答。统一模型为团队共同成果，本人主要负责其中 Self-GRPO 自反馈联合优化：以生成图像上的结构化问答正确性形成语义奖励，在控制多步梯度开销的同时联合优化生成与理解目标。答辩材料标注该论文处于 IJCV Minor Revision 阶段。

第二，在推理时扩展方面，本人作为共同第一作者参与 dMLLM-TTS（CVPR 2026），提出自验证反馈和分层轨迹搜索；并作为第一作者开展 dMLLM-TTS v2（答辩材料标注为 TPAMI 在审），扩展多调度器探索和多维评价。相关结果表明，在用户材料所列设置中，分层搜索可用更少前向计算取得更高 GenEval 分数，为本课题的轨迹价值估计和预算分配提供了直接基础。

第三，在离散生成强化学习方面，本人作为第一作者完成 Sketch Then Paint，提出 HT-GRPO 的全局—结构—细化三阶段优化、按生成次序的层次信用分配和全掩码概率比估计。答辩材料标注该工作已被 NeurIPS 2026 录用；所提供论文稿件为较早的匿名投稿版本。该工作在 MMaDA 和 Lumina-DiMOO 上获得稳定的组合语义提升，是本课题研究内容一的主要前期成果。

第四，在评测和高效适配方面，本人作为第一署名共同第一作者完成 MICE-Bench: A Challenging and Comprehensive Benchmark for Multi-Reference Image Creation and Editing（ICML 2026），积累了复杂生成任务构建、指标设计和模型评测经验；作为第一署名共同第一作者完成 TR-PTS: Task-Relevant Parameter and Token Selection for Efficient Tuning（ICCV 2025），通过任务相关参数和 token 选择研究计算分配；答辩材料另标注 Enhancing Test Time Adaptation with Few-Shot Guidance 处于 Pattern Recognition Major Revision 阶段。

答辩材料还列出本人在2025—2026年参与的多项相关成果，包括 CCF A、CCF B 类会议和期刊论文。这些工作使本人具备大规模多模态模型训练、强化学习、离散采样、奖励设计、推理优化、参数高效方法和基准评测等经验。现有统一模型、训练代码、搜索框架及评测流程能够直接支持后续粗到细蒸馏与推理加速研究。
