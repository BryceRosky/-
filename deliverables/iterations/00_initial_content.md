# 面向离散扩散多模态大模型的生成优化方法研究

## 一、国内外研究进展、现状、挑战与意义

### 1.1 研究背景与选题意义

近年来，以大规模预训练模型为核心的人工智能技术已从单一文本建模快速扩展到图像、视频、语音等多种模态。多模态大模型不再仅承担分类或检索等判别任务，而是逐步形成“理解—生成—交互”一体化能力：模型既能读取图像并回答问题，也能根据自然语言合成图像、编辑已有图像，并在多轮交互中持续修正结果。生成与理解的统一有望减少任务专用模块之间的信息壁垒，使一个共享主体模型在不同任务间迁移知识，并为内容创作、视觉设计、智能教育、具身交互和科学可视化等应用提供统一接口。

文生图是检验多模态模型生成能力的代表任务。现有模型已能生成具有较高感知质量的图像，但复杂提示仍会暴露对象遗漏、计数错误、属性绑定混乱、空间关系颠倒和文字细节失真等问题。单纯扩大训练数据、模型参数和训练计算虽然持续提高上限，却面临高质量数据趋于稀缺、训练成本快速增长以及迭代周期过长等现实限制。另一方面，许多失败并非模型完全缺乏相关知识，而是推理时没有把有限计算用于最关键的结构决策，或者训练时未能把图像级反馈准确分配给真正影响结果的 token。因此，研究如何识别高价值生成决策、按价值配置训练与推理计算，并将搜索所得经验迁移为少步生成能力，具有明确的理论价值和工程意义。

本课题聚焦生成与理解统一的离散扩散多模态大模型。与连续扩散在连续潜变量上逐步去噪不同，离散扩散先把图像编码为有限词表中的视觉 token，再从全掩码状态出发，通过多轮并行预测和重掩码逐步补全。该过程没有固定的从左到右顺序，同一个最终图像可以对应多条去掩码轨迹；早期 token 往往决定对象数量、位置和大体布局，后期 token 更多补充颜色、纹理与局部细节。可调的生成顺序、轨迹数量和采样步数既为优化提供了新自由度，也带来了信用分配、搜索预算和蒸馏迁移等新问题。本课题围绕这些问题建立一条从训练后优化、推理时搜索到少步蒸馏的完整研究链路。

### 1.2 图像生成范式与离散表示的发展

扩散概率模型通过逐步破坏数据并学习反向恢复过程，为高质量图像生成建立了稳定的似然学习框架。DDPM 证明了逐步去噪在图像建模中的有效性[1]，潜空间扩散进一步把去噪过程转移到压缩潜变量中，显著降低高分辨率生成成本[2]。SDXL 等工作通过更强的网络、数据和条件编码器继续提升感知质量[41]。连续扩散的优势是细粒度连续表示和成熟的采样理论，但理解任务通常需要另接语言模型或视觉编码器；其固定多步求解也使每次生成需要大量网络前向。

另一条路线把图像压缩成离散视觉 token，再使用序列模型建模。VQGAN 通过向量量化与对抗/感知损失获得可供 Transformer 使用的视觉码本[3]；DALL-E 展示了统一序列建模在文本到图像生成中的可行性[4]。自回归模型按固定顺序逐 token 生成，条件概率定义清晰，但高分辨率图像对应的长序列会带来较大延迟，且早期错误可能沿固定顺序累积。MaskGIT 改用双向 Transformer 迭代预测被掩码 token，并在每轮保留高置信位置、重掩码低置信位置，由此实现并行生成[5]。D3PM 则从马尔可夫转移角度系统化离散状态空间中的扩散建模[6]，后续的比率估计方法进一步拓展了离散扩散的训练与采样形式[7]。

离散掩码扩散兼具序列化表示和并行采样的特点。设图像 token 序列为 z=(z1,…,zN)，初始状态全部为特殊掩码 [M]。第 t 轮模型在文本条件 c 和当前可见 token 上预测所有掩码位置的类别分布，再依据置信度和调度函数保留部分预测，其余位置重新置为 [M]。经过 T 轮后将完整 token 序列交给图像解码器。与自回归固定顺序相比，该过程允许多个位置同时恢复，也允许不同样本形成不同顺序；与连续扩散相比，类别分布、掩码位置和 token 顺序都可直接用于策略优化、搜索和蒸馏。其代价是视觉 tokenizer 的重建误差和语义抽象能力会限制上限，离散类别采样也会产生不可直接套用连续梯度的优化难题。

### 1.3 生成与理解统一的多模态模型

统一多模态模型试图用共享参数处理文本和图像的输入与输出。Emu3 等模型将多模态任务统一为下一 token 预测[11]；Show-o 在同一 Transformer 中结合自回归文本建模与离散扩散图像生成[12]；Janus-Pro 等工作通过数据和模型规模化增强理解与生成能力[13]。这些研究证明了共享表示的潜力，但不同模态仍可能依赖不同注意力模式、生成头或采样算法，统一架构与统一学习目标之间仍有距离。

离散扩散大语言模型的发展提供了更一致的方案。LLaDA 将掩码扩散扩展到语言建模[19]，相关工作表明可从自回归模型迁移能力以降低训练难度[20]，LLaDA-V 则通过视觉指令微调连接图像理解与扩散语言建模[17]。在此基础上，MMaDA、Muddit、LaViDa-O 等模型进一步探索统一的多模态离散扩散框架[14-15,18]。这类模型通过双向注意力和统一掩码目标处理文本与视觉 token，可以在同一主体网络中完成文生图、图像理解及部分编辑任务。与“语言模型+连续扩散头”的混合系统相比，全离散框架为生成和理解之间传递反馈提供了更直接的参数与表示通道。

用户提供的 Lumina-DiMOO 材料给出了该方向的完整实例[16]。该 8B 模型以扩散语言模型为初始化，在文本词表之外加入 8192 个视觉 token，并使用同一个双向 Transformer 和掩码预测目标处理两种模态。其图像 tokenizer 的空间下采样率为 16，1024×1024 图像对应 4096 个视觉 token；模型通过行结束标记保留二维形状信息。训练包含图文预训练、多任务中期训练、监督微调和 Self-GRPO 四个阶段，覆盖文生图、编辑、主体驱动、控制生成、补绘、外扩与视觉问答。在论文报告设置下，基础模型 GenEval 总分为 0.88，Self-GRPO 后为 0.91；颜色和属性绑定指标分别由 0.89、0.76 提升到 0.95、0.82。该结果说明统一模型的理解分支能够为生成提供有用语义反馈，但这些生成指标不能替代理解基准，联合优化是否保持乃至提升理解能力仍需独立验证。

统一模型也暴露出新的效率矛盾。一方面，视觉 token 可并行恢复，理论上比逐 token 自回归更适合图像；另一方面，每轮仍需对长序列执行完整前向，并伴随重掩码和候选评价。Lumina-DiMOO 使用最大 logit 缓存复用稳定 token 的中间表示，在其设置下将 1024×1024 文生图时间从约 45 秒降至约 22 秒，但显存从 38.9 GB 增至 45.9 GB，且缓存属于有损近似[16]。这表明仅优化网络复用不足以解决全部问题，还需要在轨迹、阶段与步数层面决定“哪些计算值得做”。

### 1.4 奖励后训练与层次信用分配

强化学习可直接以提示遵循、审美、质量或人类偏好作为奖励，弥补最大似然训练与最终评价之间的差异。PPO 通过裁剪概率比稳定策略更新[22]；GRPO 使用同一输入下多条采样结果构造组内相对优势，减少对独立价值网络的依赖[21]。在图像生成中，奖励通常在完整图像上计算，而策略动作发生在大量 token 或多次去噪步骤上。因此，如何把终局奖励传回各个生成决策，是生成模型强化学习的核心问题。

将 GRPO 直接用于离散扩散并不简单。随机重掩码方法会从最终图像随机遮蔽部分 token，再计算新旧策略概率比。它能制造多种训练上下文，但保留下来的 token 可能包含真实轨迹中尚未生成的“未来信息”，导致估计上下文与实际采样顺序不一致；同时，同一次更新会混合承担布局和纹理职责的 token。轨迹记录方法则保存真实去掩码状态，条件更忠实，却需要缓存多个中间状态并执行多轮前向，显存与计算开销较高。MaskGRPO 和 TraceRL 分别代表这两类思路[23-24]。更根本的问题是，两类方法常将同一个图像级优势均匀广播给所有 token，忽略了不同生成阶段对最终结果的贡献差异。

《Sketch Then Paint》提出的 HT-GRPO 从生成顺序中提取层次结构[25]。方法记录每个视觉 token 在 rollout 中被恢复的次序，把较早生成、高熵的 token 视为结构集合，把较晚生成的 token 视为细化集合；内循环依次执行全局、结构和细化三个更新阶段，并对结构 token 赋予更高信用权重。为避免未来 token 污染和轨迹缓存，概率比在图像全掩码、仅文本可见的上下文中估计。该估计并不等价于真实轨迹条件概率，但用统一、无图像泄漏的上下文换取了可计算性和较高策略熵。

在该稿件同一实验协议内，HT-GRPO 将 MMaDA 的 GenEval 从 0.56 提升至 0.83，优于 MaskGRPO 的 0.80；将 Lumina-DiMOO 从 0.83 提升至 0.92，优于 MaskGRPO 的 0.88。DPG-Bench 上也观察到同方向增益[25]。消融结果显示，全局—结构—细化三阶段、结构偏置的更新预算以及层次信用权重共同发挥作用。这些结果支持“早期结构决策应获得更多训练信用”的假设，但固定结构比例、固定权重和全掩码概率比仍是经验性设计；生成次序是否总能对应可解释的空间结构、代理估计的偏差如何影响稳定性，仍有进一步研究空间。

### 1.5 生成—理解协同的自反馈优化

统一模型的独特优势在于它可以评价自己的输出。传统文生图强化学习常依赖独立的 CLIP、奖励模型或更强视觉语言模型。CLIP 建立了可迁移的图文对齐空间[8]，ImageReward 等模型进一步学习人类偏好[10]，但外部评价器会增加部署和训练成本，也可能引入与目标模型不一致的偏好。若统一模型能够把文本要求转换为关于对象、数量、颜色和关系的问题，再读取生成图像并作答，就可以形成“生成—提问—理解—反馈”的闭环。

UniRL 探索了通过监督学习与强化学习让统一模型自我改进的方向[26]。Lumina-DiMOO 的 Self-GRPO 则针对离散生成轨迹构造结构化语义反馈：对同一提示生成多张候选图像，依据提示中的实体、关系、数量和颜色生成选择题，使用模型理解分支回答，并以正确答案数量形成组内奖励[16]。训练同时优化生成目标、理解目标和 KL 正则；为控制 4096 个视觉 token 带来的显存开销，只选择部分扩散时间步反向传播。本人在该团队工作中主要负责 Self-GRPO 自反馈联合优化，统一底座模型属于团队共同成果。

自反馈方案仍面临三个风险。第一，模型可能在生成和评价两端共享同类偏差，自认为正确的图像不一定符合外部观察者判断；第二，联合更新会改变评价器本身，使奖励分布非平稳；第三，答案正确数主要覆盖可结构化提问的语义属性，难以充分衡量审美、细节、文本渲染和复杂组合关系。因此，自反馈应与外部奖励、独立理解基准和人工评价交叉验证，并通过冻结/慢更新评价分支、置信度校准或奖励集成降低自我强化偏差。

### 1.6 推理时扩展与轨迹搜索

当重新训练成本过高或模型参数固定时，可通过增加推理计算改善结果，这一方向通常称为 test-time scaling。连续扩散中的相关工作从增加采样步数、扩展初始噪声候选、使用价值函数筛选以及反思式迭代等角度展开[27-30]。简单 best-of-N 为每个提示完整生成 N 个结果再选择最好者，容易并行且实现直接，但计算随候选数线性增长；若每条候选又执行 T 步细化，总成本接近 O(NT)。树搜索能在中间状态剪枝，把预算集中到更有潜力的分支，但过早评价不完整图像可能误删后续可恢复的轨迹。

dMLLM-TTS 针对离散扩散多模态大模型提出两条互补扩展轴：轨迹探索扩大初始假设空间，迭代细化增加每条轨迹的恢复深度[31]。其自验证反馈把文本—图像一致性改写为视觉问答，利用模型自身理解能力给候选打分；分层轨迹搜索先广泛探索结构，再剪除低潜力轨迹，最后细化保留候选，使搜索复杂度由线性笛卡尔组合的 O(NT) 降为近似 O(N+T)。CVPR 版本在 Lumina-DiMOO、MMaDA 和 Muddit 上报告了稳定增益，并报告相对线性搜索最高约 6 倍的前向计算效率改善[31]。

扩展版 dMLLM-TTS v2 进一步引入多种采样调度器，并聚合提示遵循、美学与质量信号[32]。答辩材料给出的代表设置为 T=32、N=32、K=8：线性轨迹搜索 GenEval 为 0.91，分层轨迹搜索为 0.93；在相近总体得分下，后者所需 NFE 约为前者的五分之一。该结果说明轨迹价值估计能够改善质量—计算折中，但 NFE 仅统计模型前向次数，不能直接等同于五倍端到端延迟加速。自验证问答、多评分器聚合、候选调度和内存管理均有额外开销，因而必须同时报告真实时延、峰值显存和吞吐。

推理搜索还存在经验难以沉淀的问题。每次请求都重新扩展和验证轨迹，优质路径的信息没有写回模型参数；部署成本随预算提高而提高。与此同时，中间状态只展示部分视觉 token，验证器对模糊结构的判断噪声较大，搜索策略可能因局部评分误差错过优质轨迹。因此，一个自然方向是把搜索找到的高价值结构、条件补全关系和阶段预算转化为训练监督，使学生模型在较少步骤中复现搜索收益。

### 1.7 少步生成与离散扩散蒸馏

蒸馏旨在把多步教师的知识迁移到少步学生。连续扩散中已形成一致性模型、轨迹蒸馏和分布匹配等路线；对于掩码离散扩散，主要困难是学生一步需要同时预测大量 token，而多步教师的中间条件分布依赖已揭示上下文。若只匹配最终样本，监督稀疏且高方差；若逐步模仿教师，又可能保留原有步数和计算。

Di[M]O 通过匹配教师与学生的 token 级条件分布，将多步掩码扩散模型蒸馏为一步生成器，并允许蒸馏后再用奖励优化[33]。答辩材料引用的同一 Meissonic 设置中，48 步基座 GenEval 为 0.54，Di[M]O 一步模型为 0.43，说明大幅压缩步数伴随可见质量差距。该差距不意味着一步学生必然低于教师，而是表明仅靠一步分布匹配可能难以同时保留全局结构和局部细节。近期工作也开始学习潜空间受控动力学以加速掩码图像生成[34]，反映出“学习跨步状态转移”正成为重要方向。

本课题拟采用粗到细少步生成，而非把所有决策压缩到单一步。结构阶段用较少但关键的步骤确定对象、数量和布局，细化阶段在结构条件下补全纹理与局部属性；训练时用多次教师补全的平均奖励估计结构价值，并在学生实际访问的同一状态上构造跨步教师目标。这样，强化学习负责回答“哪些结构值得保留”，蒸馏负责回答“给定结构如何跳过若干中间步完成补全”。二者共享学生参数，可把在线搜索经验转化为固定预算下的生成能力。

### 1.8 评价体系与研究规范

生成优化必须同时衡量语义、感知、效率和稳定性。GenEval 以对象为中心评估单/双对象、计数、颜色、位置和属性绑定[9]，适合诊断组合语义；DPG-Bench 使用更稠密提示评估复杂文本遵循，其来源工作为 ELLA[35]。ImageReward、HPSv3、DeQA 和 Unified Reward Model 等指标可从偏好或感知质量角度补充[10,36-38]。但自动指标各有偏差：CLIP 类指标可能忽略细粒度计数，奖励模型可能偏爱特定风格，使用与训练奖励相同的指标又会高估泛化。因此应设置与训练奖励独立的测试指标，并通过人工盲评检查语义、质量与多样性。

统一模型还需防止“生成进步、理解退化”。应在 POPE、MMBench、SEED、MMMU 等理解基准上比较优化前后结果，并单独报告问答校准和幻觉。效率方面同时统计 NFE、端到端延迟、吞吐、峰值显存、训练 GPU-hours；在固定预算下比较质量，在固定质量下比较延迟。稳定性方面至少使用多个随机种子报告均值和方差，分析奖励方差、策略 KL、梯度范数和失败率。对于不同论文中相同模型的分数，只在各自 checkpoint 和评测协议内部比较增量，避免把不一致的基础分数拼成同一排行榜。

多参考图像创作与编辑是更复杂的能力边界。本人已开展 MICE-Bench 相关工作，用于考察多个参考图像条件下的创作与编辑[39]。这类任务同时要求目标主体保持、指令执行、非目标区域保护和多参考关系组合，可作为文生图之外的泛化验证。TR-PTS 则通过 Fisher 信息选择任务相关参数，并结合 token 选择降低视觉模型微调成本，在 FGVC 和 VTAB-1k 上以少量可训练参数取得有竞争力结果[40]。该工作虽不直接解决生成问题，但为本课题分析“哪些参数、token 和计算最值得保留”提供了方法与实践基础。

### 1.9 视觉离散化、空间结构与长序列效率

离散扩散模型的第一层瓶颈来自视觉 tokenizer。图像压缩必须同时保留低层纹理、对象边界、文字细节和高层语义，但有限码本与较大下采样率会造成信息损失。码本越大、空间分辨率越高，重建越精细，Transformer 需要处理的序列也越长；压缩越激进，生成成本越低，但小物体、文字和精细属性更容易丢失。VQGAN、MaskGIT 等工作建立了“离散编码—序列建模—图像解码”的基本范式[3,5]，后续统一模型仍需在重建质量、语义可分性和序列长度之间折中。Lumina-DiMOO 使用 8192 个视觉 token 和 16 倍空间下采样，将 1024×1024 图像表示为 4096 个位置[16]。这一选择支持较高分辨率，但每个扩散步骤都要处理数千视觉位置，说明采样步数和无效 token 计算仍是系统成本的主要来源。

二维图像被展平为一维 token 后，空间归纳偏置也会变化。自回归模型通常沿栅格顺序生成，顺序本身携带空间邻接；掩码扩散允许任意位置并行恢复，生成次序主要由置信度、掩码调度和随机采样共同决定。Lumina-DiMOO 在每行末尾插入特殊标记以区分纵横比相同长度的二维布局[16]，其他模型则使用二维位置编码或分块结构。无论采用何种方案，token 的“早/晚”并不必然等价于空间上的“轮廓/纹理”：某些高置信背景可能先生成，复杂对象的关键轮廓也可能较晚才稳定。因此，层次强化学习需要结合生成秩、预测熵、空间连通性和对最终奖励的因果敏感度，不能仅凭固定前若干比例定义结构。

长序列还改变了并行生成的实际收益。理论上，一轮可以恢复多个位置；实际实现中，Transformer 前向仍随序列长度付费，且 classifier-free guidance 往往需要额外条件/无条件计算。若每轮只保留少数高置信 token，过程接近长步数迭代；若一次保留过多，早期错误可能被锁定。掩码调度因此承担类似连续扩散噪声日程的作用：余弦、线性或自适应日程会影响探索、稳定性和可恢复性。ML-Cache 等方法通过复用稳定 token 的表示减少计算[16]，token 剪枝/合并则从序列长度入手；本课题更关注从决策价值出发减少无效轨迹和无效步骤。三类优化具有互补性，后续实验需要区分网络级缓存、序列级压缩和算法级预算分配各自贡献。

图像编辑、多参考创作等任务进一步放大序列问题。输入参考图像、编辑条件和输出图像可能同时占据上下文，目标不仅是生成合理结果，还要保持非编辑区域与主体身份。简单沿用文生图奖励容易鼓励“整体重绘”而破坏保持性。MICE-Bench 等多参考评测工作说明，生成质量需要与参考一致性、指令遵循和区域保持联合评价[39]。因此，本课题在验证通用性时将把 token 价值从单纯的“影响最终美观”扩展为“影响指令目标且尽量不改变无关内容”，考察层次分组和自反馈能否迁移到条件更复杂的生成任务。

### 1.10 离散策略概率、轨迹多样性与信用估计

离散扩散的策略概率与自回归模型存在本质差异。自回归轨迹的联合概率可按固定顺序分解为条件概率乘积；掩码扩散在每轮同时预测多个位置，并由置信度或随机规则选择哪些 token 固化，同一终态可能由大量顺序到达。若直接把每个最终 token 当作独立动作，会忽略掩码调度和并行选择对轨迹概率的影响；若严格记录所有中间状态和选择事件，计算又随步数、序列长度和 rollout 数量快速增长。由此，现有方法在“概率估计忠实度”和“训练可承受成本”之间采用不同近似。

随机重掩码近似从最终样本构造训练上下文，优点是无需保存完整轨迹，可在同一图像上覆盖多种掩码组合；缺点是可见集合可能包含实际决策之后才生成的 token。对结构 token 而言，这相当于先看到部分答案再评估当初动作，概率比与真实行为策略不一致。真实轨迹方法消除了这种未来信息，却只能覆盖已采样的一条去掩码路径，且对每个时间步都保存长序列状态。全掩码提示条件估计器把所有视觉上下文统一移除，从构造上避免未来泄漏，也能用一次前向得到各位置分布，但同时丢失真实过去信息，是一种有偏代理[25]。本课题拟通过少量真实轨迹校准、多个部分上下文估计和重要性权重截断，实证比较这些估计器的偏差、方差、显存和最终性能。

信用分配还应区分“状态价值”和“动作贡献”。图像级奖励反映终态好坏，但一个早期结构 token 的贡献取决于后续策略能否把它补全；同一结构在不同随机补全过程中可能得到不同质量。固定地给早期 token 更高权重是一种有效先验，却可能在简单提示或背景主导图像中误分配信用。更稳健的做法是估计条件补全价值：固定某个中间结构，从教师或当前策略多次补全，使用平均回报近似该结构的期望价值；再比较替换、重掩码某个 token 后的价值变化，获得反事实贡献。完整计算代价很高，可用少量补全、价值网络或分层共享估计近似。该思想也是本课题把层次强化学习与后续粗到细蒸馏连接起来的关键。

GRPO 的组内标准化能减少奖励尺度差异，但当同一提示下样本奖励接近时，优势信号会变弱；过强奖励差异又可能导致策略快速偏离参考模型。离散生成中的高熵早期步骤通常提供更大探索空间，后期分布逐渐尖锐，统一的裁剪阈值和 KL 系数未必适合所有阶段。本课题将监控阶段熵、有效样本量、概率比裁剪率和策略 KL，研究阶段相关的更新强度。目标不是简单放大早期梯度，而是在结构探索、细节稳定和模型原有多样性之间建立可测量的平衡。

### 1.11 自验证信号的可靠性与多目标奖励

自验证的核心前提是模型“能看出自己生成的问题”。统一模型在外部图片上的问答能力不等于在自身生成分布上的可靠评价能力：生成图像可能含有局部伪影、重复对象或模糊关系，评价分支又可能受文本先验影响，在没有真正识别图像时根据提示猜答案。若直接以“回答与提示一致”作为奖励，模型甚至可能学习产生有利于自身判断、但不利于人类感知的模式。因此，自验证需要证明图像证据确实影响回答，可通过图像遮挡、交换图像、反事实问题和无图条件对照检验；还应测量答案置信度的校准误差，而不只统计正确率。

不同生成阶段适合不同验证粒度。全掩码或早期状态只能显示粗略布局，此时适合判断对象数量、主体位置和大体关系，过早评价颜色、纹理和审美会产生高噪声；后期图像较完整，才适合细节与质量评分。分层搜索因而不应在所有节点使用同一验证器和阈值。本课题拟建立阶段感知验证：早期以结构化语义问题和不确定性为主，中期加入属性绑定和局部一致性，末期再聚合感知质量与审美。对于低置信候选采用延迟决策或保留少量探索配额，以降低早期误删。

单一奖励模型容易造成 reward hacking。CLIP 类对齐分数可能偏好显著关键词而忽视计数；审美模型可能偏好特定构图和色调；问答正确数覆盖可枚举语义，却不能充分评价纹理、文字与真实感。多目标奖励可以缓解单一偏差，但简单加权又会受到量纲和相关性影响。应先对各评分器做归一化和相关性分析，再采用加权和、Pareto 选择或分阶段目标；训练指标与最终测试指标尽量解耦。人工盲评用于检查自动指标一致性，失败案例则按语义、感知、文字和保持性分类，以识别性能提升究竟来自真正改进还是指标偏好。

自反馈训练还具有“评价器随策略共同变化”的非平稳性。同步更新理解分支可能使奖励标准逐步漂移，完全冻结又无法适应学生生成分布。本课题将比较三种机制：冻结评价分支保证标准稳定；以较小学习率慢更新，在保持能力的同时适应新分布；使用冻结教师评价与当前模型评价的集成。每隔固定训练周期在独立理解集和人工校验集上重新测量评价可靠性。只有当生成指标、独立理解指标和人类偏好同时改善时，才将结果解释为生成—理解协同，而不以生成分数单独推断理解能力提高。

### 1.12 搜索、蒸馏与系统效率的统一考察

推理搜索和蒸馏分别对应“用更多在线计算换质量”和“用离线训练换部署速度”。搜索能够在不改参数的情况下快速验证价值函数和预算策略，却需要每个请求重复探索；蒸馏把教师行为写入学生参数，部署成本稳定，但训练成本较高且可能丢失多样性。将两者结合的关键，不是简单把搜索最优图像作为监督，而是保存为什么某条轨迹更好：哪些结构在多次补全后仍获得高回报、哪些中间状态允许教师跨越多步稳定补全、哪些提示需要更多结构预算。

只蒸馏搜索最终样本可能引入选择偏差。搜索保留的是高分尾部样本，学生若把这些少数结果当作唯一目标，容易降低分布覆盖并复制验证器偏好。本课题拟保留候选组及相对价值，用组内优势学习结构选择，同时让教师为同一结构提供多个条件补全目标；对低分结构也保留少量样本以学习决策边界。蒸馏监督只作用于新增去掩码位置，并在不同跨步间隔上训练，使学生既能完成大跨度跳步，也能在困难状态下使用较小跨度。

学生状态分布偏移是另一难点。若监督状态全部来自教师，少步学生推理时访问的错误或不完整结构在训练中没有出现，误差会累积。采用学生在线生成状态再由教师补全，可让监督覆盖学生真实分布，但教师在异常状态上的输出也可能不可靠。需要周期性刷新数据、设置教师置信度筛选，并比较 on-policy、离线教师轨迹和混合状态。结构强化学习与蒸馏若给出冲突梯度，可使用权重退火、分阶段训练或梯度投影；若学生尚未学会基本补全，则先蒸馏建立能力，再逐步提高奖励优化比重。

系统效率必须从端到端口径评估。NFE 便于比较模型核心前向次数，但不同方法可能包含问题生成、视觉问答、多个评分器、数据搬运和动态批处理。搜索剪枝减少主模型计算的同时，也可能因分支长度不一致降低 GPU 利用率；缓存方法减少计算却提高显存；少步学生减少同步次数，但单步若处理更多候选，时延未必按步数等比例下降。因此，本课题将用相同硬件与批量测量预处理、主模型、验证、解码等各环节时间，报告单图延迟、吞吐和峰值显存。只有端到端实测支持时才使用“实际加速”表述，其余统一称为 NFE 或理论计算降低。

### 1.13 国内外研究格局与可突破空间

国际上，扩散生成、离散表征和强化学习后训练由高校、研究机构与工业界共同推进。DDPM、潜扩散、MaskGIT、D3PM 等工作奠定连续与离散生成基础[1-2,5-6]；近两年研究重点转向统一模型、推理时扩展和奖励优化。Emu3、Show-o、Janus-Pro 等证明统一序列模型能够兼顾多模态任务[11-13]，推理时扩展与反思优化工作则显示冻结模型仍可通过搜索提升结果[27-30]。这些方法多数从连续扩散或自回归系统出发，其价值估计、轨迹定义和缓存机制未必适合全离散、双向注意力的多模态模型。

国内团队在统一离散扩散方向形成了密集成果。MMaDA、Lumina-DiMOO、Muddit、LLaDA-V 等工作由国内高校与研究机构牵头或深度参与[14-17]，覆盖基础模型、视觉指令、统一生成理解和多任务扩展。dMLLM-TTS、Self-GRPO 与 HT-GRPO 进一步把研究推进到自验证、生成—理解闭环和层次策略优化[16,25,31-32]。这些工作使本课题能够基于已有开源模型和真实实验经验开展研究，而无需重新建立全部基础设施，也说明该方向竞争迅速、评测版本迭代频繁，必须强调可复现协议和严格对照。

目前仍缺少把训练后优化、在线搜索和少步蒸馏统一起来的系统研究。现有强化学习关注参数更新，却常忽略部署计算；现有搜索提高质量，却不沉淀每次搜索经验；现有一步蒸馏追求极端步数压缩，却难以保持复杂语义和细节。统一模型的理解能力又提供了传统生成模型没有的内部反馈通道。围绕“高价值 token—高潜力轨迹—可信语义反馈—可迁移条件补全”建立同一价值视角，有望形成区别于单点改进的方法体系。

此外，现有论文常使用不同 checkpoint、分辨率、CFG、采样器和评测代码，导致同名基础模型分数不一致。例如用户材料中 Lumina-DiMOO 在不同稿件的 DPG/GenEval 基础分存在版本差异，合理原因可能是模型与协议变化，但不能跨表直接比较。本课题将固定基础模型与测试配置，所有增量只在同协议内解释；对论文状态、个人贡献和团队成果也保持边界清晰。该规范既是保证博士论文可信度的需要，也能使质量—效率结论真正可复验。

### 1.14 核心科学假设与验证边界

本课题的第一项科学假设是：离散扩散的生成顺序包含可利用的层次信息。该假设并不要求每个早期 token 都表示几何轮廓，而是认为在统计意义上，低上下文、高不确定性的早期决策对后续可行补全空间具有更大影响。验证时将同时测量生成秩与预测熵、对象区域、空间关系、最终奖励敏感度的相关性，并通过重掩码或替换 token 的反事实实验估计因果贡献。若某类提示中相关性不成立，则动态分组器应降低顺序先验权重，而不是强制使用固定结构比例。

第二项科学假设是：统一模型的理解能力可以提供有效但不完备的内部价值信号。所谓“有效”需要由其与人工判断、外部独立评价和最终任务成功率的相关性证明；所谓“不完备”意味着必须承认盲区并使用校准、集成和不确定性控制。研究将分别评价完整图像和中间状态上的自验证精度，测量不同阶段的误删概率，并检查提示泄漏、无图猜测和共享偏差。由此确定自验证适合承担的决策范围，而非把模型自评分视为客观真值。

第三项科学假设是：高价值结构与条件补全能力可以通过联合学习压缩到少步学生中。其成立条件包括教师对学生状态仍能给出可靠补全、结构价值估计方差可控、强化学习与蒸馏梯度不存在长期不可调和冲突。研究将用纯搜索、纯蒸馏、先蒸馏后强化和联合训练四类对照逐项验证。若联合方法只降低 NFE 而未降低真实延迟，或只提高训练奖励而未提高独立指标，则不视为假设得到完整支持。

这些假设使论文结论具有清晰边界：阶段性结果用于说明机制在指定底座和协议上有效，跨模型、跨分辨率和跨任务实验用于判断可迁移性，理论分析用于解释方向而不替代实证。对于匿名稿、在审稿和答辩材料中的状态信息，论文定稿时将根据正式公开版本更新；对尚未完成的粗到细方法，只陈述研究目标、方案和可检验预期，不把预期收益写成既成事实。

### 1.15 现有挑战与本课题定位

综合现有研究，离散扩散多模态生成仍有四个相互关联的挑战。其一，信用分配粒度不足。图像级奖励难以区分早期结构 token 与后期细节 token 的贡献；固定结构比例和固定权重又不能适应提示复杂度。其二，推理预算分配不足。全面扩展所有轨迹浪费计算，过早剪枝则受不完整语义和验证误差影响。其三，自反馈可靠性不足。模型自身问答可以减少外部验证器依赖，但共享偏差、奖励漂移和理解能力退化需要独立约束。其四，搜索经验迁移不足。现有推理扩展带来在线成本，一步蒸馏又可能损失结构与细节，需要在价值学习和跨步监督之间建立联系。

据此，本课题以“识别高价值决策—按价值分配计算—迁移为少步生成能力”为主线，安排四项递进研究：首先在训练侧根据生成层次进行强化学习与 token 信用分配；其次在推理侧利用自验证分层搜索高潜力轨迹；再次把生成与理解纳入结构化自反馈训练；最后以条件补全价值连接结构强化学习和跨步蒸馏，形成粗到细少步生成。前三项已有阶段性结果，第四项是后续重点。课题将在统一离散表示和真实采样轨迹上贯通训练、推理和蒸馏，以期在有限计算预算下同时改善提示遵循、视觉质量和生成效率，并为统一多模态模型的自我评价与自我改进提供可验证的方法基础。

从理论层面看，课题将研究非固定去掩码顺序中的层次结构、终局奖励到并行 token 的信用传递，以及代理概率比与真实轨迹概率之间的偏差。这些问题不同于固定顺序自回归策略，也不同于连续扩散的可微状态演化。通过熵、生成秩、条件补全价值和反事实扰动建立联系，有望形成适用于离散并行生成的价值分析框架。即使某些经验假设在特定任务上不成立，明确其成立范围和失败条件也能完善对离散生成机制的理解。

从方法层面看，四项研究共享同一价值概念，却分别作用于 token、轨迹、反馈和步数。层次强化学习回答“训练时更新哪些决策”，自验证搜索回答“推理时继续计算哪些分支”，自反馈回答“由谁判断结果价值”，粗到细蒸馏回答“如何把高价值行为固化到少步模型”。这种统一组织有助于避免多个算法的简单堆叠，并可通过统一消融判断每种价值信号在质量、成本和稳定性上的真实贡献。

从应用层面看，减少无效轨迹和采样步骤能够降低生成服务的计算、显存和等待时间，使高质量生成更适合交互式创作和批量内容生产；结构化自验证可在不额外部署大型外部模型的情况下检查数量、关系和属性错误，也便于形成可解释的失败提示。对于多参考编辑等高约束任务，按价值保护主体与非编辑区域具有直接意义。但效率提升必须与输出安全和可信评价同步考察，不能以更快生成交换不可控错误。

最终，课题预期产出不只是一组更高的自动指标，而是一套可复验的比较协议：固定预算看质量、固定质量看延迟、独立基准看理解、人工盲评看真实偏好、多随机种子看稳定性。通过同时报告有效结果、额外开销和失败案例，建立对离散扩散生成优化更完整的证据链。这也是把前期模型与算法成果整合为博士学位论文的主要学术意义。

## 二、课题研究目标、主要研究内容和拟解决的关键问题

### 2.1 总体研究目标

本课题面向生成与理解统一的离散扩散多模态大模型，研究有限计算预算下的生成质量与效率优化。总体目标是建立“价值识别—计算分配—能力迁移”的统一方法：从视觉 token 的生成次序和不确定性中识别关键结构决策；利用模型自身理解能力评价候选轨迹并分配推理预算；将结构化语义反馈用于真实生成轨迹上的训练；最终把搜索和教师补全经验蒸馏为粗到细少步生成能力。评价上同时考察提示遵循、感知质量、多样性、理解能力、NFE、端到端时延和训练成本，形成可复现的质量—效率分析。

### 2.2 主要研究内容

#### （1）生成层次感知的强化学习优化

研究离散去掩码顺序与全局结构、局部细节之间的关系。依据 rollout 中 token 的生成秩、预测熵和跨步稳定性划分结构集合与细化集合，把强化学习内循环组织为全局、结构、细化三个阶段。对图像级组内优势进行层次加权，使早期结构决策获得更高信用；在全掩码、仅文本可见的上下文中估计新旧策略概率比，以减少未来 token 泄漏和中间状态缓存。进一步研究从固定比例、固定权重向提示条件和不确定性条件的自适应分组与动态信用分配扩展。

#### （2）自验证驱动的推理搜索优化

研究无需额外大模型验证器的轨迹价值估计。把提示拆解为对象、数量、颜色、属性和空间关系问题，使用统一模型自身的图像理解能力评估候选；在生成早期保留多样结构，在中期剪枝低潜力轨迹，在后期集中预算细化。结合多种采样调度器扩展候选差异，并聚合语义一致性、美学和质量评分。分析剪枝时机、候选宽度、验证置信度与错误累积之间的关系，在固定 NFE 和固定质量两种口径下比较搜索效率。

#### （3）生成与理解协同的自反馈优化

研究结构化语义反馈在参数更新中的有效性和稳定性。对生成图像自动构造实体、数量、颜色与关系问题，以理解分支的正确数和置信度形成奖励；在保留真实完整采样轨迹的前提下抽取部分时间步计算梯度，并联合优化生成目标、理解目标和 KL 正则。通过独立理解基准、外部奖励与人工评测检查自反馈偏差；研究冻结或慢更新评价分支、奖励校准和多奖励集成，避免生成与理解共同向错误偏好漂移。

#### （4）粗到细蒸馏与推理加速

研究将在线搜索经验迁移到少步学生模型。学生先用 Ks 步产生多个结构候选，冻结教师对每个结构进行 M 次随机补全，以多次补全的平均语义与质量奖励估计结构价值；使用组内优势和 KL 约束强化结构策略。在同一学生访问状态 zt 上，保持文本、可见 token 和掩码一致，由教师生成若干步后的目标状态 zs，仅在新增去掩码位置计算跨步交叉熵，学习条件补全。两分支共享学生参数，联合优化强化学习损失和蒸馏损失。推理时只部署学生，以 Ks 步确定结构、Kr 步完成细化，并在固定总预算 B=Ks+Kr 下研究阶段步数分配。

### 2.3 拟解决的关键问题

第一，如何从非固定的离散生成顺序中识别真正影响布局和语义完整性的高价值 token，并把终局图像奖励分配到相应决策，同时控制概率估计偏差和轨迹缓存开销。

第二，如何在中间图像不完整、验证信号含噪的条件下识别高潜力轨迹，使搜索既保持足够探索多样性，又能及时停止对低价值分支的计算。

第三，如何利用统一模型的理解能力形成可信、自洽且可校准的生成反馈，避免评价分支与生成分支共享偏差造成奖励投机，并保证优化后理解能力不退化。

第四，如何以稳定的条件补全价值连接结构强化学习和跨步教师监督，缓解少步学生的状态分布偏移与奖励—蒸馏目标冲突，并确定结构阶段和细化阶段的合理预算。

## 三、拟采取的研究方法、研究方案及其可行性分析

### 3.1 总体技术路线

以 Lumina-DiMOO、MMaDA 等开源离散扩散多模态模型为主要实验底座，建立统一的数据、采样、奖励和评测接口。首先复现基础推理及代表性后训练基线，记录每个视觉 token 的生成秩、预测熵、最大 logit、跨步变化、空间坐标与最终奖励敏感度；其次分别实现层次强化学习、自验证搜索和自反馈联合训练，验证价值识别在训练端和推理端的作用；最后构建粗到细学生，把前述价值信号和教师轨迹用于跨步蒸馏。全流程在同一实验协议下报告质量、效率、稳定性和理解能力，避免只以单一自动指标判断结论。

### 3.2 研究内容一的方法方案

对同一文本提示采样 G 条完整轨迹，记录 token i 在第 g 条轨迹中的生成秩 ρg,i。以秩、熵和跨步 logit 变化构造结构概率 si，将 token 分为结构与细化集合；初期沿用固定比例建立可比基线，后续用轻量分组器根据提示复杂度和 rollout 不确定性动态预测。组内奖励标准化得到图像级优势 Ag，再按结构概率形成 token 权重 wi，使结构、全局和细化阶段获得不同信用。概率比采用全掩码提示条件估计，并选择少量真实中间状态作为校准样本，比较全掩码代理、随机重掩码和真实轨迹估计的偏差—方差—成本折中。

训练内循环依次执行全局、结构和细化更新，各阶段从对应集合随机抽取 token，并将覆盖率从高到低退火。设置均匀信用、固定层次信用、动态信用三组方法；设置仅全局、全局+结构、三阶段等调度消融；分析结构比例、阶段预算、KL 系数和抽样率。主要检验 GenEval 的计数、位置、属性绑定，以及 DPG-Bench 的复杂提示遵循，并结合注意力/熵可视化判断“早生成 token=结构”的适用边界。

### 3.3 研究内容二的方法方案

将候选搜索表示为宽度和深度均可调的分层过程。探索阶段从全掩码状态使用不同随机种子、温度或掩码调度器生成 N 个结构候选；筛选阶段把提示解析为可回答的原子问题，由模型自身理解分支计算语义得分，同时加入与训练独立的质量/美学评分；细化阶段为保留的 K 条轨迹分配剩余步骤。为降低中间状态评价误差，将研究分数置信区间、延迟剪枝和多阶段复核：不确定候选暂缓淘汰，高置信低分候选提前停止，高分候选获得更多细化预算。

与 best-of-N、线性轨迹搜索、随机剪枝和外部验证器搜索比较。统一记录模型前向次数、验证器开销、端到端延迟、峰值显存和并行吞吐；在相同 NFE 下比较生成质量，在达到相近 GenEval/DPG 分数时比较真实延迟。通过关闭自验证、替换为外部验证器、改变剪枝层数、候选宽度和评分组合进行消融，并统计误删高质量轨迹的比例。

### 3.4 研究内容三的方法方案

从文本提示提取实体—属性—关系三元组，自动生成多项选择或短答案问题及可核验答案。对每张生成图像调用理解分支，按对象存在、数量、颜色、属性绑定和空间关系分别计分，经置信度校准后形成语义奖励；与独立的感知质量奖励组成奖励向量，避免单一问答信号牺牲画质。生成分支使用真实 rollout 上抽样时间步的策略目标，理解分支使用图像条件答案似然，加入相对冻结参考策略的 KL 约束。

设置自反馈、外部反馈、混合反馈和无反馈基线；比较评价分支冻结、慢更新和同步更新。每隔固定步数在独立理解数据上校准问题正确率和期望校准误差，若出现理解退化或奖励漂移，则降低自反馈权重并提高外部/冻结评价占比。生成侧报告 GenEval、DPG-Bench、ImageReward 等，理解侧报告 POPE、MMBench、SEED、MMMU，另做人工盲评检查自动问答遗漏的语义错误。

### 3.5 研究内容四的方法方案

训练阶段从文本 c 与全掩码视觉序列出发，由学生策略 πθ 运行 Ks 步得到结构状态 zτ。对于同一 zτ，冻结教师 πφ 独立补全 M 次得到 x1,…,xM，以语义、质量和多样性奖励的加权平均作为结构价值估计；在同提示结构组内标准化优势，配合 KL 约束更新学生结构策略。多次补全用于降低一次随机补全的方差，同时保留完成同一结构的多样可能。

蒸馏分支从学生访问的状态 zt 出发，让教师沿同一文本和掩码条件运行到更晚状态 zs。只对 zs 相对 zt 新增的可见位置计算交叉熵，避免要求学生重学已有 token；随机采样跨步间隔，使学生学习不同跨度的条件补全。总损失写为 L=λRL LRL+λKD LKD+βLKL。训练中周期性刷新学生状态和教师目标，减少静态数据造成的状态分布偏移；监控两类损失梯度夹角，当长期冲突时采用权重退火、梯度投影或分阶段优化。

推理阶段固定总步数 B，在结构生成 Ks 和细化补全 Kr 之间分配。比较均分、前多后少、前少后多和不确定性自适应四种策略，并与原多步模型、一步 Di[M]O 类基线和纯蒸馏学生比较。核心消融包括 M、跨步间隔、状态刷新频率、两类损失权重、是否使用结构奖励、是否使用教师条件补全以及不同 Ks/Kr。最终在至少两个底座上验证跨模型可迁移性。

### 3.6 实验设计与评价

文生图组合性采用 GenEval、DPG-Bench；通用质量采用与训练奖励解耦的 ImageReward、HPSv3、DeQA、感知/美学指标和人工盲评；必要时在多参考创作与编辑任务上评估主体一致性、编辑指令遵循和背景保持。统一理解采用 POPE、MMBench、SEED、MMMU。效率报告 NFE、端到端每图延迟、吞吐、峰值显存、训练 GPU-hours；稳定性至少使用三个随机种子报告均值、标准差或置信区间。

所有比较固定分辨率、CFG、采样器、随机种子集合与评测实现，区分基础 checkpoint 差异。人工评测采用随机打乱和盲评，分别评价提示一致性、视觉质量和整体偏好。对自动奖励开展相关性和 reward hacking 检查；对失败案例按对象遗漏、计数、属性、空间关系、文字、结构崩坏和过度平滑分类，形成定量与定性相结合的结论。

### 3.7 可行性分析

理论上，离散扩散的去掩码顺序、条件类别分布和掩码集合均可观测，能够直接支持层次划分、策略概率估计和跨步监督；统一模型同时具备生成与问答接口，为自验证和自反馈提供结构基础。现有研究已证明组内相对优势、分层搜索和 token 级蒸馏在相关设置中的可行性，拟议方案是在同一离散状态空间中连接这些环节，技术路径清晰。

实验上，前三项研究已有阶段性结果：HT-GRPO 在两个底座的同协议对照中提高 GenEval；dMLLM-TTS/v2 已验证自验证分层搜索的质量—NFE优势；Self-GRPO 已在统一模型中观察到生成语义对齐改善。本人参与相关模型、奖励、训练和评测工作，具备继续完成粗到细联合方案的代码与实验基础。Lumina-DiMOO、MMaDA 等已有可用模型和评测协议，可减少从零训练基础模型的成本。

风险方面，重点关注高算力需求、奖励偏差、训练不稳定和蒸馏质量下降。应对措施包括：先在较小分辨率/较少 token 上验证机制，再扩展；使用参数高效训练、梯度检查点和时间步抽样控制显存；以外部奖励和人工盲评校准自反馈；通过 KL、梯度裁剪、权重退火和多随机种子监控稳定性；若联合训练冲突明显，则采用先结构强化、后条件蒸馏的分阶段方案。若少步学生无法在同一质量下显著减少真实延迟，也将如实报告 NFE、验证器和系统开销的分解结果。

## 四、课题的创新点

### 4.1 面向生成层次的 token 信用分配

区别于把图像级奖励均匀广播给所有视觉 token，本课题利用实际去掩码顺序和不确定性区分结构与细化决策，在全局—结构—细化阶段内分配不同训练信用；进一步研究提示条件的动态分组和动态权重。该思路把离散扩散的非固定生成顺序从训练难点转化为可利用的层次信号。

### 4.2 统一模型自验证驱动的轨迹预算分配

利用模型自身视觉理解能力把文本要求分解为结构化问答，在无需额外大型验证器的条件下评价中间候选；通过分层搜索、置信度感知剪枝和多调度器探索，把有限计算集中到高潜力轨迹。评价同时覆盖 NFE 与端到端时延，明确算法计算节省与系统实际加速的差异。

### 4.3 生成—理解闭环中的轨迹一致自反馈

将对象、数量、颜色和关系问答构造成可核验语义奖励，并在真实离散采样轨迹上联合优化生成与理解目标；通过抽样时间步、KL 约束、独立理解评价和奖励校准控制计算与反馈漂移。创新重点在于把统一模型的理解能力转化为生成训练信号，同时显式验证评价可靠性。

### 4.4 以条件补全价值连接结构强化学习与跨步蒸馏

提出粗到细联合方案：用同一结构的多次教师补全平均回报估计结构价值，用同批条件一致轨迹构造跨步蒸馏目标，使“选择高价值结构”和“高效完成该结构”作用于同一学生状态分布。该方案拟将在线搜索经验迁移为仅部署学生的少步能力，并系统研究固定总预算下结构与细化阶段的步数分配。
