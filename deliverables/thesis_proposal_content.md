# 面向离散扩散多模态大模型的生成优化方法研究

## 一、国内外研究进展、现状、挑战与意义

### 1.1 研究背景、问题范围与选题意义

大规模预训练模型正在由单一文本建模扩展到图像、视频、语音等多种模态，并从分类、检索等判别任务逐步走向理解、生成与交互的一体化。统一多模态模型希望以共享的主体网络接收文本和视觉输入，同时完成视觉问答、文生图、图像编辑及多轮修正。其价值不只在于减少任务专用模块，还在于使理解侧获得的对象、属性和关系知识能够约束生成，使生成结果又能成为理解与反馈的对象。若这种闭环能够稳定建立，同一模型便可能在内容创作、视觉设计、教育辅助、具身交互和科学可视化中提供一致接口。

文生图是检验生成能力的代表任务。现有模型能够合成具有较高感知质量的图像，但在包含多个对象和组合关系的提示上，仍会出现对象遗漏、计数错误、属性绑定混乱及空间关系颠倒等问题；GenEval 和 DPG-Bench 分别从对象中心组合语义和稠密提示遵循角度揭示了这些不足[1–2]。后续强化学习、自反馈和搜索研究表明，部分失败可通过重新分配训练信用或推理预算得到纠正[3–5]，因此性能不仅取决于模型知识和规模，也取决于奖励如何传递到具体决策及有限计算如何分配。持续扩大模型、数据和训练计算可以提高能力上限，却难以替代对生成机制和部署预算的研究。因此，在固定底座与有限计算条件下提高提示遵循、视觉质量和生成效率，是具有独立价值的问题。

本课题把研究范围限定为使用离散视觉 token、通过多轮掩码预测生成图像，并兼具视觉理解能力的统一模型。该范围需要与三类相邻系统区分。第一类是连续潜空间扩散模型，其图像状态为连续变量；第二类是按固定顺序逐 token 输出图像的自回归模型；第三类是“语言模型加独立连续扩散生成器”的组合系统。三类系统都可能完成理解和生成，但动作空间、轨迹概率、缓存方式和少步化方法并不相同。本文关注的离散掩码扩散从全掩码状态出发，在每轮并行预测多个视觉位置并按置信度或调度规则保留部分 token，同一终态可以由不同去掩码顺序到达。可调的生成顺序、候选轨迹和采样步数为优化提供了自由度，也带来了离散信用分配、中间状态评价和跨步迁移等特有问题。

围绕这一对象，现有研究可分为四个相连层面：基础模型决定视觉表示与生成轨迹；训练后优化决定终局奖励如何传到 token 和阶段；推理时扩展决定额外计算用于哪些候选；蒸馏与少步生成决定在线搜索经验能否固化为固定预算能力。本文综述按这一链路组织，而不把“统一架构”“强化学习”“搜索”和“加速”视为互不相关的技术点。其核心问题是：能否识别离散生成中的高价值决策，按其预期贡献配置训练和推理计算，并在不牺牲理解可靠性与视觉多样性的前提下，将所得经验迁移到少步模型中。

这一问题具有三方面意义。理论上，非固定去掩码顺序中的联合概率与信用传播不同于固定顺序自回归，也不同于连续扩散的状态演化，需要分析生成秩、条件上下文和终局奖励之间的关系。方法上，统一模型能够同时生成和读取图像，为内部语义反馈提供了条件，但也产生共享偏差和评价器漂移。应用上，减少无效轨迹和采样轮数有望降低交互等待和部署成本，不过只有端到端时延、吞吐和峰值显存的实测才能证明实际加速，网络前向次数减少本身并不等同于墙钟时间按比例下降。

### 1.2 图像生成范式、离散视觉表示与掩码扩散

扩散概率模型通过构造逐步破坏数据的前向过程并学习反向恢复，为高质量图像生成建立了稳定训练框架。DDPM 证明了多步去噪的有效性[6]，潜空间扩散将去噪转移到压缩潜变量中，降低了高分辨率生成成本[7]，SDXL 又通过更大的网络、改进的条件编码与训练策略提升了高分辨率合成质量[8]。连续表示便于描述细粒度变化，相关采样理论和工程生态也较成熟。传统连续扩散采样通常需要多次网络前向；渐进蒸馏、一致性模型和分布匹配蒸馏则已证明，这一计算形态可以通过轨迹压缩、一致性映射或分布匹配减少到少数步甚至一步[9–11]。

离散图像生成首先需要把像素压缩为有限词表。VQ-VAE 以向量量化学习离散潜变量，奠定了神经离散表示的基本形式[12]；VQGAN 在此基础上结合感知损失与对抗训练，提高了高分辨率图像的重建与感知质量[13]。DALL-E 展示了将文本和离散图像 token 作为统一序列进行生成的可行性[14]。这一路线把图像问题转化为词表上的概率建模，使 Transformer 能够在同一序列空间处理两种模态，但其性能上限受 tokenizer 约束：较大的码本和较低的压缩率有助于保留纹理、文字与小物体，却会增加序列长度和计算；较强压缩降低主干成本，却可能在建模之前已经丢失细节。因而，视觉 token 数量、码本利用率、重建质量和主体模型长度必须联合报告，不能只用主体模型参数量衡量系统能力。

早期离散图像模型多采用自回归分解，按栅格或预定顺序逐 token 生成。其联合概率定义清晰，但高分辨率图像对应长序列，逐位置解码造成较高延迟，早期错误也可能沿固定顺序累积。MaskGIT 改用双向 Transformer 反复预测被掩码位置，每轮保留高置信 token 并重掩码低置信位置，实现多位置并行恢复[15]。D3PM 从离散状态空间的马尔可夫转移角度建立更一般的离散扩散框架[16]，后续比率估计方法进一步扩展了训练与采样形式[17]。这些工作共同说明，离散生成并不等于自回归：掩码扩散可以同时预测多个位置，并通过掩码调度改变生成顺序和步数。

设视觉 token 序列为 z=(z1,…,zN)，初始状态全部为特殊掩码 [M]。在第 t 轮，模型根据文本条件 c 和当前可见 token 预测所有掩码位置的类别分布，再按置信度与随机性以及调度函数决定哪些预测被写入状态、哪些重新置为 [M]。经过 T 轮之后完整序列由图像解码器还原。相对自回归模型，这一过程允许并行恢复和非固定顺序；相对连续扩散，类别分布、掩码集合与去掩码事件构成显式的离散决策变量，可用于策略优化、搜索和跨步监督。不过“可作为决策变量”不等于可以直接套用连续梯度：并行选择改变轨迹概率，同一终态对应许多路径，随机重掩码还可能构造出真实 rollout 从未访问的上下文。

二维图像展平为一维序列后，模型还需恢复空间关系。自回归栅格顺序本身含有局部邻接，而掩码扩散的恢复次序由置信度、调度和随机采样共同决定，需要二维位置编码、行列标记或分块机制补充空间结构。一次恢复多个位置能减少同步轮数，但每一轮 Transformer 前向仍需处理长序列，classifier-free guidance 还可能引入条件与无条件计算。若每轮只保留少量位置，过程退化为长步数迭代；若过早固化过多位置，错误结构可能难以纠正。因此，视觉 tokenizer、空间编码、掩码日程和主干计算共同决定质量与效率，不能把“并行 token”简单等同于“低延迟”。

《Sketch Then Paint》在所考察底座和采样协议中，将较早恢复且高熵的 token 作为结构近似，并报告了层次更新收益[3]。这一结果支持“生成顺序可能包含可利用的层次信息”，尚不足以证明早期 token 普遍等同于轮廓或布局。高置信背景可能很早出现，复杂主体的关键边界也可能较晚稳定；后续优化需要把顺序作为可检验先验，并结合预测熵、空间区域和对终局奖励的敏感度判断其适用范围。

### 1.3 生成与理解统一模型的技术谱系及比较

“统一多模态模型”至少包含架构共享、表示共享和学习目标共享三个层次，不能仅因一个系统同时支持问答和文生图就认为三者都已统一。按图像生成机制，现有代表工作可分为三类。第一类把文本和离散图像都视为序列并使用下一 token 预测，Emu3 代表这种全自回归路线[18]；Janus-Pro 则通过解耦的视觉编码路径缓解理解与生成对表示需求不同的问题，同时保留共享主体模型[19]。这类方法的联合分布定义直接，但图像长序列仍带来逐 token 解码成本。第二类在同一 Transformer 中组合不同目标，Show-o 对文本采用自回归建模、对图像采用离散扩散[20]。它共享主体参数，却没有把两种模态的生成过程变为同一目标。第三类进一步采用双向注意力和掩码预测处理多模态 token，试图在统一离散扩散目标下覆盖理解与生成；MMaDA、Muddit、Lumina-DiMOO 和 LaViDa-O 属于这一方向[4, 21–23]。

语言扩散模型为第三类路线提供了初始化和训练基础。LLaDA 将掩码扩散扩展到语言建模[24]，从自回归模型迁移参数的研究表明，适配可以降低从头训练扩散语言模型的成本[25]。LLaDA-V 通过视觉指令微调使扩散语言模型读取图像并回答问题[26]，但视觉理解能力本身不等于具备图像生成。横向看，全自回归路线以统一的下一 token 目标换取清楚的概率分解，但图像端仍需顺序解码；Show-o 类混合路线共享主体参数，同时保留适合不同模态的生成目标；全掩码扩散路线进一步统一双向条件建模，却更依赖视觉 tokenizer、掩码日程和多轮采样。现有结果尚不能隔离统一目标、tokenizer、模型规模和训练数据各自的贡献，因此跨模型优劣只能在统一 checkpoint 与评测协议下判断。

所附 Lumina-DiMOO 论文给出了全离散统一模型的完整实例[4]。该模型以扩散语言模型为初始化，在文本词表之外使用包含 8192 个离散符号的视觉词表，使用同一个双向 Transformer 和掩码预测目标处理两种模态。其图像 tokenizer 的空间下采样率为 16，1024×1024 图像对应 4096 个视觉位置，并通过行结束标记保留二维形状信息。训练由图文预训练、多任务中期训练、监督微调和 Self-GRPO 组成，覆盖文生图、编辑、主体驱动、控制生成、补绘、外扩和视觉问答。这个例子说明架构统一需要数据和阶段化训练配合；仅共享主干并不能自动消除生成与理解之间的目标冲突。

在论文报告的同一设置内，Lumina-DiMOO 基础模型的 GenEval 总分为 0.88，Self-GRPO 后为 0.91，颜色与属性绑定分项由 0.89、0.76 提升至 0.95、0.82[4]。这些数值支持理解分支能够构造对生成有用的语义反馈，但 GenEval 只评价生成图像是否符合对象和属性要求，不能由此推出视觉理解能力同步提高。证明“生成—理解协同”至少需要三类证据：生成指标改善、独立理解基准不退化，以及评价分支与人工或外部判断保持相关。若只有第一类证据，更准确的结论是“理解分支为生成提供了有效训练信号”。

统一模型还面临长序列和多轮采样的系统矛盾。Lumina-DiMOO 在所报设置下使用最大 logit 缓存复用稳定 token 表示，将 1024×1024 文生图时间由约 45 秒降至约 22 秒，同时峰值显存由 38.9 GB 增至 45.9 GB，且缓存为有损近似[4]。这一结果体现了计算、内存和误差的交换：网络级缓存减少重复计算，但不决定哪些候选值得继续；序列剪枝可以缩短输入，却可能破坏全局关系；算法级预算分配能够减少低价值轨迹或步骤，却要承担评分与调度开销。后续工作需要在相同硬件、批量、分辨率与解码设置下分别报告主模型、验证和图像解码成本，才能比较不同层面的效率优化。

综合而言，现有统一模型已经证明共享主体网络可以覆盖多种理解和生成任务，却尚未形成单一最优范式。全自回归路线具有清楚的概率分解，混合目标路线保留各模态的成熟机制，全掩码扩散路线则提供双向条件建模和并行恢复。本文选择第三类路线，是因为非固定去掩码顺序、内部理解反馈与可调采样步数共同形成了独特优化空间；这一选择并不意味着其他统一架构在能力或效率上天然较弱，所有结论都应限定在可比底座和评测协议内。

### 1.4 奖励后训练、离散策略概率与层次信用分配

最大似然或掩码预测训练优化的是数据分布上的局部预测，而实际生成评价通常关心完整图像的提示遵循、审美、感知质量或人类偏好。奖励后训练试图缩小两者差距。PPO 以裁剪概率比限制策略更新幅度[27]，GRPO 在同一输入下比较多条样本，以组内相对奖励构造优势，从而减少对独立价值网络的依赖[28]。在连续扩散图像生成中，DDPO 把逐步去噪视为策略轨迹，直接依据终局奖励优化扩散模型[29]；Diffusion-DPO 则把成对偏好转化为无需单独训练显式奖励模型或执行在线 RL rollout 的直接偏好目标[30]。前者说明扩散生成模型可以通过策略梯度依据外部终局奖励更新，奖励本身不必对生成图像可微；后者说明离线偏好也能改变生成分布。但两者所处理的是连续状态和预定时间序列，不能直接回答离散掩码扩散中“哪些 token 在何时成为动作”的问题。

离散掩码生成的困难首先来自轨迹定义。自回归模型的联合概率按固定位置顺序分解；掩码扩散在一轮内同时给出多个位置的类别分布，再由置信度与随机性以及掩码日程决定写入集合。同一最终图像可以经由不同写入次序产生，轨迹概率不仅包含 token 类别概率，还与位置选择事件有关。若将最终每个 token 当作彼此独立的动作，会遗漏并行选择和调度的贡献；若严格保存每一轮状态、位置事件与新旧策略概率，计算和显存又随序列长度、采样步数及 rollout 数量增长[3, 31–32]。离散 RL 的关键取舍因此不是“要不要使用奖励”，而是如何在训练上下文忠实度、概率估计偏差和可承受开销之间平衡。

现有离散扩散强化学习大体采用三类上下文。第一类随机重掩码最终样本，代表方法包括 MaskGRPO[31]。它无需保存完整轨迹，能够在同一图像上构造多种掩码组合，但可见 token 可能含有真实 rollout 中尚未生成的未来信息，导致训练条件与行为策略不一致。第二类保存实际去掩码轨迹。TraceRL 主要面向扩散语言模型；《Sketch Then Paint》依据其轨迹记录思想构造图像生成对照 TraceGRPO[3, 32]。该路线可减少未来信息污染，却需要缓存多个长序列中间状态，且单条图像只覆盖已经采样的一条顺序。第三类在统一的全掩码、仅文本可见上下文中估计概率，使所有位置都不接触图像答案，计算更规整，但同时删除了真实过去信息，因此属于有偏代理而非真实轨迹概率[3]。三类方法分别换取覆盖度、忠实度和效率，不宜只用最终分数判断哪一种估计“更正确”。

第二个困难是图像级奖励与 token 级动作之间的信用分配。将同一个终局优势广播给全部视觉 token，隐含假设每个位置和阶段贡献相同；实际生成中，改变对象数量、空间关系的决策与补充背景纹理的决策对语义指标影响不同。另一方面，固定给早期 token 更高权重也不是严格的因果估计，因为某个早期状态能否获得高回报取决于后续策略如何补全，同一结构经不同随机补全可能产生很大方差。更恰当的区分是“状态价值”和“动作边际贡献”：前者表示给定部分结构后继续生成的期望回报，后者表示替换或重掩码某个动作造成的价值变化。精确计算需要多次条件补全或反事实 rollout，成本较高，因此现有方法多使用生成秩、预测熵或分组权重作为近似。

《Sketch Then Paint》提出 HT-GRPO，将 rollout 中较早恢复且高熵的视觉 token 视为结构集合，较晚 token 视为细化集合，在全局、结构和细化三个阶段分配不同训练预算与信用权重[3]。该方法使用全掩码文本条件估计概率比，以避免随机重掩码的未来信息污染和真实轨迹的缓存开销。其代价是代理分布不含真实已生成上下文，不能与行为轨迹条件概率等同。方法所利用的“早期更偏结构”应理解为统计先验，而不是逐 token 的语义标注。

在该稿件所报的同一实验协议内，HT-GRPO 将 MMaDA 的 GenEval 从 0.56 提升至 0.83，MaskGRPO 对照为 0.80；在 Lumina-DiMOO 上由 0.83 提升至 0.92，MaskGRPO 对照为 0.88，DPG-Bench 也报告同方向增益[3]。这些结果支持层次信用在指定底座、提示集与评价器上的有效性，但尚不能证明固定结构比例或全掩码概率代理具有普适性。稿件属于最新公开工作，相关结论还需在更多采样日程、分辨率和非文生图任务中验证，并与相同训练预算、rollout 数量和奖励模型的基线比较。

现有研究由此形成清晰而未闭合的链条：连续扩散 RL 证明终局奖励能够优化生成策略[29–30]，离散方法提出了可计算的概率代理[3, 31–32]，层次方法进一步承认阶段贡献不同[3]。仍然缺少的是对代理偏差、轨迹成本和动态信用的统一测量。评价此类方法时应同时报告奖励提升、独立测试指标、策略 KL、概率比裁剪率、样本多样性、训练显存和 GPU 时间；若只报告训练奖励或单一对齐指标，无法排除奖励过拟合、模式收缩或计算换分数。

### 1.5 生成—理解自反馈与推理时轨迹扩展

统一模型的特殊能力在于它可以读取自己的输出并形成内部反馈。常用外部评分包括 CLIP 和 ImageReward[33–34]；DDPO 与 Diffusion-DPO 又展示了外部奖励或偏好数据如何改变扩散生成策略[29–30]。外部评价器与生成模型参数分离，标准相对稳定，但会增加计算和部署复杂度，其偏好也可能与目标模型、提示分布或人工判断不一致。内部评价器无需引入另一套大型模型，还能把提示分解为对象、数量、颜色和关系问题，再通过视觉问答给出结构化反馈。不过，生成器和评价器共享参数或训练数据时，二者也可能共享盲区，内部一致不等于对人类正确。

UniRL 探索了通过监督学习和强化学习使统一多模态模型自我改进[35]。Lumina-DiMOO 的 Self-GRPO 针对同一提示生成多张图像，将提示中的实体、关系、数量和颜色转为选择题，由模型理解分支作答，并以正确答案数量构造组内奖励[4]。其训练联合生成目标、理解目标和 KL 正则，为控制 4096 个视觉位置带来的显存，只在部分扩散时间步反向传播。与只给一个整体相似度相比，问答反馈能够指明计数、绑定或关系中的具体错误；与外部视觉语言模型相比，它复用统一主干。然而，当前生成指标提升只能证明这种反馈对生成有效，不能单独证明理解分支本身提高。

内部自验证有三类可靠性风险。第一，模型可能根据提示先验猜答案，而没有真正读取图像；可通过无图输入、交换图像、遮挡区域和反事实问题检验图像证据是否改变判断。第二，若生成和评价分支同步更新，奖励标准随策略变化，模型可能学会产生便于自身判对、却不符合外部观察者的模式；冻结评价器能稳定标准，却又无法适应新的生成分布。第三，结构化问答容易覆盖对象和属性，难以充分评价审美、文字、局部伪影、真实感和多样性。因此，内部反馈需要与冻结的外部指标、独立理解集和人工盲评交叉验证，并报告置信度校准，而不能把自评分当作客观真值。

在参数保持不变时，另一种提高生成质量的途径是增加推理计算，即 test-time scaling。连续扩散中的代表工作从扩展初始噪声候选、以奖励或价值函数筛选、在中间状态搜索以及反思式迭代等方向展开[36–39]。最简单的 best-of-N 为同一提示完整生成 N 张图像再选择最好结果，容易实现和并行，但主模型成本随 N 近似线性增长；若每条候选又尝试 T 种细化设置，朴素组合需要约 N×T 组生成。树或分层搜索在中间状态剪枝，把预算集中给高潜力分支，却面临不完整图像难以评价的问题：越早剪枝越能节省计算，评价噪声和误删风险也越大。

dMLLM-TTS 将离散扩散的推理扩展分为轨迹探索和迭代细化两条轴[5]。轨迹探索扩大初始结构假设，迭代细化增加保留轨迹的恢复深度；其自验证把文本—图像一致性转化为视觉问答，并用模型自身理解分支评分。分层轨迹搜索先探索多个结构，再保留固定宽度 K 的候选继续细化，避免对所有 N 个候选执行全部 T 种后续配置。在 K 视为固定且只统计主模型前向的预算模型下，所需 NFE 可由朴素组合的量级 O(NT) 降为近似由探索与细化相加的 O(N+T)。这一表述依赖固定保留宽度、共享计算和具体实现，验证问题生成、问答、解码、数据搬运与不规则批处理并未包含在该渐近记号中。

CVPR 版本在 Lumina-DiMOO、MMaDA 和 Muddit 上报告了质量增益，并在其设定下相对线性搜索获得最高约 6 倍的主模型前向计算效率改善[5]。该最高值仅代表论文特定配置下的主模型计算变化，不等同于普遍端到端加速。扩展版 dMLLM-TTS v2 又加入多种采样调度器，并聚合提示遵循、审美和质量信号[40]。该稿件在 T=32、N=32、K=8 的代表设置下报告：线性轨迹搜索 GenEval 为 0.91，分层搜索为 0.93；在相近总体得分下，后者 NFE 约为前者五分之一。[40] 尚未形成正式卷期，本文仅将这些数字作为未发表作者稿在指定配置下报告的阶段性证据，不与正式发表结果合并比较。

自反馈训练和推理搜索虽然发生在不同阶段，却共享同一瓶颈：价值信号是否可信。训练时错误反馈会改变参数并长期积累，搜索时错误评分会提前剪除可恢复轨迹。完整图像适合评价细节和审美，中间状态更适合判断粗略对象与布局，验证粒度应随生成阶段变化。多评分器可以覆盖语义、感知和偏好，但简单加权会受量纲与相关性影响，还可能增加足以抵消主模型节省的计算。评价这一路线应同时测量验证器与人工判断的相关性、早期误删率、候选多样性、主模型 NFE、验证 NFE、端到端时延和峰值显存。

现有证据说明，统一模型的理解能力既可形成训练奖励，也可用于推理时选择轨迹[4–5, 35, 40]。尚未解决的问题是内部评价在中间生成分布上的校准、共享偏差如何被独立发现，以及搜索收益如何避免在每个请求中重复支付。前两项决定“选得准不准”，后一项连接推理扩展与少步学习。

### 1.6 少步生成、扩散蒸馏与搜索经验迁移

蒸馏的目标是将多步教师的生成能力迁移给少步学生。连续扩散已形成至少三种代表性路线。渐进蒸馏每轮让学生用一步逼近教师的两步确定性更新，再反复将步数减半[9]；一致性模型要求同一概率流轨迹上的不同噪声状态映射到一致的干净样本，可通过教师蒸馏或直接训练获得一步及多步生成能力[10]；分布匹配蒸馏不要求学生逐点复制某条教师轨迹，而是利用真实与生成分布的得分差异训练一步生成器[11]。三类方法分别强调局部轨迹压缩、跨时间一致性与边缘分布匹配，说明“少步”并不存在唯一监督对象。

这些连续方法不能不加改变地用于掩码离散扩散。连续状态之间可以定义数值距离，渐进蒸馏和一致性蒸馏还可在确定性采样器或概率流轨迹上构造对齐监督；掩码离散学生的一步输出则可能同时改变大量类别 token，且教师预测依赖已经揭示的离散上下文。若学生直接匹配最终完整图像，监督稀疏且高方差，也难以定义像素或 token 的一一对应；若逐轮模仿教师，则可能保留原有采样步数；若只匹配每个位置的边缘类别分布，又会忽略对象结构和位置间相关性。少步离散生成还面临训练—推理状态偏移：教师轨迹上的干净中间状态与学生实际产生的错误或不完整结构不同，学生在未见状态上继续生成时可能积累误差。

Di[M]O 通过匹配多步教师与一步学生的输出分布，将掩码图像生成模型蒸馏为一步生成器[41]。现有可核验材料没有提供可用于本报告独立复算的同协议质量差值，因此本文不引用其具体实验数字，也不据此推断一步模型在一般情况下必然弱于教师。近期工作进一步尝试学习潜空间受控动力学来跨越多步掩码状态[42]，反映出研究重点正在从“删除步骤”转向“学习跨步状态转移”；[42] 为 2026 年预印本，相关结论限于其公开稿件范围。

一步生成具有最低同步轮数，却可能把全局布局和局部纹理压在同一高难度决策中。少数步生成提供另一种折中：前几步建立可补全结构，后几步在结构条件下恢复属性与细节。这里的关键不只是给总步数设定一个较小值，而是决定学生学习什么。若监督对象是教师终态，学生可能复制高分样本而丢失分布覆盖；若监督对象是教师中间 token 分布，需要保证教师和学生处在可比状态；若监督来自搜索最优样本，还会产生选择偏差，因为高分尾部受到验证器偏好影响。评价少步方法应同时比较固定步数下的质量、固定质量下的真实时延、输出多样性、教师调用成本和训练数据生成成本。

推理搜索日志原则上可为蒸馏提供比单条教师轨迹更丰富的信息：候选组不仅包含“哪张图最好”，还可通过重复补全估计哪些部分结构保持高回报、哪些状态容易被教师修复、哪些提示需要更宽探索。现有测试时扩展主要在每次请求中使用候选信息[5, 36–40]，现有离散蒸馏则侧重压缩教师生成过程[41–42]，二者的监督对象和计算账本通常分开。若只将搜索选出的最终图像作为训练目标，学生可能复现验证器偏好而不知道分支优劣；若保留候选的相对价值及条件补全分布，才可能把预算选择与跨步生成联系起来。

截至 2026 年 10 月，在本文覆盖的公开文献和本课题可核验材料范围内，尚未见一种离散扩散多模态生成方法同时系统处理以下三点：以多次条件补全估计部分结构的期望价值；在学生实际访问状态上构造跨步教师监督；以同一质量—效率协议验证搜索收益是否转化为少步端到端收益。这一判断不等同于搜索与蒸馏从未被结合；若出现同时处理上述要素的公开工作，本课题的创新边界将相应收窄并纳入同预算比较。

### 1.7 评价体系、可比性与证据边界

生成优化至少需要同时评价语义遵循、感知质量、多样性、理解能力、系统效率和训练稳定性，单一总分不能覆盖全部目标。GenEval 以对象为中心，将单对象、双对象、计数、颜色、位置和属性绑定拆分评价，适合诊断组合语义[1]；DPG-Bench 使用更稠密的提示考察复杂文本遵循，其来源工作为 ELLA[2]。ImageReward、HPSv3、DeQA 和 Unified Reward Model 分别从人类偏好或感知质量角度提供补充[34, 43–45]。这些自动指标并非可互换：对象检测式指标对构图与真实感不敏感，CLIP 类相似度可能忽略计数和绑定，偏好模型可能奖励特定风格，质量回归模型又未必反映文本一致性。因此，应按能力维度分别报告结果，并避免把训练使用的奖励同时作为唯一测试指标。

统一模型还必须检查“生成提高而理解退化”。本课题选用 POPE 诊断对象幻觉及 yes-bias，选用 MMBench 覆盖较广的细粒度感知与推理[46–47]。二者分别对应“对象幻觉”和“总体理解”两个互补终点；若研究范围后续扩展到专家知识、视频或文本密集场景，再采用与任务接口相符的专门基准。理解评测使用优化前后同一模型、提示模板和解码配置，并同时报告准确率、校准及无图/交换图像对照，判断模型是否真正利用视觉证据。

对自反馈和多目标奖励，还需要验证评分器本身。应在独立人工标注子集上测量内部问答得分、外部奖励与人类判断的相关性，记录不同错误类型的假阳性和假阴性。训练时使用的问答模板、奖励模型和提示集合不能与最终测试完全重合，否则提升可能来自奖励记忆而非泛化。若多种奖励经加权组合，应报告各分量的尺度、相关性和消融；如果只给加权总分，无法判断模型究竟改善了语义、审美还是迎合某一评分器。人工评价应采用盲评、随机呈现和明确的胜负/平局规则，并报告样本数与置信区间。

效率评价必须建立完整计算账本。NFE 便于统计主模型前向次数，却不能涵盖提示解析、问题生成、视觉问答、多个奖励模型、VAE/视觉 tokenizer 解码、缓存维护、CPU—GPU 数据搬运和动态批处理。分层搜索可能降低主模型 NFE，却因分支长度不同降低 GPU 利用率；缓存减少重复计算，却提高峰值显存；少步学生减少同步轮数，但若每步扩展更多候选，其时延不会与步数同比下降。因此，至少应报告相同硬件和软件环境下的单图延迟、固定批量吞吐、峰值显存、主模型 NFE、验证 NFE 和训练 GPU-hours，并分别在固定预算下比较质量、在固定质量下比较延迟。只有端到端测量支持时才使用“实际加速”，其余应写为“NFE 降低”或“理论主干计算减少”。

稳定性与多样性同样属于证据链。奖励优化可能因组内样本分数接近而缺乏有效优势，也可能因奖励差异过大导致策略快速偏离参考模型。应使用多个随机种子报告均值和方差，并监控奖励方差、有效样本量、策略 KL、裁剪率、梯度范数及失败率。对于生成结果，还需检查提示间与同提示多样性，避免以模式收缩换取自动指标。少步蒸馏应区分教师生成数据成本与学生部署成本；推理搜索则应说明候选能否并行及批量变化。没有这些信息，质量—效率结论难以复现。

跨论文数值只适合说明趋势，不宜拼接为统一排行榜。即使使用同名底座，不同 checkpoint、分辨率、CFG、采样器、提示集、检测器版本和随机种子都会改变 GenEval 或 DPG-Bench。所核验的 Lumina-DiMOO 相关稿件存在基础分差异，可能源于模型和协议更新，因而不能用一个论文的基线与另一个论文的方法分数直接相减。可信比较优先采用同一论文同一表中的增量；跨论文比较则重新运行统一评测代码，并公开配置与 checkpoint。

多参考图像创作与编辑可作为文生图之外的外部有效性测试。MICE-Bench 从提示或指令遵循、概念一致性、物理真实性、图像美学与质量、图像结构及非编辑区域一致性等维度评价该任务[48]；本课题仅在资源允许的迁移验证阶段使用，不作为核心结论成立的必要条件。

本综述按正式发表论文、公开预印本、未发表作者稿和答辩材料区分证据等级；实验数值仅在其原始协议和公开状态内解释。稿件真实存在不等于结论已获独立验证，个人研究基础也按本人主导、主要负责和团队共同成果分别陈述。

### 1.8 国内外研究格局、现有空白与本课题定位

从全球研究脉络看，图像生成先后经历连续扩散质量提升、离散视觉表示与序列建模、统一多模态架构、奖励后训练和推理时扩展等阶段。DDPM、潜扩散、VQ-VAE/VQGAN、MaskGIT 和 D3PM 奠定了连续与离散生成基础[6–7, 12–13, 15–16]；Emu3、Show-o、Janus-Pro 等展示了不同程度的理解—生成统一[18–20]；近年的 MMaDA、Muddit、Lumina-DiMOO 和 LaViDa-O 则把统一目标进一步推进到多模态掩码扩散[4, 21–23]。与此同时，连续扩散中的奖励优化、偏好学习、推理扩展和少步蒸馏提供了可借鉴的优化框架[9–11, 29–30, 36–39]。这些方向并非线性替代关系，而是在表示空间、概率分解、在线预算和离线训练成本上采取不同权衡。

从国内相关进展看，MMaDA、Muddit、Lumina-DiMOO 和 LLaDA-V 等工作覆盖统一离散底座与视觉指令建模[4, 21–22, 26]，Sketch Then Paint 与 dMLLM-TTS 又将重点推进到层次信用和自验证搜索[3, 5, 40]。与连续扩散中较成熟的奖励对齐、推理扩展和蒸馏路线[9–11, 29–30, 36–39]相比，这些工作更集中于共享离散主干所产生的轨迹定义和内部反馈问题。多篇成果由跨机构团队合作完成，地域描述仅用于概括研究参与，不表示排他的学术归属。

第一项研究空白是离散生成的信用粒度仍不充分。随机重掩码、真实轨迹和全掩码代理分别在覆盖度、忠实度与成本上取舍[3, 31–32]，但多数方法仍以图像级优势更新大量 token。层次权重开始区分结构和细化阶段，却依赖固定比例或生成次序先验。现有证据尚未回答生成秩、预测熵、空间结构和反事实奖励变化之间是否存在稳定关系，也缺少在统一预算下对概率偏差、训练内存和最终泛化的联合比较。

第二项研究空白是推理预算分配受到验证噪声限制。best-of-N 对完整结果评价较可靠，但重复生成成本高；中间状态剪枝节省主模型计算，却可能因图像不完整而误删后续可恢复轨迹[5, 36–40]。内部视觉问答能够检查对象、数量和关系，但其在自身生成分布上的校准、对文本先验的依赖及与外部评价的相关性尚未充分建立。现有工作多报告质量和主模型 NFE，验证器成本与真实延迟的完整账本仍不统一。

第三项研究空白是生成—理解闭环的收益与风险尚未同时验证。Self-GRPO 等工作说明理解分支可以构造有效生成奖励[4]，但生成指标提升不能替代理解基准；评价器共同更新又可能产生非平稳标准。当前证据需要从“能否自评分”推进到“自评分何时可信”：内部奖励应与人工判断、冻结外部指标、POPE 和 MMBench 等独立理解测量共同检验[46–47]，并明确评价器更新方式与失败类型。

第四项研究空白是在线搜索经验尚未充分迁移为少步能力。推理搜索能够发现高价值候选，却在每个请求中重复支付探索和验证成本；一步蒸馏减少在线步骤，却可能丢失结构、细节和多样性[5, 40–42]。连续扩散的轨迹压缩、一致性和分布匹配提供了三种监督视角[9–11]，但离散模型还要处理并行 token、条件可见集合和学生状态偏移。在本文检索范围内，尚缺乏把部分结构的期望补全价值、学生访问状态上的跨步监督及端到端效率验证放进同一框架的系统研究。

上述四项空白可由一个共同视角连接：价值信号作用于不同尺度。token 尺度决定训练时更新哪些决策，轨迹尺度决定推理时继续计算哪些分支，反馈尺度决定由谁判断输出，步数尺度决定哪些中间计算可以被学生跨越。把四者放在同一质量—成本协议下研究，有助于避免多个算法的简单堆叠，也使每项结论都能通过独立消融检验。该定位来自现有方法的比较，不预设“早期 token 必然代表结构”或“内部反馈必然优于外部评价”，而是把这些主张转化为可证伪假设。

本课题已有的 HT-GRPO、dMLLM-TTS 与 Self-GRPO 分别为层次信用、轨迹搜索和内部反馈提供阶段性证据[3–5, 40]，粗到细少步生成则构成后续需要完成的环节。相关证据具有不同公开状态：dMLLM-TTS 已正式发表[5]；Lumina-DiMOO 与 Sketch Then Paint 按公开预印本引用[3–4]；dMLLM-TTS v2 为未发表作者稿[40]，答辩材料标注其处于 TPAMI 在审阶段。Lumina-DiMOO 底座属于团队成果，本人主要负责 Self-GRPO，不将整个底座归为个人独立成果。

从学术意义看，本课题关注非固定生成顺序中的层次结构、终局奖励到并行 token 的信用传递、内部评价在生成分布上的可靠性，以及搜索经验向少步学生的迁移。这些问题共同指向离散并行生成的价值建模。即便某项顺序先验只在部分提示或底座上成立，明确其有效范围和失败条件也能深化对生成机制的理解。从工程意义看，统一报告固定预算质量、固定质量时延、独立理解指标、人工偏好与稳定性，可以把“指标提高”转化为可复验的质量—效率结论，为交互式创作和多参考编辑等高约束应用提供更可信的部署依据。

### 2.2 主要研究内容

#### （1）生成层次感知的强化学习优化

研究非固定去掩码顺序中位置选择与 token 类别预测的信用分配。依据真实 rollout 中的生成秩、预测熵、跨步稳定性和少量反事实补全结果，学习提示相关的结构概率；在匹配 rollout 数、反向 token 数、优化步数和训练 FLOPs 的条件下，对图像级组内优势进行动态加权。全掩码上下文仅用于构造低成本的提示条件代理比率，不把它解释为真实行为轨迹的重要性比。该研究输出结构概率、token 权重和经校准的生成策略，并明确顺序先验成立与失效的提示范围。

#### （2）自验证驱动的推理搜索优化

研究不完整状态的条件补全价值估计和推理预算分配。探索阶段生成具有不同随机种子、温度或历史调度器的结构候选；评价阶段将候选对齐到同一决策阶段和剩余预算，并在状态副本上统一采用门 A 冻结的共同继续调度与 π_cont，执行 P_t 次独立、同预算的临时补全，形成可解码的 probe image，再由统一模型的冻结目标评价器进行结构化问答，临时 token 不写回活动轨迹；剪枝阶段依据均值和标准误形成的区间延迟淘汰不确定候选，并保留固定探索配额。P_t 的最小值、最大值和序贯停止规则由 pilot 冻结。主设置不依赖额外大型多模态验证器；所有临时补全、验证及解码成本均计入端到端账本。该研究输出候选状态、在线搜索价值 V̂_search、保留或淘汰标签、调度信息和在线观察日志；只对预抽取的训练审计子集另行输出无删失近似终局价值，供少步学生使用。

#### （3）生成与理解协同的可校准自反馈

研究内部语义反馈是否真实依赖图像证据，以及该反馈用于参数更新时是否稳定。阶段 3A 固定生成器，仅用独立带标签数据和审计样本校准目标评价器，输出不依赖研究内容一的代理效用及可靠性界限；阶段 3B 再以预先固定的基础信用规则更新生成策略，并将研究内容一的动态信用作为“反馈来源×信用方式”的独立因子消融。由提示得到的对象、数量、颜色与关系答案只用于评价生成结果是否满足条件，不直接作为错误生成图像的理解训练标签；理解分支仅使用独立可靠标签或经人工、外部工具确认的训练样本更新。目标评价器使用与在线统一模型物理分离的完整参数快照，在阶段内冻结，对奖励路径停止梯度，并用无图、错图、遮挡和反事实问题检测提示泄漏。

#### （4）粗到细蒸馏与推理加速

研究将搜索候选的相对价值和教师条件转移迁移到单轨迹少步学生。对同一提示产生 H 个结构候选，每个候选由冻结教师独立补全 M 次，用经校准的训练代理效用均值估计教师价值 V̂_teacher，并保留低价值候选学习决策边界。学生在自身访问状态上蒸馏目标窗口内的位置恢复频率和相应 token 类别投影分布；主设置沿用固定恢复数量日程，恢复数量分布只作为可学习日程的辅助扩展消融。对于低置信可见 token，比较固定与允许重掩码纠错两种机制。推理主设置只运行一条学生轨迹，以 K_s 步形成结构、K_r 步完成细化，并在固定步数预算 B_step＝K_s+K_r 下研究阶段分配。独立审计价值 V_audit 和 oracle 标签只读，不进入训练或模型选择。

四项内容共享同一状态、动作和价值接口，但在实验上保持可分离。内容三提供代理效用及其可靠性界限；内容一检验该效用能否合理分配到位置与类别决策；内容二检验中间状态价值能否在扣除验证成本后改善预算分配；内容四检验搜索相对偏好和教师跨步转移能否被单轨迹学生吸收。只有接口信息在同等计算预算下带来可重复增量，才认为相应环节支持总体主线。

### 2.3 拟解决的关键问题

第一，生成次序和不确定性是否包含可用于 token 信用分配的增量信息。本课题不预设“早生成 token 等同于结构 token”，而检验生成秩、预测熵、跨步稳定性与空间连通性以及反事实价值差的关系。在固定采样数、更新次数和训练计算下，与随机分组、均匀信用、仅按熵或仅按置信度加权的基线比较。若动态结构概率不能提高对干预敏感度的预测，或最终增益可由额外更新预算完全解释，则该假设不成立，生成次序只能作为经验调度特征。

第二，含噪内部评价能否在不完整状态上可靠排序轨迹，并在计入验证开销后改善质量—计算折中。研究分别测量中间价值排序相关、top-K 召回、优质轨迹误删率、校准误差和阶段稳定性。若内部评价在早期状态上的排序接近随机，或临时补全、问题生成和视觉问答的额外时延抵消主模型前向节省，则不把 NFE 降低解释为实际加速，并限制自验证只在可靠阶段使用。

第三，统一模型的理解能力能否形成依赖图像证据、可校准且在训练中保持稳定的生成反馈。研究通过无图输入、错图交换、图像遮挡、反事实问题和人工标注子集，检验评价器是否真正读取图像；通过冻结目标评价器、慢速同步和独立理解数据控制奖励非平稳与循环监督。若内部奖励与独立判断的相关性持续下降、理解能力退化超过预设非劣界，或错图与无图条件仍获得相近得分，则不能认为形成了可信协同。

第四，搜索所得相对价值和教师条件转移能否迁移为单轨迹少步生成能力。学生使用真实搜索候选组、保留或淘汰标签、校准价值和教师后续补全，同时学习下一阶段应恢复的位置及其类别分布。若联合方案相对纯蒸馏、纯结构强化或随机候选蒸馏没有稳定增量，若质量损失超过非劣界，或只减少 NFE 而未改善端到端时延，则搜索经验迁移假设不成立，应退回分阶段训练或把结论限定为核心计算降低。

## 三、拟采取的研究方法、研究方案及其可行性分析

### 3.1 总体技术路线

首先在可获得权重、代码和评测条件的代表性离散扩散多模态模型上建立统一实验接口，固定数据划分、分辨率、提示集合、解码方式和评测实现，复现基础推理、均匀信用、随机剪枝、best-of-N、代表性后训练与蒸馏基线。所有训练、搜索和蒸馏过程统一记录扩展状态 s_t、位置集合 S_t、类别分布、生成秩、预测熵、跨步变化、剩余预算、采样调度、策略 checkpoint、评价器版本、终局结果和成本，使不同研究只在相同状态—动作—价值口径下交换数据。

第二步建立价值信号可靠性基线。终局效用由与训练信号解耦的自动指标和人工评价共同刻画，统一模型产生的结构化问答分数只作为代理效用。数据互斥划分为自反馈训练集、用于同步与早停的 validation-audit 集，以及配置锁定后只运行一次的 final-audit 集；人工最终评价样本不进入理解训练。通过无图、错图、遮挡和反事实问题测量图像依赖性，通过独立校准子集和评分器测量排序相关与校准误差。主训练方案使用与在线策略物理分离、阶段内冻结的目标评价器并对奖励路径停止梯度；理解分支只在独立可靠标签上更新，达到预注册校准条件后才在阶段边界慢速同步。该步骤输出经校准的目标评价器及其适用阶段。

第三步分别验证训练端信用分配和推理端预算分配。训练端从真实 rollout 提取生成秩、熵、稳定性和反事实干预结果，在相同更新预算下比较均匀、固定层次和动态层次信用；全掩码上下文只构成低成本代理目标，另以真实中间状态测量偏差。推理端在候选状态副本上执行 P_t 次同预算独立临时补全，以均值和标准误执行延迟剪枝、保留探索配额和阶段感知复核；搜索成本同时统计主模型、全部 P_t 次临时补全、验证、解码与调度开销。

第四步构建搜索记录集和粗到细学生。搜索模块对同一提示输出全量候选结构、在线相对价值、保留标签和采样调度日志；仅对预注册规则分层抽取的 H 个训练候选执行冻结教师后续补全并形成无删失标签。学生从抽取状态和周期性刷新得到的自身访问状态出发，一方面通过组内排序或相对优势学习高价值结构选择，另一方面同时蒸馏教师的下一阶段位置分布和新增位置类别分布。主部署设置仅保留一条学生轨迹，在固定总步数内完成结构形成与细节补全；多候选模式仅作为增强设置单独报告。

最后开展跨环节消融与外部有效性验证。依次移除校准评价器、动态 token 信用、搜索候选偏好、位置监督和类别监督，判断各接口的独立贡献；先在一个底座完成主结论，在资源和阶段门允许时再验证第二底座。若代理评价未达到可靠性门槛，则不进入联合训练；若联合损失长期冲突，则转为先蒸馏后强化；若 NFE 降低未转化为时延改善，则只报告算法计算变化。

### 3.2 研究内容一的方法方案

设第 t 步扩展状态为 s_t，当前掩码集合为 M_t，本轮新增恢复的位置集合为 S_t，位置上的类别动作记为 y_t(S_t)。主实现把三项机制分开：固定且不训练的掩码日程只决定本轮恢复数量 m_t＝|S_t|；由类别分布的置信度、不确定性和可学习结构分数组成的位置评分 q_θ(i｜s_t，c) 对候选位置排序并确定前 m_t 个位置；类别分布决定这些位置写入什么 token。确定性的前 m_t 选择只作为策略诱导的决策记录，不宣称存在独立的随机集合策略概率；可学习位置头和随机无放回选择仅作扩展，并分别报告结构、集合概率、KL 与部署成本。对同一提示采样 G 条完整轨迹，记录生成秩及阶段内置信度、跨阶段条件熵、跨步 logit 变化和空间位置。这里区分两类量：早期阶段因上下文较少可具有较高平均条件熵，而同一阶段内被优先固化的位置仍可能是相对高置信位置。

结构概率 s_i 表示位置 i 在当前提示和轨迹中承担高影响决策的估计概率，不等同于对象轮廓标签。其候选特征包括生成秩、预测熵、跨步稳定性、对象或边界区域统计，以及对该位置执行保留、替换或重掩码后条件补全价值的变化。对同一结构使用配对随机数完成多次后续补全，以降低反事实比较的随机方差；位置选择贡献和类别选择贡献分别分析。组内终局奖励标准化为图像级优势 A_g，token 权重在 batch 内归一化到平均值 1，使不同信用方案具有可比的平均梯度尺度。

真实 rollout 动作依赖部分可见状态 s_t，而全掩码代理在仅文本可见的上下文中计算当前策略与行为策略快照的类别概率比：r̃_i(θ)＝p_θ(y_i｜c，[M]^N)／p_θ_old(y_i｜c，[M]^N)。生成本批 rollout 前，将当前策略复制为 θ_old；在该批 rollout 对应的全部更新期间保持 θ_old 不变，完成该批更新后、生成下一批 rollout 前再刷新。用于 KL 锚定的 θ_ref 在一轮完整实验内固定，正则项单独计算 KL(p_θ∥p_θ_ref)。全掩码比率删除了真实历史条件，也没有完整包含“选择哪些位置先恢复”的概率，因此只是提示条件代理比率，不是标准轨迹重要性比；相应裁剪目标也不作无偏 on-policy 策略梯度解释。校准实验从真实轨迹抽取状态，比较全掩码、部分历史上下文和真实轨迹条件下 log-ratio 的 Pearson/Spearman 相关、符号一致率、裁剪率、KL、显存与时间；若代理梯度在门 A 冻结的移动窗口和耐心阈值内持续不一致，则提高部分上下文或真实状态目标的权重，并把结论限定为经验 surrogate。

公平对照包括均匀信用、随机同规模 token 子集、仅生成秩、仅熵、固定层次、动态层次、随机重掩码和真实轨迹估计。各方法匹配 rollout 数、奖励调用、优化步数、参与反向的 token 数、训练 FLOPs 和目标 KL。主要机制证据为结构分数对高干预敏感 token 的 AUROC/AUPRC、与价值差的 Spearman 相关及分提示类型置信区间；注意力或熵图只作辅助。若最终增益可由额外更新次数或更大梯度完全解释，便不把结果解释为层次信用有效。

### 3.3 研究内容二的方法方案

搜索由探索、评价、剪枝和细化组成。探索阶段从全掩码状态使用不同随机种子、温度或掩码日程产生 N 个候选；评价阶段先把候选对齐到同一决策阶段和剩余预算，再从比较点统一切换到门 A 冻结的共同继续调度 h* 与补全策略 π_cont，不把不可解码的部分 token 直接当作完整图像，而在每个候选状态的副本上独立运行 P_t 次、每次 L_p(t) 步，形成 probe image，再由目标评价器回答对象、数量、属性和空间关系问题。临时补全 token 不写回活动轨迹。P_t、评价阶段集合和序贯停止规则由 pilot 的方差—成本曲线冻结；若某阶段补全方差过高，则推迟评价或只作软排序，不执行硬剪枝。token 状态上的轻量价值头可作为低成本对照，但其训练成本、预测区间覆盖率和精度单独报告。

设探索阶段每条候选运行 T_s 步，剪枝区间第 t 步保留宽度为 W_t，T_r 后保留 K 条轨迹至总步数 T。主模型轨迹步成本由四部分相加：N 条候选的探索步、剪枝区间各步的保留宽度、K 条轨迹从 T_r 到 T 的细化步，以及所有评价阶段候选的 P_t×L_p(t) 次临时补全步。端到端成本还包括提示解析、问题生成、每个 probe 的结构化验证、图像解码、数据搬运和动态批处理，日志可逐项重建总成本。文中不再把特定固定宽度设置下的 O(N+T) 简写当作一般实际复杂度；实验同时报告主模型 NFE、验证器等效 FLOPs、GPU-seconds、P50/P95 延迟、吞吐和峰值显存。

搜索需要估计的是固定 π_cont 下状态继续生成后的期望终局效用，而非当前 probe image 的表面得分。在线以 P_t 个 probe 的均值和标准误形成剪枝区间；离线只在训练或 validation-audit 划分的抽样状态上再独立补全 L 次，以未参与搜索决策的终局效用均值构造校准参考值，分阶段报告内部评分与该参考值的 Spearman/Kendall 相关、NDCG、top-K recall、区间覆盖率和优质轨迹误删率。区间较宽的候选延迟决策；高置信低价值候选提前停止；另保留固定探索配额，防止早期评分错误导致模式收缩。

比较对象包括单轨迹、best-of-N、线性完整扩展、同预算随机剪枝、使用同一评分器的均匀预算、冻结外部验证器以及只作上界的 oracle。best-of-N 使用与主方法相同的冻结评价器选样并计入评分成本；以独立测试指标选样者只列作 oracle。主方法的语义排序使用统一模型自身的目标评价器；外部大型视觉语言模型仅作上界或对照。在线日志为所有候选保存实际观察到的状态、V̂_search、区间和保留标签；被提前淘汰的候选没有“真实后续回报”。只对预先分层抽取的训练审计子集，无论保留或淘汰都执行同样数量的冻结教师补全，得到无删失的 V̂_teacher，其额外 GPU-hours 只计入训练数据生成成本。V_audit、final-audit、外部审计与 oracle 标签设为只读，不得进入学生训练或模型选择。

### 3.4 研究内容三的方法方案

方法先执行阶段 3A 的评价器校准，再执行阶段 3B 的自反馈更新。阶段 3A 固定生成器，从提示提取实体—属性—关系约束，并构造答案空间封闭、可程序核验的对象存在、数量、颜色、属性绑定和空间关系问题。评价器只接收生成图像或视觉 token 与问题，不接收原始生成提示和标准答案；多项选择题平衡正确选项位置并加入反事实干扰项。由提示解析得到的期望答案用于评价输出是否满足条件，不直接作为生成图像上的理解监督；否则当图像生成错误时，理解分支会被训练为忽略图像并猜测提示答案。理解分支只在独立带标签数据或经人工、外部工具确认的训练划分样本上更新，这些样本与人工最终评价互斥；短答案问题作为扩展而非主要奖励来源。

阶段 3B 维护在线生成策略 π_θ 和与其物理分离的完整目标参数快照 f̄_ψ；二者架构相同但不共享正在更新的参数，因此生成梯度不会改变阶段内奖励标准。快照前向、显存、参数换入换出和同步成本均计入训练账本。先以固定的均匀或既有时间步信用规则检验反馈来源，再与研究内容一的动态信用组成因子实验。在线理解参数只在独立理解数据上更新；目标快照是否在阶段边界以低频或指数滑动平均方式同步，只依据预留的 validation-audit 集及预注册校准阈值判断。POPE、MMBench 和 final-audit 集在最终配置锁定后才运行一次，不参与同步、早停或超参数选择。无图输入、图像遮挡、图像交换、提示—图像错配和反事实问题用于衡量视觉证据增量；若真实图像相对无图或错图的增量置信区间下界未超过门 A 冻结阈值，内部评价不进入主奖励。推理搜索阶段参数不更新，可由同一冻结模型按生成和问答接口交替执行。

内部语义、感知质量和多样性分别报告。若训练需要标量效用，各分量先在固定校准集归一化，权重在正式测试前冻结；多样性定义为同提示候选组的特征距离、覆盖率或熵约束，不与单张图像分数直接混合。训练评分器、模型选择指标和最终测试指标预先分离，至少保留一组完全未参与训练、搜索和超参数选择的终局评价。设置无强化学习、外部反馈、冻结自评、慢更新自评、同步自评和混合反馈基线，并在生成改善时同时检验理解非劣性、奖励—人工相关和 reward hacking 失败率。

### 3.5 研究内容四的方法方案

研究内容二为同一提示、同一阶段和同一剩余预算的 N 个在线候选保存搜索记录，并按预注册的分层规则从保留与淘汰分支中抽取 H≤N 个训练候选，保证两类分支均被覆盖。第 g 条训练记录包含扩展状态 s_{t_s}^{(g)}、在线搜索价值 V̂_search(g)、调度器和策略版本、保留或淘汰标签，以及冻结教师后续补全；其中 t_s 表示结构切点，避免与完整轨迹符号混用。学生的主排序标签预先指定为无删失的 V̂_teacher，V̂_search 只作辅助一致性信号；二者排序冲突超过门 A 冻结阈值时降权或剔除，不在测试后选择较有利者。用随机候选、仅最优终图、仅教师轨迹和完整搜索记录四种数据构造比较，检验增益是否真正来自搜索信息。推理主设置每个提示只生成一条学生轨迹；多候选增强模式单独报告，不与少步部署结论混合。

对于从搜索记录中预抽取的结构状态 s_{t_s}^{(g)}，冻结教师 π_φ 独立补全 M 次得到 x_1，…，x_M。V̂_teacher(s_{t_s}^{(g)}，c) 取这 M 个结果的经校准训练代理效用均值，并报告标准误、教师置信度和随 M 变化的估计方差。M 由 pilot 的方差—成本曲线选择并在门 A 冻结，各候选使用相同 M；若采用序贯采样，其停止规则和自适应成本预先登记。该量是冻结教师策略及给定剩余预算下的 Monte Carlo 近似价值，不等同于学生策略价值或只读审计价值；教师低置信或明显分布外补全需要降权。同一结构下的多样性 D_div(x_1，…，x_M)作为组级正则或约束单独计算，不与单样本语义、质量得分直接平均。训练过程中按预注册周期由当前学生生成 on-policy 状态，并用相同抽取和冻结教师补全规则刷新一部分记录，以覆盖学生实际访问分布；刷新比例及其额外成本在门 A 固定。

跨步蒸馏的主设置监督位置选择和 token 类别，并沿用 3.2 的固定恢复数量日程。给定从搜索记录抽取或由当前学生周期性刷新得到的扩展状态 s_t，对同一状态运行 M 条教师路径；位置目标由某位置在目标跨步窗口内被恢复的频率形成。学生沿用 3.2 中 q_θ 的位置评分参数化，以固定基数 m_t 的 listwise 排序损失学习该频率，并在推理时取前 m_t 个位置。教师路径在窗口内新增位置数的分布只用于可学习恢复数量日程的辅助扩展消融；该扩展预注册每步上下限、总步数和最终补全全部位置的约束，并以固定日程学生作为同预算基线。对位置 i，类别目标不是教师在初始 z_t 上的单次预测，而是汇总所有在该窗口恢复 i 的教师路径，并对每条路径在 i 实际被恢复前一状态上的软类别分布取 Monte Carlo 平均。学生从 s_t 匹配这一投影分布；若实现只保存教师硬 token，则将其明确作为高方差硬标签，并设置软目标与硬目标消融。已有可见位置不重复计入类别损失；被重掩码位置从下一步起重新进入位置与类别损失，另比较严格固定已见 token 与允许低置信位置纠错。

总目标由候选排序或结构策略损失 L_rank、位置蒸馏损失 L_pos、类别蒸馏损失 L_tok 和相对冻结参考策略的正则项 L_KL 加权组成；各项按样本或新增位置归一化，权重和 KL 方向在实验前明确。主方案先以蒸馏建立基本补全能力，再逐步增加结构策略权重；同步联合训练和梯度投影只作对照或冲突处理。若梯度长期相反或验证集质量下降，则按预先规则转为分阶段训练。

推理时固定步数预算 B_step＝K_s+K_r，比较均分、前多后少、前少后多和不确定性自适应四类预算，并与原多步教师、教师直接截短、一步 Di[M]O 类基线、相同步数普通蒸馏、纯结构强化、先蒸馏后强化和联合方法比较。只有单轨迹墙钟时间或 GPU-seconds 的置信区间支持下降且质量满足非劣界时，才称为实际加速；若只减少 NFE，则结论限定为采样步数或核心前向计算降低。

### 3.6 实验设计与评价

本课题为每项研究预先指定一个主假设；主假设可以由必须同时满足的效能终点与安全门构成，任一必要条件未通过即不宣称该假设成立。门 A 形成数值化注册表，冻结质量目标 Q*、非劣界、相关或覆盖率阈值、误删率上限、图像证据增量、移动窗口与耐心参数。所有方法在同一底座 checkpoint、图像 tokenizer、分辨率、提示集合、CFG、采样日程和评测代码版本下比较，并记录代码提交、checkpoint 哈希和随机种子。训练奖励、validation-audit 或调参使用过的评分器不作为相应实验的 final-audit 终点。

研究内容一的主假设为：在固定训练计算下，动态信用相对均匀信用的 GenEval Overall 配对差值 95% 置信区间下界大于 0。DPG-Bench、GenEval 六个子项、独立感知质量和多样性为次要或安全终点。动态信用方法与均匀信用、随机 token 子集、固定层次信用、随机重掩码和真实轨迹估计比较；各方法匹配 rollout 数、奖励调用次数、优化器步数、参与反向传播的 token 数、训练 FLOPs 和目标 KL。token 权重在 batch 内归一化，使平均权重为 1。机制验证报告全掩码代理比率与真实轨迹比率在不同阶段的相关、偏差、裁剪率和 KL，并以冻结继续策略、配对随机数和预设干预分布得到的价值差作为高影响 token 的主要证据。

研究内容二的主假设为：在 validation-audit 上冻结的质量目标 Q* 处，分层搜索相对线性搜索的质量差 95% 置信区间下界高于 −δ_G，同时端到端 GPU-seconds 或延迟差的置信区间上界低于 0；完整质量—计算 Pareto 曲线为支持性证据。在固定总计算预算处的独立生成指标差作为次要分析。搜索成本累计主模型前向、全部 probe、问题生成、视觉问答、解码、CFG、动态批处理和外部评分，同时报告估算 FLOPs、GPU-seconds、P50/P95 单图延迟、吞吐和峰值显存。比较对象包括单轨迹、best-of-N、线性搜索、同预算随机剪枝、同评分器均匀预算、外部冻结验证器和仅作上界的 oracle。

中间状态的当前自评分不直接视为轨迹价值。对抽样的中间状态独立补全多次，以独立终局效用的均值近似条件补全价值，按生成阶段报告自验证分数与该价值的 Spearman/Kendall 相关、top-K recall、NDCG 和误删率。若早期自验证不能可靠预测终局回报，则推迟首次剪枝、保留固定探索配额，或使用冻结外部/集成价值估计；不以当前局部图像得分替代可恢复价值。

研究内容三的主假设采用合取规则：相对无自反馈同预算基线，GenEval Overall 配对差值的 95% 置信区间下界大于 0，POPE 与 MMBench 分别满足各自冻结的非劣界；同时，真实图像相对无图或错图的证据增量置信区间下界高于门 A 的 δ_img，奖励—人工 Spearman 相关下界不低于 ρ_min，校准误差上界不高于 ε_cal。任一必要条件未通过均不宣称形成可信自反馈，也不以宏平均掩盖任一理解基准下降。DPG-Bench 和独立偏好/质量指标作为次要终点。评价分支只接收生成图像或视觉 token 与问题，不接收原始生成提示和标准答案，并以无图、图像遮挡、图像交换、提示—图像错配和反事实问题对照验证图像证据。完整冻结目标快照作为主奖励锚点，EMA 与同步更新只作对照；所有方案只用 validation-audit 监测训练期漂移，final-audit 在配置锁定后运行。

研究内容四的主假设也采用合取规则：相对相同步数普通蒸馏，GenEval Overall 差值置信区间下界大于 0；相对完整教师，质量差下界高于 −δ_G；单轨迹端到端延迟或 GPU-seconds 差的置信区间上界低于 0。三项同时满足才支持“搜索知识带来少步实际加速”。比较还包括教师直接截短、一步 Di[M]O 类方法、纯结构强化、先蒸馏后强化和联合训练，并对位置、类别软分布及重掩码纠错逐项消融；可学习恢复数量只作为相对固定日程的扩展对照。若只降低 NFE，结论限定为采样步数或核心前向计算降低。

非劣界在查看正式测试结果前冻结，由科学或应用上可接受的最大损失确定，并以人工最小有意义差异和既有基线差距提供依据。pilot 的测量方差和训练方差只用于样本量、重复次数和可行性判断，不用于放宽 δ。多个必要终点采用合取判定：生成质量差的 95% 置信区间下界高于 −δ_G，POPE 与 MMBench 分别高于各自非劣界，效率差的置信区间上界低于 0。pilot 所用提示和样本不进入 final-audit。

统计分析以训练 run 为上层、提示为下层进行层次配对 bootstrap 或混合效应估计；所有方法尽量共享提示和采样随机种子。机制级关键实验至少进行三次独立训练；同一 checkpoint 下增加生成随机种子只用于估计采样方差。若完整 8B 训练只能运行一次，则结论限定为该 checkpoint，并仅给出条件于该 checkpoint 的 prompt-level 区间，不表述为训练稳定性证据。多个次要指标采用 Holm 方法控制多重比较。人工评价样本数由先导功效分析确定，每对结果由至少三名盲评者判断，按评价样本与评价者聚类估计区间，随机交换左右位置并允许平局。

实验预先记录以下失败判据，并在门 A 为“缺乏相关”“长期冲突”“持续下降”等词冻结统计量、移动窗口、阈值和 patience。全掩码代理未达标时转用部分上下文或真实状态估计；内部自验证未达标时停止早期剪枝，外部或集成验证器只能作为工程回退，不能计作内部自验证假设通过；自反馈未通过图像证据或理解非劣门时不进入主奖励；联合蒸馏未通过时转为分阶段方案。增加学生步数只在预注册步数网格中作为次要边界结果，不能在主设置失败后继续宣称原假设成功。失败结果用于界定适用范围，不通过更换主指标或放宽非劣界掩盖。

### 3.7 可行性分析与资源分级

理论上，离散扩散的掩码集合、生成秩、类别分布和中间状态均可记录，能够支持代理比率校准、条件补全价值估计和跨步监督；统一模型同时提供生成与图像问答接口，可用于构造自验证和自反馈。前期材料报告 HT-GRPO 训练使用 8 张 A100-80G，Lumina-DiMOO 的 Stage IV Self-GRPO 使用 8 张 H200，说明团队实施过相近工作负载。现有材料没有提供后续 GPU 型号、可用 GPU-hours、单次最长占用时间或存储配额的批准证明，因此这些前期配置不能当作未来资源承诺；正式答辩前须由本人和导师据实补充资源来源与配额，并在门 A 归档。

后续研究采用三级资源包络。第一级为机制验证包络：使用较小底座、较低分辨率或参数高效配置，验证代理比率、结构分组、终局价值校准、提示泄漏控制和跨步蒸馏目标；该阶段覆盖多个独立训练种子，但不用于宣称 8B 模型最终性能。第二级为主实验包络：只有在门 M 前落实能够覆盖 pilot 冻结上限的配额，才将通过模块扩展到一个代表性大模型底座，完成质量、理解、效率、稳定性和人工评价。第三级为迁移验证包络：只有相应模块的完整主终点通过且另有计算资源时，才在第二底座、另一分辨率或多参考任务上验证外部有效性。

绝对 GPU-hours、最大 rollout 数 G、搜索宽度 N、保留宽度 K、训练候选数 H、每结构教师补全数 M 和训练样本数不在缺少实测吞吐时臆测。正式训练前在目标软硬件上运行固定时长 pilot，记录每次生成、验证、反向和教师补全的墙钟时间、峰值显存及失败率，据此计算三个包络的 GPU-hours、存储和人时上限并冻结。预算显式包含 G 条 rollout 与反向 token 数、在线搜索的全部 P_t×L_p(t) 临时补全、离线价值审计的 L 次补全、训练子集的 H×M 条教师路径、独立训练重复、目标快照开销和人工评价。预算调整只能由资源变化、实现错误或安全停止触发，并保留调整前后记录，不能根据测试指标临时扩大某一方法预算。

资源分配遵循“先证机制、再做单底座主结论、最后做迁移”的次序。门 M 拆为 M_credit、M_search、M_feedback 和 M_distill：各模块分别按门 A 注册的比率相关、value top-K recall、预测区间覆盖率、图像证据增量、理解安全和蒸馏质量阈值判定，且已落实配额覆盖其主实验上限；某模块失败不阻断可独立开展的其他模块。门 P 同样按 P1—P4 分别判定，只有某模块的完整合取主终点通过，该模块才进入第二底座迁移；一个模块的成功不能替代其他模块。完整闭环还要求 P4 相对移除搜索记录或移除校准评价器的接口消融具有独立增量。未通过时保留负结果并收缩相应创新声明。

主要风险及回退路径如下。若全掩码代理偏差过大，则把学术结论转向部分上下文与少量真实轨迹校准；若内部验证器存在提示先验或共享偏差，则使用冻结外部验证器或内部—外部集成作为工程对照，并明确内部自验证假设未通过；若同步更新造成理解退化，则保留完整冻结目标快照；若少步学生质量越过非劣界，则在预注册步数网格内报告质量—步数边界，并从联合训练退回分阶段方案。若只获得第一级资源，则仅完成小模型或低分辨率机制证据，将代表性大模型主实验和跨底座结论列为未验证，不以低配结果替代原定结论。

可行性还来自已有代码和实验积累，但可复现性以实际产物为准。每项实验保存配置、随机种子、checkpoint 哈希、数据版本、日志、GPU-hours、异常退出和失败案例；对无法公开的模型或数据，至少保留可审计的配置与指标生成脚本。多参考图像创作与编辑仅在第三级资源允许时作为外部有效性测试，不作为本课题通过验收的必要条件。

## 四、课题的创新点

### 4.1 面向生成层次的 token 信用分配

已有基础：前期 HT-GRPO 利用实际去掩码次序构造全局—结构—细化三阶段更新，并在特定底座和同协议实验中观察到相对均匀信用方法的生成语义增益；全掩码上下文的代理比率降低了轨迹缓存需求并避免直接引入未来可见 token。

现有不足：固定结构比例和固定权重不能适应提示复杂度；生成得早、高熵或高置信并不必然意味着对对象布局具有较大贡献。全掩码比率还丢失真实历史和位置选择事件，只能视为有偏 surrogate。现有最终分数不足以区分增益究竟来自结构信息、额外更新预算还是代理目标的正则化作用。

拟新增工作及预期创新：以生成秩、熵、跨步稳定性、空间信息和反事实条件价值差学习提示相关的结构概率，分别估计位置选择与类别预测的贡献；在相同训练预算下与随机、均匀和单特征信用比较，并用真实中间状态校准代理目标。预期创新是把固定顺序启发式扩展为可检验、可自适应的 token 信用估计框架，其结论限定在实际完成的底座、提示和调度范围；获得第二底座证据后再讨论迁移性。

### 4.2 统一模型自验证驱动的轨迹预算分配

已有基础：前期 dMLLM-TTS 系列工作已验证，统一模型可把提示遵循转化为结构化问答，并通过分层轨迹探索和筛选改善特定实验协议下的质量—NFE 折中。

现有不足：中间状态不完整，评价器可能依据文本先验而非图像证据排序；临时补全、问题生成和问答验证会引入未被 NFE 完整反映的成本。固定阈值可能在早期误删可恢复轨迹，已有 NFE 结果不能直接推出同倍数墙钟加速。

拟新增工作及预期创新：建立阶段感知的中间状态评价，以重复 probe completion 估计在线不确定性，对不确定候选延迟剪枝并保留探索配额；对预先抽取的保留和淘汰分支执行无删失教师补全，保存候选状态、调度器、相对价值和近似终局价值，供少步学生学习。预期创新是将自验证从终局选优扩展为带可靠性估计和完整成本核算的轨迹预算规则，是否构成实际加速由端到端实测决定。

### 4.3 生成—理解闭环中的可校准自反馈

已有基础：前期 Self-GRPO 利用对象、数量、颜色和关系问答形成结构化语义奖励，并在统一模型中观察到生成提示遵循改善；真实 rollout 上的时间步抽样为控制长视觉序列训练成本提供了可行基础。

现有不足：生成分支与评价分支共享参数和偏差，评价器可能根据提示猜答案；若把提示期望答案直接当作错误生成图像的理解标签，还会形成循环监督。同步更新使奖励分布非平稳，单纯生成指标提升不能证明理解能力保持或内部评价可信。

拟新增工作及预期创新：以物理分离的完整目标参数快照稳定奖励，对奖励路径停止梯度，并只用独立可靠标签更新理解能力；先在固定生成器下完成图像证据与校准检验，再用基础信用规则和动态信用规则做因子实验。通过无图、错图、遮挡、反事实问题、人工子集和独立理解基准校准评价器，再研究满足校准门槛的慢速同步与多奖励集成。预期创新是形成带图像依赖检验、奖励稳定化和理解非劣约束的自反馈闭环。

### 4.4 以搜索相对价值和位置—类别联合监督连接结构强化学习与跨步蒸馏

已有基础：HT-GRPO、dMLLM-TTS 和 Self-GRPO 已分别形成层次信用、候选搜索和内部反馈的前期方法；现有少步蒸馏工作说明多步教师信息可以迁移到更少步骤的学生，为粗到细训练提供了技术起点。动态结构概率、校准轨迹价值、无删失搜索记录和教师多次补全均属于本课题拟新增的数据与接口，不作为已经具备的事实。

现有不足：只蒸馏最终最优图像会产生高分尾部的选择偏差，普通跨步类别匹配也没有传递“哪些位置应先恢复”的生成顺序。若学生只使用教师状态训练，会面临推理时自身状态分布偏移；若部署仍依赖多候选筛选，则不能证明搜索经验已经固化为单轨迹能力。

拟新增工作及预期创新：接收本课题内容一至三产生的结构先验、校准信号和无删失候选子集，在学生真实访问状态上用候选相对价值学习结构决策，并用教师后续转移同时监督位置分布和 token 类别投影分布；恢复数量学习仅作为固定日程之外的辅助扩展。保留低价值候选学习决策边界，以周期性 on-policy 刷新覆盖学生错误状态。主部署模式只运行一条固定步数学生轨迹。预期创新是把“选择高价值结构”“决定恢复位置”和“预测位置类别”连接到同一学生状态分布，从而直接检验在线搜索信息能否转化为少步端到端收益。

### 5.2 预期成果与验收方式

本课题预期形成围绕预算条件补全价值的离散扩散生成优化方法体系，包括层次 token 信用分配、轨迹价值驱动的分层搜索、带冻结锚点的生成—理解自反馈，以及蒸馏位置日程和 token 分布的粗到细少步生成；恢复数量学习作为扩展方向单独报告。前三项各有论文方法与阶段性结果，本课题新增其机制校准、统一协议和接口化扩展；第四项是主要待完成的联合迁移方法。每项结论均对应可重新运行的配置、checkpoint 哈希、评测脚本、计算成本和失败案例。

研究内容一的验收证据为：在匹配训练计算和平均梯度尺度后，层次或动态信用相对均匀信用的 GenEval Overall 配对差值及 95% 置信区间；代理比率与真实轨迹比率的分阶段校准；生成秩/结构分数对干预敏感 token 的预测能力。若质量提升未通过主终点，但得到稳定的失效场景和代理偏差证据，则作为机制边界报告，不宣称动态信用普遍有效。

研究内容二的验收证据为：包含生成与验证开销的完整质量—计算 Pareto 曲线；在预先指定质量目标处的非劣性和端到端成本差；中间价值预测的相关、top-K recall 与误删率。只有墙钟延迟或 GPU-seconds 的置信区间支持下降时才称为实际加速；仅 NFE 下降时交付算法计算压缩结论。

研究内容三的验收证据为：独立生成主指标改善，且 POPE 与 MMBench 分别满足非劣性；自评分与人工/外部评价的相关和校准；无图、换图、反事实问题下的图像证据增量；完整冻结快照、EMA 和同步评价器的奖励漂移对照。若生成改善伴随任一关键理解指标退化或提示泄漏，则不认定为生成—理解协同。

研究内容四的验收证据为：固定少步预算下生成质量满足预先冻结的非劣界，同等质量下端到端延迟或 GPU-seconds 下降；位置日程蒸馏、token 软分布蒸馏、纠错重掩码和结构价值估计的消融完整；与教师截短采样、普通蒸馏、Di[M]O 类一步基线、纯强化和分阶段训练公平比较。若少步学生无法满足质量非劣性，则交付质量—步数边界、错误累积分析和可复现负结果，不把降低步数本身作为方法成功。

最终成果包括博士学位论文《面向离散扩散多模态大模型的生成优化方法研究》、相应学术论文或投稿材料、统一评测协议、实验配置与日志、质量—计算 Pareto 数据、生成—理解安全审计和可公开范围内的代码/模型产物。代表性大模型主实验以门 M 前落实足额配额为启动条件；若只有第一级资源，成果范围收缩为小模型或低分辨率机制证据，并把大模型结论列为未验证。第二底座和多参考编辑属于相应门 P 通过且资源允许时的迁移证据。
