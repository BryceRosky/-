# 两轮评阅与修订记录

评阅对象为《面向离散扩散多模态大模型的生成优化方法研究》开题报告。两轮均从格式、逻辑、文献综述、引用真实性、方法与统计、答辩压力测试六个角度独立检查；原始意见保存在 `reviews/round1/` 和 `reviews/round2/`。

## 第一轮：大修后复审

第一轮认为选题和前期工作基础成立，但研究问题尚未被一个可检验的主线约束，搜索、反馈、蒸馏之间的接口不够明确，预算公平性、评价隔离、统计判据和个人贡献边界不足以支持正式答辩。主要修订如下：

| 评阅问题 | 第一轮修订 |
|---|---|
| 四项研究像并列模块，缺少共同变量 | 引入“条件价值—预算分配—能力迁移”主线，统一状态、动作、终局效用和计算约束 |
| token 信用分配容易被误解为真实轨迹概率 | 将全掩码上下文明确限定为低成本提示相关代理，并要求用反事实和同预算基线验证增量信息 |
| 搜索只比较结果，未计入真实计算 | 把临时补全、视觉问答、解码与调度开销计入端到端成本，预注册停止规则和固定搜索额度 |
| 自反馈存在奖励泄漏和循环自证 | 分离生成器、冻结目标评价器和研究内代理效用；将图像证据支持的结构化回答与理解训练标签分开 |
| 搜索经验如何迁移到少步模型不清楚 | 明确恢复位置、恢复数量和 token 类别的联合教师信号，并加入硬标签/软分布、固定位置/允许重掩码消融 |
| 实验成功标准含糊 | 预注册单独模块门槛、共享总预算、非劣界、效应量、置信区间、失败类型及回退条件 |
| 文献综述罗列论文、缺少比较轴 | 重构为八个主题：生成范式、统一模型、奖励后训练、自反馈与搜索、少步蒸馏、评价体系、研究格局与课题定位 |
| 个人贡献和资源可行性证据不足 | 增加贡献边界矩阵和资源分级；没有可核凭据的算力与分工只写成启动门槛，不写成既成事实 |

## 第二轮：定向小修后通过

第二轮确认第一轮的原则性问题已解决，并继续收紧可复现性与证据边界。最终修订包括：

| 第二轮剩余问题 | 最终修订 |
|---|---|
| 条件价值未把阶段、剩余预算和调度器完整写入状态 | 定义扩展状态 `s_t=(z_t,M_t,t,b_t,h_t)`，并在同提示、同阶段、同预算、同调度条件下比较候选；成本不同时按边际价值/边际成本排序 |
| 行为策略与 KL 锚点符号混用 | 分开 `theta_old`（行为策略）和 `theta_ref`（参考策略） |
| 在线 probe 次数、写回规则和成本不明确 | 定义每个候选的独立重复次数、区间估计、端到端计费；probe 副本不覆盖活动轨迹 |
| 剪枝分支导致标签删失偏差 | 区分 `V_search`、`V_teacher`、`V_audit`，在独立审计子集上补全被剪枝与保留分支 |
| 跨步蒸馏教师目标过于抽象 | 固定教师独立补全次数，输出 Monte Carlo token 分布，登记恢复频率、数量和位置—类别联合监督 |
| 反馈评价器训练与最终测试仍可能泄漏 | 采用训练、验证—审计、最终审计三分；POPE/MMBench 仅作冻结最终评估；阶段 3A 先校准，3B 再闭环更新 |
| 主要终点和模块门槛未完全分开 | 设置 `M_credit`、`M_search`、`M_feedback`、`M_distill`，并以预注册联合主要终点判定，不允许事后放宽非劣界 |
| 文献技术措辞与评价边界需收窄 | 将 POPE 限定为对象幻觉诊断，使用 MICE-Bench 正式评价维度，精确表述 DDPO、Diffusion-DPO 和 Di[M]O 的能力边界 |
| 顺序编码和悬空引用 | 补引 TR-PTS，并按首次出现全局重排；最终 49 条连续、唯一、全部被正文引用，首次出现严格为 1—49 |
| Linux 导出的旧 PDF 出现中文缺字与叠印 | 保留学校字体版 DOCX，另建渲染兼容版 DOCX 生成最终 PDF；逐页检查 55 页，字体全部嵌入且带 Unicode 映射 |
| 全量在线日志、教师补全子集和学生状态来源混写 | 明确所有候选保留在线日志，仅对预抽取的 `H` 个训练候选补全无删失教师标签；以当前学生 on-policy 周期刷新覆盖实际访问分布 |
| PDF 换行边界吞掉标点，贡献表题与表格分离 | 将受影响短语改为不依赖行末标点的连词结构；修复表格插入顺序并让表题与完整表格同页。最终逐段对照无实际字符丢失 |

## 最终评阅结论与提交前事项

内容、逻辑、方法、文献综述和引用真实性已完成两轮修订并通过终检。49 条参考文献中，48 条有公开论文集、预印本或作者项目记录；`dMLLM-TTS v2` 仅由所附作者稿支持，因此始终标为 `Unpublished manuscript, 2026`，未写成已发表 TPAMI 论文。

以下事项需要作者用真实信息补齐，不能由评阅者推断：学号、学院、专业、开题日期、开题地点；“学术型博士、全日制、自拟课题”三个选择项也需本人确认。正式答辩前还应附实际 GPU/模型/时数/存储额度证明，以及代码提交、实验日志或合作者说明来核签个人贡献比例。
