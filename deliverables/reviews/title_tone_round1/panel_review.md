# 新题目与文风专项评审：第一轮

## 评审结论

重大修改后复审。

稿件已有较完整的研究基础和实验设计，但题目改为《面向多模态离散扩散模型的生成优化理论与方法》后，正文尚未同步完成范围和贡献调整；语言也过度接近审稿回复或实验预注册文件，影响开题报告的可读性。

## 主要问题

1. **题目范围需要界定。** 正文实际研究的是以离散视觉 token 表示图像、采用掩码扩散生成，并以文本—图像统一模型为主要实验载体的一类方法。应明确结论不直接外推到语音、视频或所有离散扩散模型。
2. **“理论”贡献尚不清楚。** 当前只有状态、动作和条件价值的形式化定义。需要增加代理概率比偏差、含噪价值估计对剪枝决策的影响，以及跨步蒸馏误差传播等可分析问题，并说明假设、结论形式和实验验证方式。
3. **研究内容的依赖顺序不自然。** 评价信号的定义与校准应先于信用分配和轨迹搜索；建议按“价值建模与校准—训练信用—推理预算—少步迁移”组织。
4. **真实评价与代理奖励之间缺少连接。** 训练和搜索只能使用代理分数，正文却以独立评价和人工评价定义最终效用。需要分析代理误差如何影响 token 权重、候选排序和蒸馏标签。
5. **状态与动作定义应统一。** `z_t` 应表示第 `t` 步的完整视觉 token 状态，而不是“第 `t` 个 token 状态”；确定性位置选择与类别概率也要分别说明，避免把代理概率比写成完整联合策略概率。
6. **正文过度协议化。** “门 A/M/P/T”“资源包络”“合取主终点”“只读标签”等术语反复出现，且多数段落以限制和失败声明收尾。应把统计规则集中到实验设计，把研究动机、方法直觉和个人判断放回正文主线。
7. **已有成果与新增工作仍需分开。** HT-GRPO、dMLLM-TTS 和 Self-GRPO 属于前期工作；本课题新增的理论分析、动态信用、可靠性校准和跨步蒸馏应逐项对应。
8. **资源可行性需要分级。** 应给出最低可完成方案和完整方案，待实际资源确认后再确定大模型规模、训练次数和跨底座实验。

## 第一轮修改要求

- 全文统一新题目及模型名称；
- 在绪论明确文本—图像实证范围；
- 增加三项理论分析任务和可验证结果；
- 调整四项研究的逻辑顺序；
- 删除门控代号和重复的防御性说明；
- 将英文实验术语改为中文为主，并在首次出现时解释；
- 保留引用编号与证据等级，不增加未经核验的文献。
