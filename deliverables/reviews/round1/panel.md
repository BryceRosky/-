# 第一轮匿名博士开题评审意见（严格评审口径）

## 一、总体评价与评审结论

课题围绕离散扩散多模态模型的训练后优化、推理时搜索、自反馈和少步蒸馏展开，选题处于快速发展的前沿方向。申请人已有较扎实的阶段性工作，报告也能主动承认 NFE 不等于真实时延、自验证存在共享偏差、不同论文的基础分数不能横向拼接等限制。这些自我约束比常见开题材料严谨，说明申请人对方法边界已有认识。

但以博士学位论文的标准看，当前稿件仍有一个根本问题：四项研究更像三篇已完成论文与一项拟开展工作的并列汇编，“价值识别—计算分配—能力迁移”目前主要是事后概念包装，尚未落实为同一状态空间、同一价值定义和可递推的科学问题。四项工作中的“价值”分别指 token 的奖励信用、候选轨迹的验证分数、生成图像的自问答奖励和教师补全后的期望回报，定义、估计对象和用途不同。若不能给出统一数学对象及前后依赖，答辩委员很可能认为这是“已有论文拼接”，而不是围绕一个核心科学问题连续推进的博士课题。

文献综述覆盖面较广，引用也经专门核验，但篇幅长、重复较多，且综述后半部分已大量写成“本课题拟……”的方案说明。对连续扩散蒸馏、离散扩散加速、搜索理论、奖励模型可靠性等直接相关领域的基础文献覆盖仍不足。报告的方法设计细致，但缺少可执行的算力预算、定量验收指标和统一符号定义，创新点中已完成成果与待完成创新也没有充分分开。

**评审建议：大修后通过。若校内表决只能选择“通过/不通过”，当前版本不建议直接通过，建议修改后复审。** 修改的关键不是继续增加篇幅，而是收束核心科学问题、重构四项工作的因果链、补齐关键文献与实证判据，并明确个人贡献和未完成工作。

## 二、最主要的学术缺陷

### 1. 统一科学问题尚未真正成立

目前主线是“识别高价值决策—按价值分配计算—迁移为少步能力”，但四项工作没有共享一个严格的价值函数。建议把核心问题明确为：**在具有随机、并行、非固定去掩码顺序的离散扩散过程中，如何可靠估计部分状态的条件补全价值，并用该价值统一指导训练信用分配、推理预算分配和跨步能力迁移？**

随后应定义统一的状态、动作、转移、终局奖励以及部分状态价值，例如明确 `s_t=(c,z_t,m_t)`、动作包含 token 预测与掩码集合选择、`V(s_t)=E[R(x)|s_t]`，再说明四项研究分别解决价值的归因、估计、校准和迁移。若 HT-GRPO 的全掩码代理与该统一价值不一致，也应明说它是早期近似以及后续如何校准。否则“价值”只是同一词语在不同章节中的复用。

### 2. 四项研究的递进关系存在顺序和功能重叠

研究二用模型理解能力做自验证，研究三又专门研究生成—理解自反馈；两者在当前叙述中是并列关系，但逻辑上研究三应为研究二提供“验证器为什么可信”的基础，或研究二产生数据再服务研究三。需要明确两者的输入、输出和依赖关系。

研究一的 token 信用分配、研究二的轨迹搜索和研究四的结构价值并未证明可共享同一估计器或中间表示。建议增加一张总技术路线图和一张接口表，逐项写清：输入状态、价值信号、学习对象、输出、如何传递到下一项研究、若该环节失败下一项能否独立成立。

### 3. 已完成成果与未来博士研究边界不清

创新点 4.1—4.3 基本对应已完成或已投稿/录用的 HT-GRPO、dMLLM-TTS 和 Self-GRPO；真正尚待完成的核心似乎主要是 4.4。开题报告不能把已完成论文的创新全部当作未来拟创新，也不能只用一项尚处概念阶段的工作支撑后续博士研究。

应按“已完成、需补强、拟开展”三栏重写每一项内容，并列出申请人在团队论文中的具体责任、独立完成模块、代码/实验/写作贡献及可用于学位论文的部分。尤其 Lumina-DiMOO 是团队底座，须避免把底座统一能力整体归为个人创新。还应解释第四项与 Di[M]O 或其他少步方法相比，新增的可证伪贡献到底是什么。

### 4. 若干关键方法假设尚未闭环

- “早生成 token 更结构化”是统计假设，不是普遍事实。报告已承认反例，但需预先规定结构性的量化定义、验证数据和失败阈值，避免事后选择支持性案例。
- 全掩码条件下的概率比不是行为策略在真实轨迹上的概率比。若仍使用 PPO/GRPO 式裁剪，需要说明该代理目标的优化含义、偏差来源和稳定条件，不能仅以效果好替代理论解释。
- 中间状态如何被理解分支评价没有明确说明。若需要把部分 token 解码成图像，应说明掩码位置怎样填充、解码伪影如何处理、评分是否引入额外前向；若直接用 token 状态，则需说明理解接口如何接收。
- 所谓 `O(N+T)` 与线性搜索 `O(NT)` 的比较过于简化。保留宽度 `K`、验证器调用、CFG 双前向、批处理和解码开销均未进入表达式，至少应给出精确 NFE 公式和端到端成本公式。
- 粗到细蒸馏中教师、学生、`z_t`、`z_s`、新增可见位置的选取规则、教师随机补全分布和 KL 作用位置仍不够明确。仅在新增位置做交叉熵可能导致全局不一致或多样性收缩，需要对应对照和失败诊断。

### 5. 可行性论证缺少资源约束

8B 模型、4096 个视觉 token、多轨迹 rollout、多次教师补全与自验证会形成很高的显存和 GPU-hours 开销。当前仅写“参数高效训练、梯度检查点、时间步抽样”，没有列出可用 GPU 型号和数量、单项实验预算、最大候选数、训练时长、数据规模及存储开销。应给出最小可行实验、标准实验和扩展实验三级预算，并为算力不足、验证器失准和少步质量下降分别设置可交付的替代路线。

## 三、文献综述专项意见

### 1. 结构和篇幅问题

第一部分达到模板字数要求，但 1.9—1.12、1.14—1.15 与第二、三部分大量重复，连续出现“本课题拟……”。这使综述从“研究现状与缺口”滑向了方法方案，且全文呈现密集文字墙。建议把综述压缩为六个主题：离散表示与生成、统一离散扩散模型、奖励后训练与信用分配、推理时搜索与自验证、少步生成与蒸馏、评价与研究缺口。将拟议方法统一移入第二、三部分。

应增加一张系统对比表，至少包含：模型/方法、连续或离散状态、生成顺序、反馈来源、信用粒度、是否保存真实轨迹、推理计算、端到端开销、主要局限。当前“国内外研究格局”主要按团队和成果罗列，缺少可审查的方法学比较。

### 2. 关键文献缺口

报告提到“一致性模型、轨迹蒸馏和分布匹配”，却没有给出对应代表文献；对 progressive distillation、consistency models、distribution matching/distillation 等连续扩散加速工作的回顾明显不足。即使课题研究离散扩散，也需要解释哪些思想可迁移、哪些因为离散并行状态而不可迁移。

推理时扩展部分偏重申请人相关工作，对 best-of-N、beam/tree search、MCTS、self-consistency、value-guided decoding 及生成模型中的验证器选择缺少系统来源。奖励可靠性部分提出校准、reward hacking、非平稳评价器等重要问题，但代表性文献几乎没有。离散蒸馏则主要依赖 Di[M]O 和一篇 2026 年预印本，尚不足以支撑“现状”判断。

POPE、MMBench、SEED、MMMU 被用作关键理解基准，却没有说明选择依据及版本；人工评测、多样性和校准指标也缺少标准协议来源。建议补充基准原始文献和正式评价定义，避免最终实验时随结果选择口径。

### 3. 自引和证据层级问题

综述中最新、最关键的论据集中来自申请人团队的 Lumina-DiMOO、Sketch Then Paint、dMLLM-TTS/v2 和 MICE-Bench，容易形成“用自己的阶段结果证明自己的研究缺口与有效性”的闭环。应把“领域独立证据”和“本人前期结果”分开呈现，并增加同类独立团队方法。阶段性结果应放入第六部分或明确标注为 preliminary evidence，不能充当领域共识。

实验数值应配统一条件表，至少写明 checkpoint、分辨率、采样步数、CFG、评测代码版本、硬件和是否来自原论文。当前正文虽提醒不同基础分不可直接比较，但仍在多处并排报告不同稿件的 GenEval，读者容易误读为可横向排名。

## 四、引用真实性与书目质量意见

根据随附核验说明，现有 41 条文献均有可追溯题名或公开标识符，正文 [1]—[41] 连续且均被使用；已纠正 GenEval 页码、LLaDA 的错误会议归属、CVPR 题名混用和 dMLLM-TTS v2 的在审状态。**当前没有发现可以认定为完全虚构的条目。**

但“未发现虚构”不等于书目状态完全无风险。下列条目需要在送审前保存正式网页、OpenReview/CVF/PMLR 页面、DOI 或 arXiv 快照，并再次核对：

- [15]、[23]、[24] 的 ICLR 2026 正式录用/出版状态；若只有预印本，应只按 arXiv 著录。
- [25] 参考文献本身按 arXiv 著录是稳妥的；“NeurIPS 2026 已录用”目前仅由答辩材料支持，正文必须继续明确证据来源，正式 proceedings 发布前不可改写成已发表。
- [31] CVPR 2026 页码与最终作者顺序应以 CVF 正式页面复核。
- [32] 只能写未发表/在审稿件，不得写成 TPAMI 论文或形成卷期、DOI 的错觉。
- [34] 是 2026 年预印本，只能作为近期动向，不能承担成熟共识的证据。
- [39] 应以 ICML 2026/PMLR 正式页面再次核对作者顺序、卷号和异常大的页码范围；全文因文件体积限制未直接核读，应保留这一材料边界。

书目格式尚未统一。正式会议论文、预印本、在审稿件、同时给出 arXiv 的会议论文混用不同著录颗粒度；部分有 DOI/页码，部分没有。应按学校指定规范（通常为 GB/T 7714—2015，需以学院要求为准）统一 `[J]`、`[C]`、`[EB/OL]` 类型、作者缩写、会议名、年份、页码、DOI/URL 与访问日期。不能为了“统一”而补造不存在的页码或 DOI。

## 五、格式与表达意见

1. 封面仍有学号、院系、专业、开题地点等待填字段，学位类型、学习形式和课题来源为暂定选择；未补齐前不能作为正式提交版。
2. 第一部分 15 个小节、约 1.1 万汉字，虽满足字数要求，但整份报告缺少技术路线图、方法关系图和相关工作比较表。建议减少重复文字并加入 2—3 张真正承载逻辑的信息图表。
3. NFE 首次出现时应给出完整英文及精确定义，并明确一次 CFG 条件/无条件计算、批内多个分支和验证器前向如何计数。`token`、`rollout`、`checkpoint`、`reward hacking` 等术语应统一中英文用法。
4. `K_s`、`K_r`、`z_t`、`z_s`、`L_RL`、`L_KD`、`L_KL` 等应使用统一数学排版，并设置符号表；当前纯文本表达不利于正式评审。
5. 预期成果过于笼统，应写成可验收成果，如论文/代码/数据或复现实验包数量、核心实验矩阵、最低性能与效率目标。不得预设必然提升，但应设定成功、部分成功和否证标准。
6. 计划中应加入每阶段的里程碑和 go/no-go 条件，避免所有风险推迟到 2027 年末统一处理。
7. 若成稿 PDF 仍存在章节起页导致的近空白页，应在最终排版中清理；同时检查表题、图题、页码、参考文献悬挂缩进和中英文标点是否符合学院模板。

## 六、必须修改清单（按优先级）

### A 级：不解决则不建议通过

1. 用一个正式定义的“部分状态条件补全价值”或等价数学对象重构总问题，并证明四项研究不是只共享“价值”一词。
2. 画出四项研究的依赖关系，消除研究二与研究三的功能重叠；说明每一项怎样产生下一项可使用的信号、数据或模型。
3. 将已完成成果、尚需补强工作和未来拟创新严格分开；逐项列明个人贡献，避免把团队底座或已发表结果整体写成拟创新。
4. 给出可检验、可否证的主要假设和定量验收标准，包括结构 token 假设、自验证可靠性、搜索误剪率、理解不退化、少步质量与真实时延。
5. 补充实际算力、数据、工期和失败回退方案，证明第四项研究在 8B/4096-token 设置下可执行。

### B 级：送审前必须完善

6. 重写文献综述结构，删除与方案章节重复的“本课题拟”，补齐扩散蒸馏、搜索/规划、奖励可靠性和离散加速的独立代表文献。
7. 为所有关键结果建立实验条件表；重写 `O(N+T)` 等过度简化表述，并统一 NFE、验证开销和端到端时延口径。
8. 增加相关工作对比表、统一技术路线图和符号表；明确中间状态如何评价及蒸馏目标如何构造。
9. 逐条复核 2025—2026 年文献的正式状态，按统一书目规范重排；继续把在审、匿名稿和答辩材料信息与正式发表事实分开。
10. 补齐封面字段，统一术语、公式和版式，清理冗余段落及异常留白。

## 七、最可能的现场追问

1. 请只用一句话说出本课题唯一的核心科学问题；四项工作共享的数学对象是什么，而不仅是共享“价值”这个词？
2. 研究一、二、三已经形成论文后，博士阶段尚未完成且具有独立创新性的工作究竟占多少？申请人在团队底座和各论文中的不可替代贡献是什么？
3. 早生成 token 为什么可以代表结构？若背景 token 先生成、主体轮廓后稳定，你的分组和信用分配如何避免系统性错误？请给出预设的否证标准。
4. 全掩码上下文的概率比并不是实际 rollout 的策略概率比，为什么仍可使用 PPO/GRPO 裁剪？它优化的目标是什么，偏差是否可能把策略推向错误方向？
5. 自验证模型既生成又评分，怎样排除根据提示猜答案、无图作答和共同偏差？如果内部评分与人工判断冲突，搜索和训练听谁的？
6. 你声称搜索从 `O(NT)` 降为近似 `O(N+T)`，当保留宽度为 `K`，再计入 CFG、自问答、质量评分、解码和动态批处理后，精确成本是多少？为什么 NFE 改善会转化为真实时延改善？
7. 研究二的自验证与研究三的 Self-GRPO 在科学上是什么关系？为什么不是同一反馈机制在推理和训练中的简单重复？哪个环节验证反馈是可信的？
8. 粗到细蒸馏中，学生访问的异常状态上教师也可能不可靠。教师如何定义跨步目标，为什么只监督新增 token 能保持全局一致性和多样性？若联合梯度长期冲突，核心方案是否仍成立？
9. 你的训练奖励、模型自评、GenEval/DPG 和人工评测之间如何隔离，怎样排除奖励泄漏、基准过拟合和多重比较后只汇报有利指标？
10. 请给出完成全部实验所需的 GPU 型号、数量、GPU-hours 和最小可行预算。如果只能获得计划算力的一半，哪些结论仍可完成，哪些必须放弃？

## 八、建议的第二轮复审判据

第二轮不以新增字数为准，应检查五项实质变化：是否出现统一形式化定义；四项研究是否形成明确输入输出链；已完成和待完成创新是否分开；关键假设是否有预注册式验收阈值与资源预算；文献是否补齐独立工作并完成正式状态复核。若这五项完成，报告具备通过开题的基础；若仅润色措辞、增加引用和图表，而核心结构不变，仍不建议直接通过。
